# 关于 abox.tools

加拿大安大略省的一个人，把自己一直需要、又一直不太敢信的工具自己写了出来。这里的一切都跑在你自己的设备上，代码是公开的。这一页写的就是这两件事的理由。

最后更新 2026年8月27日

## 这是什么

abox.tools 是一堆小工具，每个只干一件事。把照片改个尺寸，把视频裁一段，把两个 PDF 合起来，看看一个二维码里到底装了什么。现在有 44 个，旁边还有一批[指南](https://abox.tools/zh/guides/)，讲的是这些工具对应的活儿。

不寻常的不是它们做什么，而是在哪里做。每一个都完全在你的浏览器里跑，用你自己的硬件，用浏览器本来就带的那套编解码器。你打开的东西不会被传到任何地方。这些页面背后也没有一台服务器可以接收：整个站点就是一堆静态文件，工具则是放在旁边的普通 JavaScript 模块。

产品就是这些。这一页剩下的内容讲的是，为什么值得这么做，以及做这件事的是谁。

## 谁在做

一个人，独自在加拿大安大略省。这不是公司。没有团队，没有投资方，没有母公司，也没有被谁收购的打算。信件寄到 [hi@abox.tools](mailto:hi@abox.tools)，收信的就是写代码的那个人。这个地址适合谈什么、不适合谈什么，写在[联系页](https://abox.tools/zh/contact/)上。

站点是有意不署名发布的。这是个小项目，不是个人品牌。这里值得信的不是页脚的一个名字，而是任何人都能读的[代码](https://github.com/A-Box-of-Tools/website)，以及任何人打开开发者工具三十秒就能验的页面行为。这两样能核实，名字不能。

## 为什么这么做

做这类工具的常规办法是：把文件传上去，在服务器上处理，再把结果发回来。这样更省事，什么设备上都能用，几乎每一个“免费在线转换器”都这么干。

这也意味着把自己的文件交给一个陌生人。传个表情包无所谓。护照扫描件、医学影像、签了字的合同、元数据里带着家庭住址的照片，就不是无所谓了。文件一旦到了别人机器上，它的去向就取决于对方的规矩和对方的靠谱程度，而这两样你都查不了。那种站点的隐私政策是一句承诺，不是一道闸门。

浏览器已经好到用不着这句承诺了。它能读写 JPEG、PNG 和 WebP，能拆开视频容器并解码，能算文件的哈希，能读二维码，也能写 PDF。既然活儿能在你自己的机器上干完，“他们会不会留下我的文件”就不再是一个关于谁的动机的问题，而变成一个关于代码到底能干什么的问题。后面这个问题，你自己就能回答。

道理就这些，另有一篇指南把它讲透了：[往网站上传文件安全吗？](https://abox.tools/zh/guides/is-it-safe-to-upload-files/)

## 别信，去验

上面每一句话都是写来给人验的。按费劲程度从低到高，有四种办法。

- **把网断掉。**随便打开一个工具页，断开连接，照样用。它照样能用，因为里面从来就没有联网这一步。要是一个工具把你的文件送出去处理，这时候就停住了。
- **盯着网络看。**打开开发者工具，切到“网络”，处理一个文件。没有任何一条请求带着你的文件、它的缩略图、它的文件名，或者它内容里的哪怕一个字节。你会看到的是页面本身、页面的脚本、广告和访问统计。
- **读读页面给自己定的规矩。**每一页都带着一份 `Content-Security-Policy`，把它被允许连的地址一个不落地列了出来，其中没有一个属于本站。就算代码里有错，也没法把文件送到哪里去，因为浏览器会拒掉那个连接。
- **读代码。**代码[全部公开](https://github.com/A-Box-of-Tools/website)，没有构建步骤，也没有打包器：仓库里是什么，浏览器跑的就逐字节是什么。每个工具都有一份 README 讲它怎么工作，每个工具页也点名了先读哪几个文件最划算。

“不联网”只有一个刻意留下的例外，而且在它自己的页面上讲得很细：[文本共享](https://abox.tools/zh/share-text/)要把文字从你的一台设备挪到另一台，没有网就办不成。它只开一条连接，通向一个什么都不存的中转点，而那个中转点被告知的只有一件事：有两个浏览器想认识一下。

## 工具怎么做，怎么验

一个工具是在它能处理真实文件的时候上线的，不是在它能处理开发时手边那个文件的时候。具体做法是在浏览器里手动喂它一些难缠的输入：你想剪的那一处正好没有关键帧的视频，容器写得略有偏差的手机 HEIC，字体只嵌了一部分的 PDF。人们手上真正有的就是这些文件，而写出这个缺陷的人自己写的测试，恰恰找不出它们。

下面还有一整套自动测试，两头都盖到：生成站点的那个生成器，和浏览器执行的那些模块。每次改动都跑一遍，测试没过就什么都不会发布。同一段活儿出现在多个工具里的地方，比如有好几个工具都要读 MP4，会有测试盯着这几份副本是不是还对得上，免得修好一处，另几处却悄悄错着。

指南也按同一把尺子写。里面的截图不是画的也不是摆拍的，是脚本从已经构建好的站点上抓的。所以指南里的图，就是那个页面今天的真实样子。

## 钱从哪来

广告，加上觉得这些工具有用的人的捐助。整个盈利模式就这些，而它包含什么、不包含什么，值得说清楚。

**这里没有东西卖。**不用注册，没有账号，没有上面压着付费版的免费版，没有要花钱去掉的水印，没有文件大小上限，没有每日次数限制，也没有留一手的功能。站点上有的，就是全部。

**你的文件不在这笔买卖里。**广告是 Google 的，访问统计用的是 Google Analytics，这两样都不会被告知你打开了什么、做出了什么、它叫什么名字、有多大。这些信息压根不会交到那两个脚本手里，就算其中一个想发，页面的安全策略也会拒掉。那两样究竟收集了什么、各自怎么关掉，写在[隐私页](https://abox.tools/zh/privacy/)上。把两样都拦掉，所有工具照常能用。

**工具不是为广告写的。**这里没有哪个工具是因为某个关键词值钱才存在的，也没有哪个为了多卖几次曝光而被故意做慢、做繁琐、拆成更多页。接下来做什么是摊在明面上争论的，在 [ROADMAP.md](https://github.com/A-Box-of-Tools/website/blob/main/ROADMAP.md) 里，一个想法一段，包括好几个看起来理所当然的提议为什么被否掉。

## 语言

站点有十五种语言。每一种都是真的翻译，不是机器过一遍就撂在那儿：工具名、说明、指南，连地址本身都翻了。一个页面只有在那种语言真的写出来之后，才会被列进那种语言。还在做的语言仍然能读，但不进站点地图，也不进语言切换器，免得把人请到一个一半是英文的页面上。

来信用英文回。对一个这么大点的项目来说，这是唯一诚实的说法。

## 本站不会做的事

- 让你注册账号，或者向你要邮箱地址。
- 上传、保存、查看或者留下你在这里打开的文件。
- 在结果上打水印，或者把某个功能留给付费版。
- 给一个用不着联网的工具加上联网这一步。
- 在工具页上说一些仓库里的代码并不会做的事。

要是你发现上面哪一条真的发生了，那既是一个缺陷，也是一句被打破的承诺，值得告诉我一声。[联系页](https://abox.tools/zh/contact/)是最快的路。
