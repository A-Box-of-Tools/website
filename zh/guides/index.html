指南

一个工具一篇。写给那些被人要求交出某个大小、某种格式，又想弄明白手上这个设置到底在动什么的人。这里讲的每一步，都发生在你自己的机器上。

41 篇指南

把活干完

一个工具一篇：这活要做什么，哪个设置真管用，代价又是什么。

  • 怎么把图片压到指定的文件大小 上传框要 500 KB，你的照片有 4 MB。一个大小限制到底要你付出什么，先动哪个设置，以及 PNG 为什么不像 JPEG 那样能压。
  • 怎么改图片尺寸而不把它弄坏 改像素尺寸时画面到底经历了什么：为什么缩小安全、放大不安全，框的比例跟照片对不上该怎么办，以及什么时候其实该裁而不是缩。
  • 怎么拍一张不会被退回来的证件照 证件照真正被量的是什么——头部高度、眼睛的位置、背景——哪个国家要哪些数字，以及怎么满足网上表格卡的像素和 KB 限制。
  • 怎么做一个到十六像素还看得清的网站图标 favicon.ico 里到底该装哪几个尺寸，iPhone、安卓和 Mac 另外要哪些文件，以及为什么一个在海报上好好的 logo，到了十六像素就没了。
  • 怎么把 SVG 转成合适尺寸的 PNG 矢量图自己没有像素尺寸，所以这个数字由你定。屏幕、应用图标和印刷各自的数字从哪儿来，以及一张图纸变成像素那一刻会发生什么变化。
  • 什么时候该把图片塞进 CSS，什么时候不该 data URI 的代价在哪儿，base64 为什么多出三分之一而 gzip 又还不回来，SVG 为什么绝不该用 base64，以及那个只坑内联 SVG、还一声不吭的引号问题。
  • 一张照片把你交代了多少，以及怎么把它删掉 手机拍的照片通常带着精确的拍摄地点、精确到秒的时间，还有相机的序列号。里面到底有什么，谁读得到，以及怎么在不动画面的前提下把它们清掉。
  • 图片怎么涂黑，才能让被遮住的那块真的没了 大多数软件画出来的黑色方块只是压在图片上面，随手就能挪开。真正的涂黑和只是遮住差在哪里，打过码的文字为什么能被读回来，以及发出去之前怎么检查一个文件。
  • 怎么堆栈照片来压噪点，或者把人去掉 堆栈把一串连拍合成一张。用哪种手法，取决于你想失去什么：噪点、路人，还是微距那浅得可怜的景深。每种手法怎么运作、代价是什么，以及 RAW 文件在这里是什么位置。
  • 怎么打开一个 DICOM 文件，以及里面有什么 医院给的光盘里都有什么，文件为什么没有后缀，怎么在浏览器里打开一份 .dcm 影像，窗宽窗位到底在做什么，以及一份影像除了图像之外还带着关于病人的哪些东西。
  • 手机存下的那张照片，和那个什么都打不开的格式 iPhone 把照片存成 HEIC，而半个互联网打不开它。这个格式是什么，为什么只有 Safari 解得了，转换要拿画质换多少，以及怎么做到不把照片交给任何人。
  • 怎么合并、拆分和重排 PDF 页面 把几个 PDF 合到一起、把一个切成好几个、把页面挪来挪去：重排之后什么留得下、什么是任何工具都带不过去的，以及为什么这些事都不必把你的文件传到别处。
  • 怎么把 PDF 涂黑，让文字真的消失 在 PDF 阅读器里画的黑块，通常把词原封不动地留在了下面，复制粘贴就能拿回去。真正的涂黑拿掉的是什么，词在页面之外藏身的四个地方，以及发出去之前怎么检查一个文件。
  • 怎么给 PDF 瘦身，以及有些为什么压不动 一份 PDF 的体积到底压在哪儿，扫描件为什么能小 80% 而合同几乎纹丝不动，这里的 DPI 是什么意思，以及压缩工具绝不该对你的文档做什么。
  • 怎么把多张图片合成一个 PDF 把照片或者扫描件做成一个 PDF：页面大小、顺序和旋转，JPEG 为什么进去时可以一点不掉画质，以及这份 PDF 会向收件人交代些什么。
  • 怎么用手机扫描文档 一张纸的照片和这张纸的扫描件之间差在哪里：倾斜、不匀的光，还有文件大小。照片怎么拍，之后要修什么，以及为什么这些都不需要服务器。
  • 怎么把一个文件夹的图片做成视频 用照片做一段 MP4 幻灯片：帧率和停留时间各管什么，比例不对的照片怎么办，以及成品为什么没有配乐。
  • 怎么用图片做一个动图 GIF 把一组图片变成一个动图 GIF：GIF 到底能放多快、调色板那个选项改的是什么，以及真正能让文件变小的三件事。
  • 怎么剪视频而不重新编码 剪一段片子可以一个字节的画质都不掉。为什么下刀的位置有时候比你标的早，关键帧跟这有什么关系，以及什么时候该认下那次重新编码。
  • 怎么把视频画面裁成另一个形状 把片子裁成方图、9:16 竖屏，或者精确到像素的一个框。各家平台要哪个比例，为什么剪时长不用重编而裁画面非重编不可，以及这一下的代价。
  • 怎么把视频倒过来放 把片子反着放：倒放对画面和声音都做了什么，为什么它绕不开重新编码，为什么比剪辑慢，以及动手之前该先做哪一步。
  • 怎么把视频里的一帧存成图片 按原分辨率从片子里取一张静帧：为什么暂停后的截屏不是同一张图、该存成什么格式，以及怎么正好停在你想要的那一帧。
  • 怎么剪音频而不掉音质 一刀落在哪儿、为什么音频能剪得准而视频不能、为什么接缝有时会「咔」一声，以及那五毫秒的淡入淡出到底在做什么。
  • 怎么做一个到了别人手机上还扫得出来的二维码 纠错等级该选哪个，二维码周围那圈白为什么是码的一部分，印多大合适，还有免费生成器的“动态码”日后要你付出什么。
  • 怎样用校验和核对下载的文件 在 Windows、macOS、Linux 或浏览器里比对 MD5 与 SHA-256 校验和的办法，对上了究竟证明了什么，以及那个让整件事白做的错误。
  • 怎么把视频做成 GIF 该挑哪一段、多宽、每秒几帧，视频做成 GIF 为什么会大出十倍，以及什么时候压根不该用 GIF。
  • 怎么把 GIF 拆成一帧一帧 把动图 GIF 的每一帧存成 PNG：为什么有些帧只是画面里的一小块、透明会怎么样，以及怎么把时间留住，好把它再拼回去。
  • 一个 GIF 里到底装着什么 帧、延时、处置方式和调色板都讲清楚：浏览器为什么不认最短的延时，以及怎么查出一个 GIF 的体积究竟花在了哪里。
  • 怎么不把 JSON 交给任何人也能格式化 在自己的浏览器里排版、检查和压缩 JSON：一个格式化工具绝不该改动你文件的哪些地方、错误信息该怎么读，以及你把东西粘进哪个框里为什么要紧。
  • 如何不上传就在设备间分享文本与文件 把文本或文件经直连加密通道从一个浏览器送到另一个——不用给自己发邮件，不留聊天记录，不需要账号，也没有哪台服务器留着副本。

工具接力

要接连用上两三个工具的活儿：按什么顺序用，顺序又为什么要紧。

  • 怎样把视频的一段做成 GIF 先剪出要紧的那几秒，再只转换那一段。什么时候 GIF 转换器自带的时间轴就够用，什么时候该先用视频剪切器剪，以及 GIF 的每一秒为什么那么贵。
  • 怎样做一个回旋镖视频 剪出瞬间，倒转副本，把两段接起来循环。三个工具连着用，全在浏览器里，还有一个把整件事压进一分钟的次序。
  • 怎么把长视频变成延时摄影 一小时的素材浓缩成看得下去的一分钟：怎么选速度，为什么直接说成片多长比做除法更好，以及什么时候成品该做成 GIF。
  • 怎么从正好那一帧做视频封面图 逐帧走到正确的瞬间，无损保存，裁成平台的形状，压到字节上限的正下方。三个浏览器工具接力，素材从不离开你的电脑。
  • 怎么逐帧编辑 GIF 把 GIF 拆成一帧一帧，删掉或重排，再在保住节奏的前提下重组。往返一趟什么能活下来、调色板的代价是什么、以及怎么看清一个 GIF 为什么重。
  • 怎样把多页扫成一个小 PDF 每页拍一张，得到一个 PDF，和已有的文档并到一起，再缩到发得出去为止。三个浏览器工具连着用，纸面材料从头到尾不离开手机。
  • 怎样把手机照片弄妥了再上网 HEIC 转 JPEG，抹掉 GPS，按页面缩好尺寸，再按预算压缩：整条链子都在浏览器里，原图从不离开你的机器。
  • 怎么做一个二维码，并证明它扫得出来 生成二维码，再用同一个网站的识别器验证：一字不差的内容、真正的链接，按印刷尺寸、用一张照片，在批量印刷之前。全在浏览器里，什么都不上传。
  • 怎么在发出去之前整理好语音备忘录 剪掉空白和口误重来的开头，再把音量提到满格线的正下方。两个浏览器工具接力，按保住音质的顺序来，录音从不离开你的电脑。
  • 怎样比对两个 JSON 文件 两个文件用同一种方式格式化，键排好序，再比对。为什么生比 JSON 几乎全是噪音，怎么在浏览器里把两边化成规范形，以及什么能一路留到补丁里。

上传之前

把文件交给一个网站，到底等于交出了什么，以及这一步是不是非做不可。

  • 把文件传给在线转换器安全吗？ 多数在线转换器会把你的文件送到服务器上。这意味着什么，文件在那边会经历什么，以及四项能看出一个工具到底需不需要你文件的检查。
