# AI 智能体能用这些工具吗？

代理可以使用浏览器界面。判断数据去哪儿，要看浏览器在哪儿运行、代理自身发送什么，以及工具哪些功能联网。

最后更新 2026年10月12日

## 先说结论

能控制浏览器的代理可以操作这些普通网页：有标签的控件、文件选择和下载，无须本站账号。运行环境必须支持所需的文件访问、浏览器 API 和权限。摄像头许可或设备分享面板可能需要你参与。

处理文件时，首先要问**受控浏览器在哪里运行**。还要检查代理服务收到什么，以及功能是否主动获取或分享数据。本地浏览器本身不能回答这三个问题。

## 智能体分两种，分界只有一条

会用工具的智能体有两副样子。两者的差别，比这一页其余所有内容都要紧。

**本地受控浏览器**在那台设备上读取和处理文件。本站的本地处理不会额外上传文件去处理。但代理仍可能向服务商发送指令、截图或文件上下文，这取决于代理自身实现和设置。

**云浏览器**运行在代理服务商的机器上。为在那里使用而附上的文件，已经离开你的设备。工具在远程浏览器内处理它，不能撤销先前的传送。主动分享和应用交接在两种环境里都是额外操作。

若要让处理留在设备上，就指定本地浏览器，核查代理自身的数据处理，并单独授权主动传送。[汇率查询和邮件交接](https://abox.tools/zh/receipt-invoice-extractor/)、[网址图片导入](https://abox.tools/zh/images-to-video/)、[分享](https://abox.tools/zh/share-text/)和[摄像头观看](https://abox.tools/zh/remote-camera/)都有明确联网边界。

## 怎么把活交给智能体

智能体干活，最好的交代和交给同事的一样：哪个工具，哪个文件，干完了长什么样。几个管用的路数。

- **说结果，别只说工具。**“打开 abox.tools/compress-image/，把这张照片压到 200 KB 以下”，等于把页面要问的那个数字提前交给了智能体。[图片压缩工具](https://abox.tools/zh/compress-image/)就认一个指名道姓的目标大小，智能体最能忠实执行的，恰好是这种指令。
- **把地图给它。**这个站发布了 [llms.txt](https://abox.tools/llms.txt)：每个工具、每篇指南，各配一行说明，纯文本，一次抓取就是全部。读过它的智能体不用爬任何页面，就知道这里有什么。另外，每个页面在自己的地址后面加上 `index.md`，都有一个孪生版本：去掉界面、只剩文字的 Markdown 页面，给那些想知道工具页面说了什么、而不是长什么样的智能体。
- **让它读自己站着的那页。**每个工具的常见问题就写在页面里，每个工具的指南只隔一个链接。看上去拿不准某个设置的智能体，可以让它先读指南。给人的建议，也是这一句。
- **说明步骤之间的检查。**扫描成 PDF 或清理图片时，让代理核对页序、裁剪、文字可读性和输出大小。OCR、遮盖以及决定什么能分享，都需要判断和结果审核。

## 哪些不该托付

操作控件只是任务的一部分。凡是会改变别人看到或收到什么的决定，都要审核。两个例子：

**决定什么不能被看见。**涂黑工具会把你盖住的部分删掉。可挑出该盖什么，那才是这件活本身。漏看一行的智能体，交出来的是一份看着完工、其实没完工的文件。涂黑的操作尽可以让智能体来，结果在发去任何地方之前，要你自己过目。那些工具的指南给人类操作者立的，就是这条规矩。

**打开读到的东西。**这个站的二维码识读器拒绝打开它解出来的内容，因为读和跟着走是两个动作。同样的分界也值得立给智能体：在文件里读到码、链接或地址的智能体，应该报告它，而不是访问它。还有一层，操纵你自己浏览器的智能体，手里握着那个浏览器登录着的一切。这是用打量任何工具的那种眼光打量它的理由，下一节就说这个。

## 承诺，智能体也验得了

[上传那篇指南](https://abox.tools/zh/guides/is-it-safe-to-upload-files/)教的四项检查，拔网线、盯网络面板、读 Content-Security-Policy、读代码，智能体全做得来，而且比人做还顺手：读一个 CSP 头，或者在下发的源码里搜 `fetch` 调用，本来就是机器活。要是你习惯先让智能体验一验工具再信它，这个站就打算被这么验。这些检查倚仗的离线行为，有[自己的一页](https://abox.tools/zh/guides/how-can-a-web-page-work-offline/)。

页面为控件加标签，提供[llms.txt](https://abox.tools/llms.txt)和 Markdown 副本。源码、共享模块和内置引擎公开。构建会生成页面并压缩代码，审核时应把自行构建结果与发布输出比较。代理是否能使用开发者工具和 WebRTC 诊断，取决于运行环境。

本指南不能替代理服务商保证隐私。即使浏览器在本地，代理也可能发送指令、截图，有时还有文件。代理的数据路径和工具说明的联网功能，都应纳入任务；浏览器位置本身不能证明它们。
