# 照片要求：中国护照和签证

National Immigration Administration 对这种证件的照片有什么要求，以 2026-08-20 读到的为准；以及一个不用把脸交给任何人、就能做出合格照片的办法。

最后更新 2026-08-20

## 具体数值

| 测量的项目 | 这条规定公布的数值 |
| --- | --- |
| 打印尺寸 | ⁦33 x 48⁩ 毫米，300 dpi |
| 头部，下巴到头顶 | 58.3% 到 68.8%（⁦28–33⁩ mm） |
| 眼睛高度，从底部量 | 50.0% 到 62.0%（⁦24–29.8⁩ mm）（参考） |
| 背景 | 纯白 |
| 在线签证申请上传 | 正好 ⁦354 x 472⁩ px，JPEG，40.0 KB 到 120.0 KB |

[按这条规定制作照片](https://abox.tools/zh/id-photo/#cn-passport) 打开证件照工具，并且已经选好这条规定。它在你的浏览器里运行：照片不会上传，不用注册，也没有水印。

## 这条规定还说了什么

- ⁦33 x 48⁩ 毫米的画幅，比几乎其他所有地方用的 ⁦35 x 45⁩ 更窄，头部从下巴到头顶 28 到 33 毫米。
- 上传不但有上限还有下限——在正好 ⁦354 x 472⁩ 像素下是 40 KB 到 120 KB，也就是同一个画幅按 272 dpi 算出来的。

## 这些数值从哪里来

转录自 National Immigration Administration — Published photograph standard for exit and entry documents。2026-08-20 核对。规定会变；上面的数字是拿去跟你面前那张表格对照的。

## 工具拿这些数值做什么

- 把裁剪框锁定成这种证件的形状，并在框里画出头部和眼线的区间，让你在自己的照片上直接看到规定，而不是只读到它。
- 通过测量画面找出头顶、下巴和两只瞳孔，不下载任何人脸模型，并用毫米告诉你，按这条规定头是偏大还是偏小。
- 读取背景的颜色，以及光线是否均匀；有问题的时候，说明是两者中的哪一个。
- 按精确的毫米写出打印文件，分辨率写在文件里；再生成一张带裁切标记的拼版，以及符合这条规定的像素和体积的上传文件。
