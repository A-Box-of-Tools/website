# 照片要求：韩国护照

외교부 (Ministry of Foreign Affairs) 对这种证件的照片有什么要求，以 2026-09-17 读到的为准；以及一个不用把脸交给任何人、就能做出合格照片的办法。

最后更新 2026-09-17

## 具体数值

| 测量的项目 | 这条规定公布的数值 |
| --- | --- |
| 打印尺寸 | ⁦35 x 45⁩ 毫米，300 dpi |
| 头部，下巴到头顶 | 71.1% 到 80.0%（⁦32–36⁩ mm） |
| 眼睛高度，从底部量 | 50.0% 到 60.0%（⁦22.5–27⁩ mm）（参考） |
| 背景 | 纯白 |
| 网上申请用照片 | 正好 ⁦413 x 531⁩ px，JPEG，没有写明文件大小的规定 |

[按这条规定制作照片](https://abox.tools/zh/id-photo/#kr-passport) 打开证件照工具，并且已经选好这条规定。它在你的浏览器里运行：照片不会上传，不用注册，也没有水印。

## 这条规定还说了什么

- 这条规定量的是到头颇顶端的高度，不算头发。这里的标记点找的是头发的顶端，因为照片上有的就是头发；所以头发多的人量出来会偏高——往区间的下半段取。
- 韩国查两件别处几乎不明写的事：背景不允许用软件抠掉或换掉，以及头高量到头颇顶端、不算头发。网上表单建议 ⁦413 x 531⁩ 像素，就是这个尺寸在 300 dpi 下的像素数。
- 没公布眼线。这里显示的区间，是头部居中时眼睛会落在的位置——是参考，不是要求，也从不标红。

## 这些数值从哪里来

转录自 외교부 (Ministry of Foreign Affairs) — 여권안내 — 여권사진 규격 안내 <2022. 10. 개정>。2026-09-17 核对。规定会变；上面的数字是拿去跟你面前那张表格对照的。

## 工具拿这些数值做什么

- 把裁剪框锁定成这种证件的形状，并在框里画出头部和眼线的区间，让你在自己的照片上直接看到规定，而不是只读到它。
- 通过测量画面找出头顶、下巴和两只瞳孔，不下载任何人脸模型，并用毫米告诉你，按这条规定头是偏大还是偏小。
- 读取背景的颜色，以及光线是否均匀；有问题的时候，说明是两者中的哪一个。
- 按精确的毫米写出打印文件，分辨率写在文件里；再生成一张带裁切标记的拼版，以及符合这条规定的像素和体积的上传文件。
