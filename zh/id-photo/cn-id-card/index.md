# 照片要求：中国身份证

北京市公安局 对这种证件的照片有什么要求，以 2026-09-21 读到的为准；以及一个不用把脸交给任何人、就能做出合格照片的办法。

最后更新 2026-09-21

## 具体数值

| 测量的项目 | 这条规定公布的数值 |
| --- | --- |
| 打印尺寸 | ⁦26 x 32⁩ 毫米，300 dpi |
| 头部，下巴到头顶 | 60.0% 到 72.0%（⁦19.2–23⁩ mm）（参考） |
| 眼睛高度，从底部量 | 50.0% 到 62.0%（⁦16–19.8⁩ mm）（参考） |
| 背景 | 纯白 |
| 上传规定 | 没有公布——这一条是给打印的 |

[按这条规定制作照片](https://abox.tools/zh/id-photo/#cn-id-card) 打开证件照工具，并且已经选好这条规定。它在你的浏览器里运行：照片不会上传，不用注册，也没有水印。

## 这条规定还说了什么

- 身份证照比任何护照尺寸都小：⁦26 x 32⁩ 毫米，白色背景、无边框，头部约占照片的三分之二，两耳根之间的脸宽 15 毫米，上下差一毫米。不穿制式服装，不穿白色上衣；常戴眼镜的人应戴着眼镜拍。大多数派出所是自己拍，或者让你去指定的照相馆——打印之前先问一声。
- 这一条没公布头高区间，画幅也不是常见的那种，所以 ICAO 的数字套不上。这里显示的是根据规定的文字描述读出来的一个宽松区间；它只是参考，从不当作不合格标红。

## 这些数值从哪里来

转录自 北京市公安局 — 居民身份证照片标准，引《居民身份证制证用数字相片技术要求》GA461—2004。2026-09-21 核对。规定会变；上面的数字是拿去跟你面前那张表格对照的。

## 工具拿这些数值做什么

- 把裁剪框锁定成这种证件的形状，并在框里画出头部和眼线的区间，让你在自己的照片上直接看到规定，而不是只读到它。
- 通过测量画面找出头顶、下巴和两只瞳孔，不下载任何人脸模型，并用毫米告诉你，按这条规定头是偏大还是偏小。
- 读取背景的颜色，以及光线是否均匀；有问题的时候，说明是两者中的哪一个。
- 按精确的毫米写出打印文件，分辨率写在文件里；再生成一张带裁切标记的拼版，以及符合这条规定的像素和体积的上传文件。
