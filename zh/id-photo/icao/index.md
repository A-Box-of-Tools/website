# 照片要求：ICAO 标准任何生物特征旅行证件

International Civil Aviation Organization 对这种证件的照片有什么要求，以 2026-08-20 读到的为准；以及一个不用把脸交给任何人、就能做出合格照片的办法。

最后更新 2026-08-20

## 具体数值

| 测量的项目 | 这条规定公布的数值 |
| --- | --- |
| 打印尺寸 | ⁦35 x 45⁩ 毫米，300 dpi |
| 头部，下巴到头顶 | 70.0% 到 80.0%（⁦31.5–36⁩ mm） |
| 眼睛高度，从底部量 | 50.0% 到 60.0%（⁦22.5–27⁩ mm） |
| 背景 | 纯浅灰 |
| 机读采集图 | 至少 ⁦413 x 531⁩ px，JPEG，没有写明文件大小的规定 |

[按这条规定制作照片](https://abox.tools/zh/id-photo/#icao) 打开证件照工具，并且已经选好这条规定。它在你的浏览器里运行：照片不会上传，不用注册，也没有水印。

## 这条规定还说了什么

- ⁦35 x 45⁩ 毫米这个画幅是世界上大部分地方签发证件所依照的，头部高度占七到八成、眼睛落在画面高度一半到五分之三之间，则是下面每一条规格都由此变化而来的几何。
- Doc 9303 还要求存下来的图里两眼中心之间至少 90 像素，从现在的手机照片里裁出 ⁦413 x 531⁩ 轻松就能达到。

## 这些数值从哪里来

转录自 International Civil Aviation Organization — Doc 9303, Machine Readable Travel Documents, Part 3。2026-08-20 核对。规定会变；上面的数字是拿去跟你面前那张表格对照的。

## 工具拿这些数值做什么

- 把裁剪框锁定成这种证件的形状，并在框里画出头部和眼线的区间，让你在自己的照片上直接看到规定，而不是只读到它。
- 通过测量画面找出头顶、下巴和两只瞳孔，不下载任何人脸模型，并用毫米告诉你，按这条规定头是偏大还是偏小。
- 读取背景的颜色，以及光线是否均匀；有问题的时候，说明是两者中的哪一个。
- 按精确的毫米写出打印文件，分辨率写在文件里；再生成一张带裁切标记的拼版，以及符合这条规定的像素和体积的上传文件。
