# 照片要求：美国护照和绿卡

U.S. Department of State 对这种证件的照片有什么要求，以 2026-09-17 读到的为准；以及一个不用把脸交给任何人、就能做出合格照片的办法。

最后更新 2026-09-17

## 具体数值

| 测量的项目 | 这条规定公布的数值 |
| --- | --- |
| 打印尺寸 | ⁦51 x 51⁩ 毫米，300 dpi |
| 头部，下巴到头顶 | 49.0% 到 68.6%（⁦25–35⁩ mm） |
| 眼睛高度，从底部量 | 54.9% 到 68.6%（⁦28–35⁩ mm）（参考） |
| 背景 | 白或米白 |
| 在线上传照片 | 至少 ⁦600 x 600⁩ px，JPEG，54.0 KB 到 10.00 MB |

[按这条规定制作照片](https://abox.tools/zh/id-photo/#us-passport) 打开证件照工具，并且已经选好这条规定。它在你的浏览器里运行：照片不会上传，不用注册，也没有水印。

## 这条规定还说了什么

- 正方形，而且是广泛使用的唯一一种正方形护照照片：⁦2 x 2⁩ 英寸，也就是 ⁦51 x 51⁩ 毫米。
- 头部可以落在 25 到 35 毫米之间的任何位置，比 ICAO 的规定宽松得多；眼睛的位置也是从下边缘量起，而不是按比例。
- 上传那条现在只管文件大小：54 KB 到 10 MB，JPEG、PNG 或 HEIC 都行。以前写的像素尺寸和 240 KB 上限都没了，眼线也没了——这里写出的正方形就是 300 dpi 下的 ⁦2 x 2⁩ 英寸打印尺寸，区间内更大的正方形一样可以。

## 这些数值从哪里来

转录自 U.S. Department of State — travel.state.gov, Passport Photos / Uploading a Digital Photo。2026-09-17 核对。规定会变；上面的数字是拿去跟你面前那张表格对照的。

## 工具拿这些数值做什么

- 把裁剪框锁定成这种证件的形状，并在框里画出头部和眼线的区间，让你在自己的照片上直接看到规定，而不是只读到它。
- 通过测量画面找出头顶、下巴和两只瞳孔，不下载任何人脸模型，并用毫米告诉你，按这条规定头是偏大还是偏小。
- 读取背景的颜色，以及光线是否均匀；有问题的时候，说明是两者中的哪一个。
- 按精确的毫米写出打印文件，分辨率写在文件里；再生成一张带裁切标记的拼版，以及符合这条规定的像素和体积的上传文件。
