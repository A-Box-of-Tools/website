# 照片要求：中国驾驶证

北京市公安局公安交通管理局 对这种证件的照片有什么要求，以 2026-09-21 读到的为准；以及一个不用把脸交给任何人、就能做出合格照片的办法。

## 具体数值

| 测量的项目 | 这条规定公布的数值 |
| --- | --- |
| 打印尺寸 | ⁦22 x 32⁩ 毫米，300 dpi |
| 头部，下巴到头顶 | 59.4% 到 68.8%（⁦19–22⁩ mm） |
| 眼睛高度，从底部量 | 50.0% 到 62.0%（⁦16–19.8⁩ mm）（参考） |
| 背景 | 纯白 |
| 上传规定 | 没有公布——这一条是给打印的 |

## 这条规定还说了什么

- 驾驶证用的“一英寸”照片是 ⁦22 x 32⁩ 毫米，比这份清单里照相馆的一寸要窄：头部长 19 到 22 毫米、宽 14 到 16 毫米，白色背景，彩色，六个月内拍摄，不穿制式服装。这是北京交管部门的数字；其他城市公布的也是这个尺寸。
- 没公布眼线。这里显示的区间，是头部居中时眼睛会落在的位置——是参考，不是要求，也从不标红。

## 这些数值从哪里来

转录自 北京市公安局公安交通管理局 — 驾驶人相片要求。2026-09-21 核对。规定会变；上面的数字是拿去跟你面前那张表格对照的。

## 工具拿这些数值做什么

- 把裁剪框锁定成这种证件的形状，并在框里画出头部和眼线的区间，让你在自己的照片上直接看到规定，而不是只读到它。
- 通过测量画面找出头顶、下巴和两只瞳孔，不下载任何人脸模型，并用毫米告诉你，按这条规定头是偏大还是偏小。
- 读取背景的颜色，以及光线是否均匀；有问题的时候，说明是两者中的哪一个。
- 按精确的毫米写出打印文件，分辨率写在文件里；再生成一张带裁切标记的拼版，以及符合这条规定的像素和体积的上传文件。
