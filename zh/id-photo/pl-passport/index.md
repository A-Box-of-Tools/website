# 照片要求：波兰护照和身份证

Ministerstwo Spraw Wewnętrznych i Administracji 对这种证件的照片有什么要求，以 2026-09-17 读到的为准；以及一个不用把脸交给任何人、就能做出合格照片的办法。

最后更新 2026-09-17

## 具体数值

| 测量的项目 | 这条规定公布的数值 |
| --- | --- |
| 打印尺寸 | ⁦35 x 45⁩ 毫米，300 dpi |
| 头部，下巴到头顶 | 68.9% 到 80.0%（⁦31–36⁩ mm） |
| 眼睛高度，从底部量 | 44.4% 到 66.7%（⁦20–30⁩ mm） |
| 背景 | 素白或浅灰 |
| 网上申请用照片 | 至少 ⁦492 x 633⁩ px，JPEG，最多 2.50 MB |

[按这条规定制作照片](https://abox.tools/zh/id-photo/#pl-passport) 打开证件照工具，并且已经选好这条规定。它在你的浏览器里运行：照片不会上传，不用注册，也没有水印。

## 这条规定还说了什么

- 这条规定量的是到头颇顶端的高度，不算头发。这里的标记点找的是头发的顶端，因为照片上有的就是头发；所以头发多的人量出来会偏高——往区间的下半段取。
- 波兰把眼线按距下边缘的毫米数公布出来，这么写的几乎没别家：20 到 30 毫米。它还写明，头发多的时候发型可以有一部分落在画面外，只要脸本身没因此变小。
- 身份证可以在网上申请，文件至少 ⁦492 x 633⁩ 像素、最大 2.5 MB，这里写出的上传文件就是它。护照不行，十二岁以下的孩子除外，那种要 ⁦768 x 1004⁩。

## 这些数值从哪里来

转录自 Ministerstwo Spraw Wewnętrznych i Administracji — Nowe zdjęcia do paszportu, instrukcja wykonywania zdjęć。2026-09-17 核对。规定会变；上面的数字是拿去跟你面前那张表格对照的。

## 工具拿这些数值做什么

- 把裁剪框锁定成这种证件的形状，并在框里画出头部和眼线的区间，让你在自己的照片上直接看到规定，而不是只读到它。
- 通过测量画面找出头顶、下巴和两只瞳孔，不下载任何人脸模型，并用毫米告诉你，按这条规定头是偏大还是偏小。
- 读取背景的颜色，以及光线是否均匀；有问题的时候，说明是两者中的哪一个。
- 按精确的毫米写出打印文件，分辨率写在文件里；再生成一张带裁切标记的拼版，以及符合这条规定的像素和体积的上传文件。
