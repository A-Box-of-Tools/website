## 具体数值

| 测量的项目 | 这条规定公布的数值 |
| --- | --- |
| 打印尺寸 | ⁦50 x 60⁩ 毫米，300 dpi |
| 头部，下巴到头顶 | 70.0% 到 80.0%（⁦42–48⁩ mm）（参考） |
| 眼睛高度，从底部量 | 50.0% 到 60.0%（⁦30–36⁩ mm）（参考） |
| 背景 | 纯白 |

## 这条规定还说了什么

- 不是 ⁦35 x 45⁩，而且机构自己就这么写：生物特征照片是 ⁦50 x 60⁩ 毫米，要提醒摄影师不要裁小。尺寸或背景不对，申请就办不完，或者证件在事后质检时被作废。
- 这一条没公布头高区间，所以这里放的是 ICAO 的数字，且从不当作不合格标红。按规定的文字描述取景，数字自然就对了。

转录自 Nüfus ve Vatandaşlık İşleri Genel Müdürlüğü — Biyometrik Fotoğraf Özellikleri。2026-09-19 核对。规定会变；上面的数字是拿去跟你面前那张表格对照的。

## 工具拿这些数值做什么

- 把裁剪框锁定成这种证件的形状，并在框里画出头部和眼线的区间，让你在自己的照片上直接看到规定，而不是只读到它。
- 通过测量画面找出头顶、下巴和两只瞳孔，不下载任何人脸模型，并用毫米告诉你，按这条规定头是偏大还是偏小。
- 读取背景的颜色，以及光线是否均匀；有问题的时候，说明是两者中的哪一个。
- 按精确的毫米写出打印文件，分辨率写在文件里；再生成一张带裁切标记的拼版，以及符合这条规定的像素和体积的上传文件。
