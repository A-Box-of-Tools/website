# 照片要求：韩国驾驶证

한국도로교통공단 对这种证件的照片有什么要求，以 2026-09-21 读到的为准；以及一个不用把脸交给任何人、就能做出合格照片的办法。

## 具体数值

| 测量的项目 | 这条规定公布的数值 |
| --- | --- |
| 打印尺寸 | ⁦35 x 45⁩ 毫米，300 dpi |
| 头部，下巴到头顶 | 71.1% 到 80.0%（⁦32–36⁩ mm） |
| 眼睛高度，从底部量 | 50.0% 到 60.0%（⁦22.5–27⁩ mm）（参考） |
| 背景 | 纯白 |
| 网上申请用照片 | 正好 ⁦413 x 531⁩ px，JPEG，最多 500.0 KB |

[按这条规定制作照片](https://abox.tools/zh/id-photo/#kr-driving-licence) 打开证件照工具，并且已经选好这条规定。它在你的浏览器里运行：照片不会上传，不用注册，也没有水印。

## 这条规定还说了什么

- 相纸跟护照一样，头顶到下巴 32 到 36 毫米，白色背景，只收印在相纸上的，不能露齿，不能修图。网上申请的规定精确得少见：JPG 最大 500 KB，要求 ⁦413 x 531⁩ 像素，超出 395 到 431 乘 507 到 550 的一概传不上去。
- 没公布眼线。这里显示的区间，是头部居中时眼睛会落在的位置——是参考，不是要求，也从不标红。

## 这些数值从哪里来

转录自 한국도로교통공단 — 안전운전 통합민원, 허용되는 사진 규격。2026-09-21 核对。规定会变；上面的数字是拿去跟你面前那张表格对照的。

## 工具拿这些数值做什么

- 把裁剪框锁定成这种证件的形状，并在框里画出头部和眼线的区间，让你在自己的照片上直接看到规定，而不是只读到它。
- 通过测量画面找出头顶、下巴和两只瞳孔，不下载任何人脸模型，并用毫米告诉你，按这条规定头是偏大还是偏小。
- 读取背景的颜色，以及光线是否均匀；有问题的时候，说明是两者中的哪一个。
- 按精确的毫米写出打印文件，分辨率写在文件里；再生成一张带裁切标记的拼版，以及符合这条规定的像素和体积的上传文件。
