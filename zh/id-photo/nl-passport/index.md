# 照片要求：荷兰护照、身份证和驾照

Rijksdienst voor Identiteitsgegevens 对这种证件的照片有什么要求，以 2026-09-17 读到的为准；以及一个不用把脸交给任何人、就能做出合格照片的办法。

最后更新 2026-09-17

## 具体数值

| 测量的项目 | 这条规定公布的数值 |
| --- | --- |
| 打印尺寸 | ⁦35 x 45⁩ 毫米，400 dpi |
| 头部，下巴到头顶 | 57.8% 到 66.7%（⁦26–30⁩ mm） |
| 眼睛高度，从底部量 | 50.0% 到 60.0%（⁦22.5–27⁩ mm）（参考） |
| 背景 | 白、浅灰或浅蓝 |
| 上传规定 | 没有公布——这一条是给打印的 |

[按这条规定制作照片](https://abox.tools/zh/id-photo/#nl-passport) 打开证件照工具，并且已经选好这条规定。它在你的浏览器里运行：照片不会上传，不用注册，也没有水印。

## 这条规定还说了什么

- 头高区间是 26 到 30 毫米，比听上去短：只占画面的 58% 到 67%，而 ICAO 要 70% 到 80%。按 ICAO 裁出来的图，对荷兰的申请来说太紧了——这一条就是拦这个的。
- 还有两个公布的数字只读不用：脸宽要 16 到 20 毫米（不算耳朵），11 岁以下的孩子头高可以低到 19 毫米。400 dpi 的下限，就是这一条比其他打得大的原因。
- 没公布眼线。这里显示的区间，是头部居中时眼睛会落在的位置——是参考，不是要求，也从不标红。

## 这些数值从哪里来

转录自 Rijksdienst voor Identiteitsgegevens — Fotomatrix 2020, photo specification guidelines。2026-09-17 核对。规定会变；上面的数字是拿去跟你面前那张表格对照的。

## 工具拿这些数值做什么

- 把裁剪框锁定成这种证件的形状，并在框里画出头部和眼线的区间，让你在自己的照片上直接看到规定，而不是只读到它。
- 通过测量画面找出头顶、下巴和两只瞳孔，不下载任何人脸模型，并用毫米告诉你，按这条规定头是偏大还是偏小。
- 读取背景的颜色，以及光线是否均匀；有问题的时候，说明是两者中的哪一个。
- 按精确的毫米写出打印文件，分辨率写在文件里；再生成一张带裁切标记的拼版，以及符合这条规定的像素和体积的上传文件。
