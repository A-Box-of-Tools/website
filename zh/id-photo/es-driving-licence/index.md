# 照片要求：西班牙驾驶证

Dirección General de Tráfico 对这种证件的照片有什么要求，以 2026-09-21 读到的为准；以及一个不用把脸交给任何人、就能做出合格照片的办法。

最后更新 2026-09-21

## 具体数值

| 测量的项目 | 这条规定公布的数值 |
| --- | --- |
| 打印尺寸 | ⁦26 x 32⁩ 毫米，300 dpi |
| 头部，下巴到头顶 | 70.0% 到 80.0%（⁦22.4–25.6⁩ mm）（参考） |
| 眼睛高度，从底部量 | 50.0% 到 60.0%（⁦16–19.2⁩ mm）（参考） |
| 背景 | 素净而浅——没公布颜色 |
| 上传规定 | 没有公布——这一条是给打印的 |

[按这条规定制作照片](https://abox.tools/zh/id-photo/#es-driving-licence) 打开证件照工具，并且已经选好这条规定。它在你的浏览器里运行：照片不会上传，不用注册，也没有水印。

## 这条规定还说了什么

- 跟 DNI 一样是小小的 ⁦32 x 26⁩ 毫米，彩色，纯色背景——DNI 要求白色，这一条只要求素净。自 2024 年 11 月 6 日起，交通总局手里已有照片的就不再要；在体检中心办换证的，由那里当场拍。这一条是给剩下的那些情形用的。
- 这一条没公布头高区间，所以这里放的是 ICAO 的数字，且从不当作不合格标红。按规定的文字描述取景，数字自然就对了。

## 这些数值从哪里来

转录自 Dirección General de Tráfico — sede.dgt.gob.es, Renovación de permiso próximo a caducar。2026-09-21 核对。规定会变；上面的数字是拿去跟你面前那张表格对照的。

## 工具拿这些数值做什么

- 把裁剪框锁定成这种证件的形状，并在框里画出头部和眼线的区间，让你在自己的照片上直接看到规定，而不是只读到它。
- 通过测量画面找出头顶、下巴和两只瞳孔，不下载任何人脸模型，并用毫米告诉你，按这条规定头是偏大还是偏小。
- 读取背景的颜色，以及光线是否均匀；有问题的时候，说明是两者中的哪一个。
- 按精确的毫米写出打印文件，分辨率写在文件里；再生成一张带裁切标记的拼版，以及符合这条规定的像素和体积的上传文件。
