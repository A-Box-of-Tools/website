# 照片要求：印度护照

Ministry of External Affairs 对这种证件的照片有什么要求，以 2026-08-20 读到的为准；以及一个不用把脸交给任何人、就能做出合格照片的办法。

最后更新 2026-08-20

## 具体数值

| 测量的项目 | 这条规定公布的数值 |
| --- | --- |
| 打印尺寸 | ⁦51 x 51⁩ 毫米，300 dpi |
| 头部，下巴到头顶 | 49.0% 到 68.6%（⁦25–35⁩ mm） |
| 眼睛高度，从底部量 | 54.9% 到 68.6%（⁦28–35⁩ mm） |
| 背景 | 纯白 |
| 上传规定 | 没有公布——这一条是给打印的 |

[按这条规定制作照片](https://abox.tools/zh/id-photo/#in-passport) 打开证件照工具，并且已经选好这条规定。它在你的浏览器里运行：照片不会上传，不用注册，也没有水印。

## 这条规定还说了什么

- Passport Seva 要求素净白背景上的 ⁦2 x 2⁩ 英寸照片，跟美国用的是同一个画幅。
- 大多数印度表格说的「护照尺寸」指的是 ⁦35 x 45⁩ 毫米的相纸，它在这份清单里另有一条——两者不能互换。

## 这些数值从哪里来

转录自 Ministry of External Affairs — Passport Seva, photo specifications。2026-08-20 核对。规定会变；上面的数字是拿去跟你面前那张表格对照的。

## 工具拿这些数值做什么

- 把裁剪框锁定成这种证件的形状，并在框里画出头部和眼线的区间，让你在自己的照片上直接看到规定，而不是只读到它。
- 通过测量画面找出头顶、下巴和两只瞳孔，不下载任何人脸模型，并用毫米告诉你，按这条规定头是偏大还是偏小。
- 读取背景的颜色，以及光线是否均匀；有问题的时候，说明是两者中的哪一个。
- 按精确的毫米写出打印文件，分辨率写在文件里；再生成一张带裁切标记的拼版，以及符合这条规定的像素和体积的上传文件。
