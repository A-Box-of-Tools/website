# 照片要求：加拿大持枪许可证（PAL）

Royal Canadian Mounted Police 对这种证件的照片有什么要求，以 2026-09-21 读到的为准；以及一个不用把脸交给任何人、就能做出合格照片的办法。

最后更新 2026-09-21

## 具体数值

| 测量的项目 | 这条规定公布的数值 |
| --- | --- |
| 打印尺寸 | ⁦45 x 57⁩ 毫米，300 dpi |
| 头部，下巴到头顶 | 52.6% 到 78.9%（⁦30–45⁩ mm） |
| 眼睛高度，从底部量 | 50.0% 到 68.0%（⁦28.5–38.8⁩ mm）（参考） |
| 背景 | 白色或素净的浅色 |
| 网上申请用照片 | 至少 ⁦531 x 673⁩ px，JPEG，200.0 KB 到 6.00 MB |

[按这条规定制作照片](https://abox.tools/zh/id-photo/#ca-firearms-licence) 打开证件照工具，并且已经选好这条规定。它在你的浏览器里运行：照片不会上传，不用注册，也没有水印。

## 这条规定还说了什么

- 自成一格的尺寸：⁦45 x 57⁩ 毫米，头高至少 30 毫米，没有公布上限——这里区间的上端是本工具定的。文件必须是 200 KB 到 6 MB 的 JPG。照片可以是一年以内的，也可以是黑白的；有色的处方镜片即使看得见眼睛也会被拒；首次申请时要由担保人在相纸背面签名。
- 没公布眼线。这里显示的区间，是头部居中时眼睛会落在的位置——是参考，不是要求，也从不标红。

## 这些数值从哪里来

转录自 Royal Canadian Mounted Police — Photo requirements for a firearms licence。2026-09-21 核对。规定会变；上面的数字是拿去跟你面前那张表格对照的。

## 工具拿这些数值做什么

- 把裁剪框锁定成这种证件的形状，并在框里画出头部和眼线的区间，让你在自己的照片上直接看到规定，而不是只读到它。
- 通过测量画面找出头顶、下巴和两只瞳孔，不下载任何人脸模型，并用毫米告诉你，按这条规定头是偏大还是偏小。
- 读取背景的颜色，以及光线是否均匀；有问题的时候，说明是两者中的哪一个。
- 按精确的毫米写出打印文件，分辨率写在文件里；再生成一张带裁切标记的拼版，以及符合这条规定的像素和体积的上传文件。
