# 照片要求：加拿大入籍

Immigration, Refugees and Citizenship Canada 对这种证件的照片有什么要求，以 2026-09-19 读到的为准；以及一个不用把脸交给任何人、就能做出合格照片的办法。

最后更新 2026-09-19

## 具体数值

| 测量的项目 | 这条规定公布的数值 |
| --- | --- |
| 打印尺寸 | ⁦50 x 70⁩ 毫米，300 dpi |
| 头部，下巴到头顶 | 44.3% 到 51.4%（⁦31–36⁩ mm） |
| 眼睛高度，从底部量 | 55.0% 到 72.0%（⁦38.5–50.4⁩ mm）（参考） |
| 背景 | 白色或素净的浅色 |
| 网上申请用照片 | 至少 ⁦420 x 588⁩ px，JPEG，最多 4.00 MB |

[按这条规定制作照片](https://abox.tools/zh/id-photo/#ca-citizenship) 打开证件照工具，并且已经选好这条规定。它在你的浏览器里运行：照片不会上传，不用注册，也没有水印。

## 这条规定还说了什么

- 用上传文件之前先读这一条。网上申请时，加拿大要的是“直接从相机保存、未经任何改动”的文件——而裁切就是改动，所以请用这里来核对摄影师给的文件，以及制作纸质相纸。它写的最低 ⁦420 x 540⁩ 像素，跟它自己 ⁦50 x 70⁩ 毫米的画幅不是一个形状；⁦420 x 588⁩ 才是，而且两个数字都满足。建议大小约 240 kB，上限 4 MB。
- 没公布眼线。这里显示的区间，是头部居中时眼睛会落在的位置——是参考，不是要求，也从不标红。

## 这些数值从哪里来

转录自 Immigration, Refugees and Citizenship Canada — canada.ca, Citizenship photo specifications。2026-09-19 核对。规定会变；上面的数字是拿去跟你面前那张表格对照的。

## 工具拿这些数值做什么

- 把裁剪框锁定成这种证件的形状，并在框里画出头部和眼线的区间，让你在自己的照片上直接看到规定，而不是只读到它。
- 通过测量画面找出头顶、下巴和两只瞳孔，不下载任何人脸模型，并用毫米告诉你，按这条规定头是偏大还是偏小。
- 读取背景的颜色，以及光线是否均匀；有问题的时候，说明是两者中的哪一个。
- 按精确的毫米写出打印文件，分辨率写在文件里；再生成一张带裁切标记的拼版，以及符合这条规定的像素和体积的上传文件。
