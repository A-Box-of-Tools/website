# 照片要求：香港护照（网上申请）

Immigration Department, HKSAR 对这种证件的照片有什么要求，以 2026-09-19 读到的为准；以及一个不用把脸交给任何人、就能做出合格照片的办法。

最后更新 2026-09-19

## 具体数值

| 测量的项目 | 这条规定公布的数值 |
| --- | --- |
| 打印尺寸 | 没有打印尺寸——这条规格是给网页表单的 |
| 头部，下巴到头顶 | 60.0% 到 75.0%（参考） |
| 眼睛高度，从底部量 | 50.0% 到 62.0%（参考） |
| 背景 | 纯白 |
| 网上申请用照片 | 至少 ⁦1200 x 1600⁩ px，JPEG，最多 5.00 MB |

[按这条规定制作照片](https://abox.tools/zh/id-photo/#hk-passport-online) 打开证件照工具，并且已经选好这条规定。它在你的浏览器里运行：照片不会上传，不用注册，也没有水印。

## 这条规定还说了什么

- 这不是把相纸换个分辨率。网上表单要至少 ⁦1200 x 1600⁩ 像素，是 3:4，而相纸是 4:5；JPEG，不超过 5 MB——所以它是单独一条规定，没有东西可打印。
- 这一条没公布头高区间，画幅也不是常见的那种，所以 ICAO 的数字套不上。这里显示的是根据规定的文字描述读出来的一个宽松区间；它只是参考，从不当作不合格标红。

## 这些数值从哪里来

转录自 Immigration Department, HKSAR — Photograph Requirements for Travel Document。2026-09-19 核对。规定会变；上面的数字是拿去跟你面前那张表格对照的。

## 工具拿这些数值做什么

- 把裁剪框锁定成这种证件的形状，并在框里画出头部和眼线的区间，让你在自己的照片上直接看到规定，而不是只读到它。
- 通过测量画面找出头顶、下巴和两只瞳孔，不下载任何人脸模型，并用毫米告诉你，按这条规定头是偏大还是偏小。
- 读取背景的颜色，以及光线是否均匀；有问题的时候，说明是两者中的哪一个。
- 按精确的毫米写出打印文件，分辨率写在文件里；再生成一张带裁切标记的拼版，以及符合这条规定的像素和体积的上传文件。
