# 照片要求：越南护照

Cục Quản lý xuất nhập cảnh, Bộ Công an 对这种证件的照片有什么要求，以 2026-09-19 读到的为准；以及一个不用把脸交给任何人、就能做出合格照片的办法。

最后更新 2026-09-19

## 具体数值

| 测量的项目 | 这条规定公布的数值 |
| --- | --- |
| 打印尺寸 | ⁦40 x 60⁩ 毫米，300 dpi |
| 头部，下巴到头顶 | 70.0% 到 80.0%（⁦42–48⁩ mm）（参考） |
| 眼睛高度，从底部量 | 50.0% 到 60.0%（⁦30–36⁩ mm）（参考） |
| 背景 | 纯白 |
| 上传规定 | 没有公布——这一条是给打印的 |

[按这条规定制作照片](https://abox.tools/zh/id-photo/#vn-passport) 打开证件照工具，并且已经选好这条规定。它在你的浏览器里运行：照片不会上传，不用注册，也没有水印。

## 这条规定还说了什么

- ⁦4 x 6⁩ 厘米的相纸——比例上比 ⁦35 x 45⁩ 更高，按别国裁的图放不进去——白底，不戴帽，不戴有色眼镜。要两张，而且规定写明应在出入境管理机关认可的照相馆拍。
- 这一条没公布头高区间，所以这里放的是 ICAO 的数字，且从不当作不合格标红。按规定的文字描述取景，数字自然就对了。

## 工具拿这些数值做什么

- 把裁剪框锁定成这种证件的形状，并在框里画出头部和眼线的区间，让你在自己的照片上直接看到规定，而不是只读到它。
- 通过测量画面找出头顶、下巴和两只瞳孔，不下载任何人脸模型，并用毫米告诉你，按这条规定头是偏大还是偏小。
- 读取背景的颜色，以及光线是否均匀；有问题的时候，说明是两者中的哪一个。
- 按精确的毫米写出打印文件，分辨率写在文件里；再生成一张带裁切标记的拼版，以及符合这条规定的像素和体积的上传文件。
