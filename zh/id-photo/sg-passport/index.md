# 照片要求：新加坡护照和身份证

Immigration & Checkpoints Authority 对这种证件的照片有什么要求，以 2026-09-17 读到的为准；以及一个不用把脸交给任何人、就能做出合格照片的办法。

最后更新 2026-09-17

## 具体数值

| 测量的项目 | 这条规定公布的数值 |
| --- | --- |
| 打印尺寸 | ⁦35 x 45⁩ 毫米，300 dpi |
| 头部，下巴到头顶 | 70.0% 到 80.0%（⁦31.5–36⁩ mm）（参考） |
| 眼睛高度，从底部量 | 50.0% 到 60.0%（⁦22.5–27⁩ mm）（参考） |
| 背景 | 纯白 |
| 网上申请用照片 | 正好 ⁦400 x 514⁩ px，JPEG，最多 8.00 MB |

[按这条规定制作照片](https://abox.tools/zh/id-photo/#sg-passport) 打开证件照工具，并且已经选好这条规定。它在你的浏览器里运行：照片不会上传，不用注册，也没有水印。

## 这条规定还说了什么

- 新加坡公布的是上传那一项：⁦400 x 514⁩ 像素，最大 8 MB，白底，而且要求三个月内拍的——不是通常的六个月。毫米数哪里都没写；⁦400 x 514⁩ 正好是 ⁦35 x 45⁩ 的比例，这个打印尺寸就是这么来的。
- 这一条没公布头高区间，所以这里放的是 ICAO 的数字，且从不当作不合格标红。按规定的文字描述取景，数字自然就对了。

## 这些数值从哪里来

转录自 Immigration & Checkpoints Authority — ica.gov.sg, Photo Guidelines。2026-09-17 核对。规定会变；上面的数字是拿去跟你面前那张表格对照的。

## 工具拿这些数值做什么

- 把裁剪框锁定成这种证件的形状，并在框里画出头部和眼线的区间，让你在自己的照片上直接看到规定，而不是只读到它。
- 通过测量画面找出头顶、下巴和两只瞳孔，不下载任何人脸模型，并用毫米告诉你，按这条规定头是偏大还是偏小。
- 读取背景的颜色，以及光线是否均匀；有问题的时候，说明是两者中的哪一个。
- 按精确的毫米写出打印文件，分辨率写在文件里；再生成一张带裁切标记的拼版，以及符合这条规定的像素和体积的上传文件。
