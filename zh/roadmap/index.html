接下来做什么

下面两份清单上的每一项，都得在你的浏览器里干活，都得不上传东西。过不了这一关，名字根本上不了榜。两个数字没写死在任何地方，是构建脚本从清单上数出来的。

17 项计划中 · 38 项已完成

这份清单是怎么定出来的

这不是许愿单。做法是把网上最大那家 GIF 和视频站点的工具列表从头到尾过一遍，那份列表大概是现存最接近“人们到底想拿文件做什么”的一份目录，然后只留下那些能做到在你自己机器上完成、拔了网线也照干的条目。

留下来的绝大多数，靠浏览器本来就带的接口就够了。少数几个得把编解码器打包进唯一用到它的那个工具里，这也算过关，文件照样不出这台机器。达不到这条线的宁可不写，所以下面几个看着很明显的空缺，是故意空着的。

已经做出来的排在各自分组最前面，标着已完成，点进去就是它自己的页面。下面的都还没做，做出来之前不会变成链接。

每一类文件，以及能拿它做什么

都还没做。列在这儿，好让你看清这个站要往哪儿走。

图片

  • 图片压缩 — 说个大小，剩下的它来算。 已完成
  • 图片缩放 — 说个尺寸，拉个框，挑个格式。 已完成
  • HEIC 转 JPG — iPhone 拍的照片，换成什么都打得开的格式。 已完成
  • 证件照制作 — 选好国家，它就照那个国家的规定，一字不差地办。 已完成
  • 图片堆栈 — 二十张变一张，不用传二十次，也不用 RAW 转换器。 已完成
  • 图片涂黑与打码 — 你遮住的那块是从文件里删掉的，不是藏在文件里。 已完成
  • EXIF 查看与清除 — 看看一张照片把你交代了多少，然后删掉。 已完成
  • DICOM 阅片器 — CT、MR、X 光和超声，连窗宽窗位、头信息和测量一起。 已完成
  • 图片转 ICO — 进去一张图，出来的是浏览器、Windows 和 Mac 各自要的每一个尺寸。 已完成
  • 图片转 Data URI — 整张图变成一行文本，直接粘进 CSS 或者 HTML。 已完成
  • SVG 转图片 — 说个尺寸。矢量图本来就没有尺寸可丢。 已完成
  • 加文字 — 压在画面上，或者放进画面上方的文字条里
  • AVIF — 只有一个浏览器写得出来、其余只能读的格式
  • DICOM 去标识 — 把病人的信息从影像里拿掉，影像本身一动不动

GIF 与动图

  • 视频转 GIF — 挑好段落、尺寸和帧率。 已完成
  • GIF 制作 — 把一组图片变成一段动画。 已完成
  • GIF 拆帧 — 每一帧都单独存成一张 PNG。 已完成
  • GIF 分析 — 帧、延时、调色板，以及每个字节的去向。 已完成
  • GIF 转 MP4 或 WebM — 同一段动画，通常只有原来的十分之一大
  • 编辑 GIF — 缩放、裁剪、旋转、倒放，或者改播放速度
  • 动态 WebP — 还是那段动画，体积只剩零头——也是这里唯一需要自带编码器的一个

视频

  • 图片转视频 — 一个文件夹的图片，变成一段视频。 已完成
  • 视频剪切 — 一边看一边标出要留的段落，最后拿回一个视频。 已完成
  • 视频裁剪 — 把片子切到只剩要紧的那块。 已完成
  • 视频倒放 — 最后一帧排在最前，连声音一起。 已完成
  • 延时视频 — 一小时的素材，二十秒看完。 已完成
  • 视频截帧 — 任意位置，一张原画质静帧。 已完成
  • 缩放 — 压到一个真的发得出去的尺寸
  • 旋转 — 给那些拍横了的片段——而且一帧都不用解码
  • 把视频静音 — 只去掉声音，画面原封不动
  • 转成 MP4 — 不管从相机里出来的是什么，都变成传得上去的那种文件
  • 压制字幕 — 把一个 SRT 文件画进画面里
  • 字幕转换 — SRT、VTT、ASS、SBV、LRC 互转，时间轴也能整体挪

音频

  • 音频剪辑 — 边听边标出值得留的段落。它们会合成一个文件回来，就切在你说的位置。 已完成
  • 音频编辑 — 倒着放、快慢随你调、把录轻了的声音提上来，全在你这台机器上。 已完成
  • 格式转换 — MP3、WAV 和 Opus，转哪个方向都行

文档与 PDF

  • PDF 合并与拆分 — 挪动页面，不用往服务器跑一趟。 已完成
  • PDF 压缩 — 文档变小，不用送去任何地方。 已完成
  • PDF 涂黑 — 字从文件里删掉，然后再搜一遍这个文件来证明。 已完成
  • 图片转 PDF — 把你的图片装进一个文档。 已完成
  • 文档扫描 — 把纸拍下来，回来的是一份看着像扫描的东西。 已完成
  • 旋转与裁剪页面 — 把扫横了的件扶正，或者切掉页边
  • 提取图片 — 把文档里的图片重新取出来

媒体之外

  • JSON 格式化 — JSON、XML、HTML、CSS 和 YAML，格式化或转换。没有一个字被贴进别人的服务器。 已完成
  • YAML to JSON Converter — Both directions, and it says what each one costs. Nothing is pasted into anyone else's server. 已完成
  • XML Formatter — XML laid out to read or squeezed to ship, and converted to JSON both ways. Nothing is pasted into anyone else's server. 已完成
  • 文本比对 — 两段文本进来，每处差异都被标出来，逐行、逐词。没有一个字被贴进别人的服务器。 已完成
  • Base64 编码解码 — Base64、百分号编码、HTML 实体、十六进制和反斜杠转义，双向都行。没有一个字被贴进别人的服务器。 已完成
  • 文本与文件分享 — 分享只活在这个打开的标签页里。读的人从你的浏览器直接取走加密内容，关掉标签页就结束——任何服务器上都不留一点东西。 已完成
  • 二维码与条形码生成 — 打进去，就变成一个码。生成过程不往外送任何东西。 已完成
  • 二维码与条形码识读 — 把摄像头对准码，或者把拍下来的图丢进来。读这件事只发生在这里，别处都没有。 已完成
  • 哈希与校验和 — 把下载来的文件和发布方公布的那串数字对一下，不用把它发给任何人。 已完成
  • 密码与密码短语生成器 — 在这里生成，由你自己的浏览器生成，不发往任何地方。什么都不保存，也没有历史记录。 已完成
  • CSV 与 JSON — 两个方向都能转，顺手把表格导出的东西理干净
  • 证书与密钥 — 读一份证书或签名请求，不用把它贴进别人的服务器
