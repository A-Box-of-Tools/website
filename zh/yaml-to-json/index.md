# YAML 转 JSON — JSON 也能转回 YAML

两个方向都有，而且会告诉你各自的代价。这些都不会粘进别人的服务器。

> 在你的浏览器里把 YAML 转成 JSON、把 JSON 转成 YAML。它读的是 YAML 1.2，所以 yes 和 no 还是字符串，而且会明确说出每个方向丢了什么。什么都不上传：一份配置文件永远不会离开你的设备。

本页是一个完全在你的浏览器里运行的交互式工具，地址是 https://abox.tools/zh/yaml-to-json/。你交给它的任何内容都不会被上传。下面是这个页面用文字对该工具的全部说明；要使用它，请打开这个地址。

## 你的 YAML 和 JSON **不会上传**。这里根本没有服务器。

转换是对一段字符串做算术，就在这里，在这个页面上。两个解析器都是手写的，都在 `src/` 里——`shared/parse-yaml.js` 和 `shared/parse-json.js`——除此之外再没有别的。这个工具压根就没有网络功能，没有要取的，也没有要发的。这一点在这里比本站几乎任何地方都更要紧：一份 YAML 文件多半是部署配置，而部署配置多半塞满了主机名、桶名和密钥。

## 不上传就把 YAML 转成 JSON 的步骤

1. **选方向。** *YAML 转 JSON* 或者 *JSON 转 YAML*。菜单下面那行小字会在你粘任何东西之前，而不是之后，告诉你这个方向会丢什么。
2. **粘进来，或者把文件放上去。** 能选中能复制的都行。把文件放到选择框上，你自己的浏览器会读它并填进输入框——这里没有上传这一步可以省略——而 `.json` 或 `.yaml` 的后缀顺便就把方向定好了。
3. **选缩进。** 两个空格、四个空格，或者一个制表符。制表符只对 JSON 提供：YAML 是按空格定义的，制表符在它里面不是合法缩进。
4. **在出错的地方读错误。** 在这里失败的解析器会告诉你它遇到了什么，在第几行第几列，而不是“位置 4193 处有意外的 token”。通常这就够你修好一份配置文件，不用再打开别的东西。
5. **把结果拿走。** 复制，或者下载成文件，文件名按它出来的格式取。

## 常见问题

### 我的 YAML 会被上传到什么地方吗？

不会。这个页面上的两个解析器和两个打印器，都是在你自己的浏览器里、你自己的硬件上跑的函数。这个工具压根就没有网络功能，从不取任何东西，也从不发任何东西，页面的 `Content-Security-Policy` 里写着它允许联系的每一个地址，没有一个属于本站。这正是拿它处理部署配置的理由：那种文件里塞满主机名、桶名，偶尔还有某人打算挪走的密钥，把它粘进别人的转换器，就是把它给了对方。

### 把 YAML 转成 JSON 会丢什么？

注释，因为 JSON 没地方放。锚点、别名和标签会被直接拒绝，而不是靠猜——它们各自说的事情 JSON 都说不出来，一个悄悄挑了种解释的转换器，会交给你一份并不是文件原意的文档。反方向不丢任何东西：每一份 JSON 文档本来就已经是 YAML 文档。

### 我的 YAML 里写的是 no，JSON 出来却是字符串。为什么？

因为它本来就是字符串，而这里读的是 YAML 1.2，不是 1.1。在 YAML 1.1 里，`yes`、`no`、`on` 和 `off` 都是布尔值，这就是那个著名的坑：挪威的国家代码会变成 `false`。YAML 1.2 把这条丢掉了，这里也一样：只有 `true`、`false`、`null` 和 `~` 会被当成文本之外的东西读。反过来的时候，这些词会*带引号*写回去——哪怕这里不带引号也照样当文本读——因为下一个打开这份文件的东西未必如此。PyYAML 到现在默认还是 1.1。严格地读、保守地写，是两边都对的唯一组合。

### 它会保持我的键顺序吗？

会，两个方向都会，而这比听上去难。建立在 `JSON.parse` 上的转换器会悄悄把看着像整数的键挪到前面，于是 `{"10":a,"2":b}` 回来就成了 `{"2":b,"10":a}`。数字保留你打的每一位，所以一个二十位的账号不会因为双精度浮点丢掉最后三位。如果你*就是想*排序，有个勾选框，而且它按键读起来的样子排，不是按码位。

### 能一次转换好几份 YAML 文档吗？

不能，而且它会直说，而不是替你挑一份。带 `---` 分隔符的文件装着不止一份文档，而 JSON 没有哪种形状表示“好几份文档”——用数组的话，就成了这份文件从没做过的断言。一份一份转。

### 这里为什么没有 YAML 格式化？

因为 YAML 没有值得一写的压缩形式——短的那种是流式风格，读不了，而读不了正是把文件留成 YAML 这件事的反面。排开 JSON、XML、HTML 和 CSS 是 [JSON 格式化](https://abox.tools/zh/json-formatter/)的活儿，而且它也排 YAML。

### 文件最大能有多大？

这里没有设限，因为没有服务器在为此付钱。真正的上限是你自己的设备：几兆字节的 YAML 没问题，文档很长的时候，页面会等你打字停下来再转换，而不是跟你抢键盘。

### 免费吗？需要注册吗？

免费，没有账号，不用登录，没有试用期，也不限制你粘多少。本站有广告，站点靠它维持；广告拿不到关于你文本的任何东西。

### 断网还能用吗？

能。页面加载一次之后拔掉网线，它照样工作。这也是证明没有上传的最简单办法：一个把你的配置送出去转换的工具，在你拔线的那一刻就停了。

## 这条隐私承诺怎么核实

- **你粘进来的东西没有出去的路。** Content-Security-Policy 里写着这个页面允许联系的每一个地址，没有一个属于本站。这里没有任何可以收走一份粘进来的配置的接收端，就算有，代码里也没有把它送过去的东西。
- **这里不会去取任何东西。** `src/` 里哪儿都没有 `fetch`，没有 `XMLHttpRequest`，也没有 `sendBeacon`。两个解析器和两个打印器都是这个页面里的函数：进去一段字符串，出来一段字符串。
- **它读的是 YAML 1.2，所以挪威还是挪威。** 在 YAML 1.1 里，`no` 是个布尔值，这就是那个著名的坑：挪威的国家代码会变成 `false`。这里读的是 1.2，在那里它就是它看上去的那个字符串。反过来的时候，这些词会*带引号*写回去，因为下一个打开这份文件的东西可能还是个 1.1 的读取器。`tests/js/text-convert.test.js` 两头都查。
- **没法诚实的转换，宁可停下来。** YAML 里的锚点、别名或者标签，会带着“它在第几行”的提示结束这次转换，而不是给你一份悄悄变了意思的 JSON 文档。JSON 没有办法表达“同一个节点用两次”，而挑一种解释，就是替你做主。
- **Google 加载了什么，又没拿到什么。** 广告和统计脚本来自 Google，捐赠按钮来自 Buy Me a Coffee。它们谁也没拿到你文本里的一个字符。读它、解析它、写它的每一行代码，都从这个源提供，也都列在仓库里。
- **断网可用。** 拔掉网线，这个工具一点变化都没有，因为它里面本来就没有联网这一步。这是最简单的证明。

**你可以自己核对。**上面这些不用你信。这个页面是仓库里的模板和配置生成出来的，构建脚本你能读，也能自己跑一遍，跑出来的结果就提交在 `dist` 分支上。拿实际发给你的内容，跟你自己从源码构建出来的结果对一遍就知道了： https://github.com/A-Box-of-Tools/website

最值得先读的几个文件：`config/site.toml` 里是 Content-Security-Policy，宁可拒绝一个锚点也不去猜它想说什么的读取器在 `src/shared/parse-yaml.js`；一次转换为什么就是一个解析器加一个打印器、中间没有任何同时认得两种格式的东西，在 `src/convert.js`。
