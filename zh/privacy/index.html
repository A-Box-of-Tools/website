# 隐私与 Cookie

文件在本地处理。主动分享和可选联网功能有各自的边界。本页说明这些边界，以及周围的广告、使用统计、可选反馈、存储和托管。

最后更新 2026年10月25日

## 你的文件

你选来处理的文件，在设备上的浏览器里读取、编辑和写出。abox.tools 没有接收文件做处理的上传端点，也没有这些文件的数据库。下载内容在本地组装。分享、远程摄像头观看，以及把收据报告交给其他应用，都是主动的传送，下面会说明。

本地处理不会把以下内容交给我们：

- 你的文件和预览
- 文件名、大小、尺寸或格式
- 文件内容，包括 EXIF、GPS 和识别出的文档文字

每页的 `Content-Security-Policy` 限制允许加载的资源和连接目的地。有些工具会加入引见服务器或可选汇率 API。策略不检查送给已允许主机的数据，`connect-src` 也不描述 WebRTC 对等连接的流量。应结合源码观察正在使用的功能，不能把主机列表当成所有载荷的证明。

你用工具做出来的文件，交给的是你浏览器自己的下载机制，你让它存哪儿它就存哪儿。这一步我们同样不参与。

## 主动使用连接的功能

[图片转视频](https://abox.tools/zh/images-to-video/)可以获取你提供的网址图片。那台服务器会收到你的 IP 地址和完整请求 URL，包括查询参数。图片到达后存入本地内存，并重新编码用于处理。这条请求不会发送你从设备上选的文件。

[收据与发票提取](https://abox.tools/zh/receipt-invoice-extractor/)在本地读取照片和识别文字。可选的历史汇率按钮会向 [Frankfurter](https://frankfurter.dev/) 请求货币对和你选的日期。这个日期可能就是收据上印的日期。对方看到你的 IP 地址和请求；请求不带凭据和来源页，也不含照片、文件名、商家、金额或邮箱。手动汇率无须请求。

收据的邮件和分享按钮先在本地准备报告和 JPEG 副本，再下载邮件文件或交给你选择的设备应用。本页不发送邮件；你选择的应用、服务商和收件人按各自政策处理下一步。[文本与文件分享](https://abox.tools/zh/share-text/)、[分享浏览器标签页](https://abox.tools/zh/share-tab/)和[远程摄像头](https://abox.tools/zh/remote-camera/)会主动把内容传给另一浏览器，连接元数据在下面说明。

### 供代理使用的公开工具目录（MCP 和 A2A）

MCP 和 A2A 客户端会把可公开的任务或格式关键词、目录语言和结果数量上限发送到 `mcp.abox.tools` 上的 Cloudflare Worker。目录服务返回公开的工具说明和链接。服务不接收文件，没有上传端点，也不要求账号。不要发送私密关键词、文件名、文件内容或密码。

已加载的交互式目录在本地筛选，不会再向目录服务发出请求。打开所选结果时，会请宿主打开对应工具的网站；文件选择和处理在运行那个网站的浏览器中完成。代理或应用的宿主服务商按自己的政策处理你的请求和对话记录。本服务会接收宿主在目录请求中发送的内容，但不会要求提供或主动获取宿主的对话记录。

应用程序不记录查询或请求正文日志，没有数据库，也不保存持久任务。Worker 的可观测性功能已关闭。Cloudflare 仍会为了托管、安全和请求频率控制而处理 IP 地址、时间和请求元数据。这些由服务商管理的元数据按 Cloudflare 的规定保存；我们尚未核实本服务的固定保存期限。不使用远程目录，仍可使用普通网站和本地文件处理功能。

## 什么被收集了，谁收集的

本站免费，靠广告养着。这意味着这些页面上跑着两个 Google 的产品，大部分页面上还跑着一个捐助按钮。清单如下，就这么多。

### Google AdSense，广告

广告由 Google 投放，看到哪些也由它决定。为此它可能在你的浏览器里设置和读取 Cookie 或者类似的标识，并拿到你的 IP 地址、由此推出的大致位置、你的 user agent，以及你当时在哪个页面上。视你的设置和所在地区而定，广告可能会用 Google 手里关于你的画像做个性化，而那份画像主要是从你在别的网站上的活动攒起来的。

这些我们一样都收不到，也看不见，而且我们从不给 Google 任何关于你文件的信息。Google 自己对“它如何使用来自投放其广告的网站的数据”的说明在 [policies.google.com/technologies/partner-sites](https://policies.google.com/technologies/partner-sites)。

### Google Analytics，访问与工具使用统计

我们用 Google Analytics 4 统计页面访问和成功的工具使用，好知道哪些工具值得继续做。它记录你看了哪个页面、大约什么时候、一个随机生成并存在浏览器里的标识、大致位置、设备和浏览器类型，以及常见的推广来源标签。

发给 Analytics 的页面地址使用规范网址，只保留常见的推广来源标签，省去其他查询参数和地址片段。页面标题是固定的；来源网站只保留源站地址，不含路径或查询参数。

每次加载页面，只统计首次成功的工具使用，例如请求已准备好的下载、完成复制，或在查看工具中显示可用的分析或查看结果。这个事件添加的工具专属信息只有固定的工具标识，不代表操作系统已经保存下载文件。

我们也统计工具页的打开次数。在图片转视频、图片堆栈、GIF 分析和 GIF 拆帧中，固定事件记录提供输入、开始处理、结果就绪、出现问题或取消操作；每次页面加载中，每个阶段最多统计一次，内置示例不计入这些阶段。部分后续操作链接只报告来源页和目标页的固定标识，不发送链接地址或文字。这些计数用于了解访问停在哪一步，不识别单次任务，也不证明用户已到达下一页。

可选反馈在你选定回答后，记录固定的工具标识、固定的赞或踩和固定原因，没有自由文字输入。工具不会在这两类记录中附带文件、文件名、内容、输入文字、数量、大小、尺寸、格式、设置、错误信息或其他输入输出详情。我们能查看汇总的 Analytics 报告。屏蔽 Analytics 不影响本地处理；工具缓存就绪后，离线也能使用。

### Buy Me a Coffee，捐助按钮

首页和各个工具页上带着一个捐助按钮，它从 Buy Me a Coffee 的服务器加载。加载它意味着他们的 CDN 会看到你的 IP 地址，以及你当时在本站；按钮上的字体取自 Google Fonts，那边同样会看到你的 IP 地址。除此之外什么都不发，而且你不真去点它，后面什么都不会发生；点了，你就在他们的站上，按他们的政策来。这一页和[条款页](https://abox.tools/zh/terms/)不画这个按钮。

### 托管

本站由 GitHub Pages 提供，前面挡着 Cloudflare。跟任何网站主机一样，他们要处理你浏览器发出的那些请求，其中包括你的 IP 地址、请求的页面和你的 user agent，为的是把页面送到你手上，以及让服务保持可用和安全。他们两家逐访客的日志，我们都拿不到。

### 配对工具的连接方式

五种配对工具默认使用 Direct。主机可以在开始前选择 Cloud relay，邀请会携带这个选择，另一方在连接前查看并确认。Direct 不会自动切换到中继。Cloudflare TURN 转发加密的文字、文件、视频、音频和控制消息，不持有解密密钥，但能看到地址、时间和流量。双方需要全程联网。临时中继凭据保留在浏览器内存中，通过引见服务更新，不会公开在邀请或附近列表中。列表可以显示主机选择的连接方式。批准、密码和麦克风控制仍然有效。

全部五种工具都能列出本地网络或私密群组中的可用连接。不同网络的设备可以使用同一个随机生成的群组代码来发现会话。每种工具有独立列表，群组会话不会同时公开到本地网络列表。代码只允许发现，不代表获准访问；密码、主机批准和所选连接路径仍然有效。引见服务通过加密连接接收代码以验证群组成员资格，之后只在打开的连接中保留派生标识和验证结果。请求网址及其保留七天的元数据日志包含该标识，不包含代码。页面只在内存中保留代码，不将其写入邀请或连接报告，重新加载后即忘记。页面上的普通脚本可以读取输入字段；私密群组不会将这些脚本隔离。任何知道代码的人都能发现向群组公开的会话，因此只应将代码分享给预期的人。

### 分享浏览器标签页

[分享浏览器标签页](https://abox.tools/zh/share-tab/)通过桌面浏览器自己的选择器捕获一个标签页，把实时视频传给一位获准观看者。观看者请求访问、主持人批准、观看者确认后，才发送视频。它不捕获声音、摄像头或麦克风。所选标签页中可见的信息会被分享；观看者可以录制收到的画面。

在线附近发现默认关闭。主持人可以在开始前启用 Show in nearby shared tabs；观看者主动选择 Find nearby tabs 才会打开列表。发现连接只列出随机邀请码，绝不包含所捕获标签页的标题、地址、画面或观看者留言。选择条目旁的 Join 会按所示方式发出请求。没有有效批准凭据时，仍需主机批准。复制的邀请链接仍会等待 Request to watch 操作。服务根据公网 IPv4 地址或 IPv6 /64 子网以及网站来源对本工具的页面分组，不按实际位置判断。共享网关或 VPN 可能让陌生人出现在同一组，也可能隐藏身边的设备。列表仅存在于打开的连接中，不保存历史，停止后会撤下主持人的条目。

在 Direct 方式下，视频在可互通的本地网络上使用加密直连，不使用公共 STUN 或 TURN。两台设备都需要互联网连接来发现和配对。引见服务器看到房间代码、IP 地址、时间、WebRTC 描述和连接候选，不接收视频、观看者留言或批准决定。Cloudflare 保留连接元数据日志七天。

页面的常规脚本能读取页面地址和状态，包括邀请代码；只有链接并不能获得视频访问权。观看者不能控制主机或选择网页文字。工具没有录制功能，但已登录内容只要出现在画面中就会被分享，观看者也能自行截图或录制。工具页说明网络限制；本地地址设置不能证明物理网络边界。

### 远程摄像头和浏览器引见

[远程摄像头](https://abox.tools/zh/remote-camera/)会在页面加载时打开用于发现摄像头的 WebSocket 连接。启动摄像头或点击连接时，还会与我们的连接协调服务建立房间连接。选择摄像头旁的 Join 会按所示方式请求连接并交换网络地址。打开观看链接时，页面仍会等待点击连接。默认需要摄像头端批准观看；这项设置控制视频和音频传输，不控制网络地址交换。引见服务器能看到代码、地址、时间和连接设置消息，看不到视频、音频或观看者备注。在 Direct 方式下，视频和已启用的音频走浏览器间加密直连，没有配置 STUN 或 TURN，也没有录制功能。音频默认关闭，只有主机选择分享音频后才会请求麦克风访问权限。引见仍需互联网。VPN 和系统策略可能影响路由，本地模式不证明物理网络边界。工具页说明这些限制，以及页面脚本如何读到完整观看链接。

可选的观看者提醒在观看设备上分析小尺寸视频帧和接收到的音频，不录制，也不上传。启用提醒会请求浏览器通知权限。浏览器和操作系统显示的通用活动通知不包含摄像头图像、音频、链接名称或观看者备注。断开连接会停止分析并关闭本次会话的通知。观看页面必须保持打开；浏览器可能在后台或设备休眠时暂停分析。

### 文本与文件分享及引见服务器

[文本与文件分享](https://abox.tools/zh/share-text/)首页打开发现连接，开始分享再打开一条连接。名称按公网 IPv4 地址或 IPv6 子网和页面来源分组；这只是发现线索，不证明同一物理网络。引见服务器看到名称、IP、连接时间和协商消息，不接收分享文字或文件。公开名称只存在于打开的连接里，没有持久存储。普通 Direct 使用 Google 和 Cloudflare 的公共 STUN，这些服务会看到请求来源地址。本地网络将 Direct 限制为主机地址，不使用 STUN 或 TURN。Cloud relay 是独立选择，由主机在分享前选定，并由读者在连接前确认。所有方式都需要公网引见服务器来建立连接。Cloudflare 保留分享和摄像头引见的连接元数据日志七天；这些是我们可读的逐访客服务日志。收件人已复制或下载的内容，不会随着来源标签关闭而消失。

## Cookie

我们不设置登录或会话 Cookie。Google 脚本可能设置上面说明的 Cookie 和标识。本站也使用浏览器本地存储来记住偏好和临时工作。

**配对批准。**五个配对工具会在浏览器本地存储随机重连凭据，仅保留有限数量的近期工具、房间和连接方式组合。凭据不含分享内容、姓名或 IP 地址。文本分享、标签页分享和远程摄像头只通过浏览器间的加密连接出示批准凭据；语音工具在加入时向引见服务发送个人密钥。批准仅在当前主机会话内有效：断开连接会保留批准，主机移除会撤销批准，结束或开始新会话会重置批准。清除或禁止存储可能需要重新批准。同一网站来源下任意页面运行的脚本，包括第三方脚本，都能读取这些凭据。它们不与页面脚本隔离，也不会放进邀请或发现列表。

**你选的语言。**你在切换器里挑了一种语言，这个选择会写进你浏览器的本地存储，名字叫 `abox-lang`，好让你打开的下一个页面就是你要的那种语言。它不是 Cookie：它从不发给我们，也不发给别的任何人，就待在你读这段话的这台设备上，清掉浏览器的站点数据它就没了。你要是从来没挑过语言，那就什么都不会写，一个按你浏览器语言显示的页面，是当场匹配、随后即忘的。

**其他本地存储。**反馈会记住回答或关闭的时间，避免再问。工具可能在本地保留设置或可选的分享草稿。切换语言或主动接续到另一工具时，可以把文件和设置临时存在 IndexedDB，供另一个本地页面取走。这些记录不是 Cookie，不发给我们；清理站点数据会删除它们。持久草稿由相关工具说明。

Google 的 Cookie 和标识用于统计访问和工具使用，以及选择广告和限制展示次数，与上面说明的本站本地记录不同。

### 怎么把它关掉

- 广告个性化可以一次对所有网站关掉，在 [My Ad Center](https://myadcenter.google.com/)。
- Google Analytics 可以用 Google 自己的[停用浏览器插件](https://tools.google.com/dlpage/gaoptout)在所有站点上拦掉。
- 你浏览器自己的设置能拦掉或者清掉第三方 Cookie，而任何内容拦截器都能让这些脚本从一开始就加载不了。

拦住广告、Analytics 和捐助按钮，不影响本地处理。工具的离线缓存就绪后，断网也能做本地处理。网址图片导入、在线汇率、浏览器引见和其他应用的发送，需要各自的连接。没有处理功能被扣在广告后面。

图片转视频可以获取你提供的网址图片。那台服务器会收到你的 IP 地址和完整请求 URL，包括查询参数。图片到达后存入本地内存，并重新编码用于处理。这条请求不会发送你从设备上选的文件。

收据与发票提取在本地读取照片和识别文字。可选的历史汇率按钮会向 Frankfurter 请求货币对和你选的日期。这个日期可能就是收据上印的日期。对方看到你的 IP 地址和请求；请求不带凭据和来源页，也不含照片、文件名、商家、金额或邮箱。手动汇率无须请求。

收据的邮件和分享按钮先在本地准备报告和 JPEG 副本，再下载邮件文件或交给你选择的设备应用。本页不发送邮件；你选择的应用、服务商和收件人按各自政策处理下一步。文本与文件分享、分享浏览器标签页和远程摄像头会主动把内容传给另一浏览器，连接元数据在下面说明。

供代理使用的公开工具目录（MCP 和 A2A）

MCP 和 A2A 客户端会把可公开的任务或格式关键词、目录语言和结果数量上限发送到 mcp.abox.tools 上的 Cloudflare Worker。目录服务返回公开的工具说明和链接。服务不接收文件，没有上传端点，也不要求账号。不要发送私密关键词、文件名、文件内容或密码。

已加载的交互式目录在本地筛选，不会再向目录服务发出请求。打开所选结果时，会请宿主打开对应工具的网站；文件选择和处理在运行那个网站的浏览器中完成。代理或应用的宿主服务商按自己的政策处理你的请求和对话记录。本服务会接收宿主在目录请求中发送的内容，但不会要求提供或主动获取宿主的对话记录。

应用程序不记录查询或请求正文日志，没有数据库，也不保存持久任务。Worker 的可观测性功能已关闭。Cloudflare 仍会为了托管、安全和请求频率控制而处理 IP 地址、时间和请求元数据。这些由服务商管理的元数据按 Cloudflare 的规定保存；我们尚未核实本服务的固定保存期限。不使用远程目录，仍可使用普通网站和本地文件处理功能。

本站免费，靠广告养着。这意味着这些页面上跑着两个 Google 的产品，大部分页面上还跑着一个捐助按钮。清单如下，就这么多。

Google AdSense，广告

广告由 Google 投放，看到哪些也由它决定。为此它可能在你的浏览器里设置和读取 Cookie 或者类似的标识，并拿到你的 IP 地址、由此推出的大致位置、你的 user agent，以及你当时在哪个页面上。视你的设置和所在地区而定，广告可能会用 Google 手里关于你的画像做个性化，而那份画像主要是从你在别的网站上的活动攒起来的。

这些我们一样都收不到，也看不见，而且我们从不给 Google 任何关于你文件的信息。Google 自己对“它如何使用来自投放其广告的网站的数据”的说明在 policies.google.com/technologies/partner-sites。

Google Analytics，访问与工具使用统计

我们用 Google Analytics 4 统计页面访问和成功的工具使用，好知道哪些工具值得继续做。它记录你看了哪个页面、大约什么时候、一个随机生成并存在浏览器里的标识、大致位置、设备和浏览器类型，以及常见的推广来源标签。

发给 Analytics 的页面地址使用规范网址，只保留常见的推广来源标签，省去其他查询参数和地址片段。页面标题是固定的；来源网站只保留源站地址，不含路径或查询参数。

每次加载页面，只统计首次成功的工具使用，例如请求已准备好的下载、完成复制，或在查看工具中显示可用的分析或查看结果。这个事件添加的工具专属信息只有固定的工具标识，不代表操作系统已经保存下载文件。

我们也统计工具页的打开次数。在图片转视频、图片堆栈、GIF 分析和 GIF 拆帧中，固定事件记录提供输入、开始处理、结果就绪、出现问题或取消操作；每次页面加载中，每个阶段最多统计一次，内置示例不计入这些阶段。部分后续操作链接只报告来源页和目标页的固定标识，不发送链接地址或文字。这些计数用于了解访问停在哪一步，不识别单次任务，也不证明用户已到达下一页。

可选反馈在你选定回答后，记录固定的工具标识、固定的赞或踩和固定原因，没有自由文字输入。工具不会在这两类记录中附带文件、文件名、内容、输入文字、数量、大小、尺寸、格式、设置、错误信息或其他输入输出详情。我们能查看汇总的 Analytics 报告。屏蔽 Analytics 不影响本地处理；工具缓存就绪后，离线也能使用。

配对工具的连接方式

五种配对工具默认使用 Direct。主机可以在开始前选择 Cloud relay，邀请会携带这个选择，另一方在连接前查看并确认。Direct 不会自动切换到中继。Cloudflare TURN 转发加密的文字、文件、视频、音频和控制消息，不持有解密密钥，但能看到地址、时间和流量。双方需要全程联网。临时中继凭据保留在浏览器内存中，通过引见服务更新，不会公开在邀请或附近列表中。列表可以显示主机选择的连接方式。批准、密码和麦克风控制仍然有效。

全部五种工具都能列出本地网络或私密群组中的可用连接。不同网络的设备可以使用同一个随机生成的群组代码来发现会话。每种工具有独立列表，群组会话不会同时公开到本地网络列表。代码只允许发现，不代表获准访问；密码、主机批准和所选连接路径仍然有效。引见服务通过加密连接接收代码以验证群组成员资格，之后只在打开的连接中保留派生标识和验证结果。请求网址及其保留七天的元数据日志包含该标识，不包含代码。页面只在内存中保留代码，不将其写入邀请或连接报告，重新加载后即忘记。页面上的普通脚本可以读取输入字段；私密群组不会将这些脚本隔离。任何知道代码的人都能发现向群组公开的会话，因此只应将代码分享给预期的人。

分享浏览器标签页

分享浏览器标签页通过桌面浏览器自己的选择器捕获一个标签页，把实时视频传给一位获准观看者。观看者请求访问、主持人批准、观看者确认后，才发送视频。它不捕获声音、摄像头或麦克风。所选标签页中可见的信息会被分享；观看者可以录制收到的画面。

在线附近发现默认关闭。主持人可以在开始前启用 Show in nearby shared tabs；观看者主动选择 Find nearby tabs 才会打开列表。发现连接只列出随机邀请码，绝不包含所捕获标签页的标题、地址、画面或观看者留言。选择条目旁的 Join 会按所示方式发出请求。没有有效批准凭据时，仍需主机批准。复制的邀请链接仍会等待 Request to watch 操作。服务根据公网 IPv4 地址或 IPv6 /64 子网以及网站来源对本工具的页面分组，不按实际位置判断。共享网关或 VPN 可能让陌生人出现在同一组，也可能隐藏身边的设备。列表仅存在于打开的连接中，不保存历史，停止后会撤下主持人的条目。

在 Direct 方式下，视频在可互通的本地网络上使用加密直连，不使用公共 STUN 或 TURN。两台设备都需要互联网连接来发现和配对。引见服务器看到房间代码、IP 地址、时间、WebRTC 描述和连接候选，不接收视频、观看者留言或批准决定。Cloudflare 保留连接元数据日志七天。

页面的常规脚本能读取页面地址和状态，包括邀请代码；只有链接并不能获得视频访问权。观看者不能控制主机或选择网页文字。工具没有录制功能，但已登录内容只要出现在画面中就会被分享，观看者也能自行截图或录制。工具页说明网络限制；本地地址设置不能证明物理网络边界。

远程摄像头和浏览器引见

远程摄像头会在页面加载时打开用于发现摄像头的 WebSocket 连接。启动摄像头或点击连接时，还会与我们的连接协调服务建立房间连接。选择摄像头旁的 Join 会按所示方式请求连接并交换网络地址。打开观看链接时，页面仍会等待点击连接。默认需要摄像头端批准观看；这项设置控制视频和音频传输，不控制网络地址交换。引见服务器能看到代码、地址、时间和连接设置消息，看不到视频、音频或观看者备注。在 Direct 方式下，视频和已启用的音频走浏览器间加密直连，没有配置 STUN 或 TURN，也没有录制功能。音频默认关闭，只有主机选择分享音频后才会请求麦克风访问权限。引见仍需互联网。VPN 和系统策略可能影响路由，本地模式不证明物理网络边界。工具页说明这些限制，以及页面脚本如何读到完整观看链接。

可选的观看者提醒在观看设备上分析小尺寸视频帧和接收到的音频，不录制，也不上传。启用提醒会请求浏览器通知权限。浏览器和操作系统显示的通用活动通知不包含摄像头图像、音频、链接名称或观看者备注。断开连接会停止分析并关闭本次会话的通知。观看页面必须保持打开；浏览器可能在后台或设备休眠时暂停分析。

文本与文件分享及引见服务器

文本与文件分享首页打开发现连接，开始分享再打开一条连接。名称按公网 IPv4 地址或 IPv6 子网和页面来源分组；这只是发现线索，不证明同一物理网络。引见服务器看到名称、IP、连接时间和协商消息，不接收分享文字或文件。公开名称只存在于打开的连接里，没有持久存储。普通 Direct 使用 Google 和 Cloudflare 的公共 STUN，这些服务会看到请求来源地址。本地网络将 Direct 限制为主机地址，不使用 STUN 或 TURN。Cloud relay 是独立选择，由主机在分享前选定，并由读者在连接前确认。所有方式都需要公网引见服务器来建立连接。Cloudflare 保留分享和摄像头引见的连接元数据日志七天；这些是我们可读的逐访客服务日志。收件人已复制或下载的内容，不会随着来源标签关闭而消失。

Cookie

我们不设置登录或会话 Cookie。Google 脚本可能设置上面说明的 Cookie 和标识。本站也使用浏览器本地存储来记住偏好和临时工作。

配对批准。五个配对工具会在浏览器本地存储随机重连凭据，仅保留有限数量的近期工具、房间和连接方式组合。凭据不含分享内容、姓名或 IP 地址。文本分享、标签页分享和远程摄像头只通过浏览器间的加密连接出示批准凭据；语音工具在加入时向引见服务发送个人密钥。批准仅在当前主机会话内有效：断开连接会保留批准，主机移除会撤销批准，结束或开始新会话会重置批准。清除或禁止存储可能需要重新批准。同一网站来源下任意页面运行的脚本，包括第三方脚本，都能读取这些凭据。它们不与页面脚本隔离，也不会放进邀请或发现列表。

你选的语言。你在切换器里挑了一种语言，这个选择会写进你浏览器的本地存储，名字叫 abox-lang，好让你打开的下一个页面就是你要的那种语言。它不是 Cookie：它从不发给我们，也不发给别的任何人，就待在你读这段话的这台设备上，清掉浏览器的站点数据它就没了。你要是从来没挑过语言，那就什么都不会写，一个按你浏览器语言显示的页面，是当场匹配、随后即忘的。

其他本地存储。反馈会记住回答或关闭的时间，避免再问。工具可能在本地保留设置或可选的分享草稿。切换语言或主动接续到另一工具时，可以把文件和设置临时存在 IndexedDB，供另一个本地页面取走。这些记录不是 Cookie，不发给我们；清理站点数据会删除它们。持久草稿由相关工具说明。

Google 的 Cookie 和标识用于统计访问和工具使用，以及选择广告和限制展示次数，与上面说明的本站本地记录不同。

怎么把它关掉

  • 广告个性化可以一次对所有网站关掉，在 My Ad Center。
  • Google Analytics 可以用 Google 自己的停用浏览器插件在所有站点上拦掉。
  • 你浏览器自己的设置能拦掉或者清掉第三方 Cookie，而任何内容拦截器都能让这些脚本从一开始就加载不了。

拦住广告、Analytics 和捐助按钮，不影响本地处理。工具的离线缓存就绪后，断网也能做本地处理。网址图片导入、在线汇率、浏览器引见和其他应用的发送，需要各自的连接。没有处理功能被扣在广告后面。
