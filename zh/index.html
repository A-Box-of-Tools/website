一箱子工具，都不走服务器

一个工具只干一件事，全程在你的浏览器里跑。文件留在你自己的机器上，没有东西要传，没有账号要注册，也没人在旁边记你干了什么。

这些工具免费，以后也一样。要是哪个真帮你省了事，全站开口跟你要点什么的地方，就这一处。

  • 文件不出你这台机器 打开、读取、处理，全是你自己的浏览器在做，用的是你自己的硬件。每个工具的 Content-Security-Policy 都把允许联的地址列全了，里面没有一个是我们的。
  • 连你文件的信息也传不出去 文件本身不传，缩略图、文件名、大小、选了几个，一样不传。这里没有哪个工具去读这些，另一头也没有服务器等着收。
  • 断网照样能用 把工具打开一次，然后拔掉网线，它照干不误，跟联网时没有区别。这一步很难作假。真要把文件送出去处理，断网当场就停。

上面这些不用你信。 怎么判断一个工具是不是真需要你的文件里有四项你自己动手就能做的检查，用在本站管用，用在别家也一样。

图片

压缩、改尺寸，或者抹掉照片悄悄记下的那些信息，全都不出这台机器。

  • 图片压缩 你说要多大，100 KB、2 MB 都行，它去找刚好够到这个数的最轻一档压缩。
  • 图片缩放 精确到像素、按百分比，或者定个长边，顺路还能裁一刀、换个格式。一张图或者一整个文件夹都行。
  • HEIC 转 JPG iPhone 拍的照片，换成什么都打得开的格式。解码在你自己的机器上，不在谁的服务器上。
  • 证件照制作 选一个国家和一种证件，裁切框就会按那条规定取头高和眼线。按精确的毫米和分辨率打印，附带 10 × 15 拼版，并把上传文件压进办事门户的 KB 区间。
  • 图片堆栈 把一串连拍合成一张：取平均值抹掉噪点，取中位数甩掉路人，或者取最亮做星轨。RAW 文件不用转换器也读得了。
  • 图片涂黑与打码 把图片的一部分涂黑、打码或者模糊掉。被遮的像素在文件写出来之前就被覆盖，不会留下一层可以挪开的东西。
  • EXIF 查看与清除 看清一张照片里藏着的位置、相机和机身序列号，想改哪条改哪条，或者一键清光。
  • DICOM 阅片器 在你自己的机器上打开 CT、MR、X 光或超声影像。调好窗宽窗位，翻完整套序列，按毫米测量，读遍头信息里的每一个标签。
  • 图片转 ICO 网站图标、Windows 应用图标，或者 macOS 的 .icns，每个尺寸都装在一个文件里，下载前先看 16 像素下什么样。
  • 图片转 Data URI 位图走 base64，SVG 走百分号编码，外面那圈 CSS 规则或者<img> 标签也一并写好。
  • SVG 转图片 SVG 自己没有像素尺寸，所以这个数字由你定，32 也好 8000 也好，一样锐利。

视频与动画

剪片、转格式，或者用照片拼一段，素材都不出这台机器。

  • 图片转视频 把一个文件夹的图片做成 MP4 幻灯片。编码在你自己的机器上跑，用的是你自己的硬件。
  • 视频剪切 一边看一边把值得留的段落标出来，再把它们存成一个视频。画面帧是搬过去的，不是重编的，所以什么都不会丢。
  • 视频裁剪 在片子上拉个框，切到只剩这块。发帖用方的，手机上看用竖的，或者精确到像素填一个框。
  • 视频倒放 把片子反过来放，画面和声音都算在内，而且不用把它发到任何地方去。
  • 延时视频 把长片子变成短片子，几小时压成几秒钟，而且不往任何地方送。
  • 视频截帧 把视频的任意一帧存成图片，尺寸就是视频本身的尺寸。可以一张一张地截，也可以每隔几秒截一张。
  • 视频转 GIF 标出你要的那几秒，挑好宽度和帧率，拿到一张 GIF 动图，配色板、抖动一并办好。
  • GIF 制作 把图片排好顺序，说清楚每张停多久，就能拿到一个 GIF 动图。颜色和压缩都是在你自己的机器上算出来的。
  • GIF 拆帧 把动图拆开：每一帧存成单独的 PNG，透明保留下来，时长另外记下。解压 GIF 这件事发生在你自己的机器上。
  • GIF 分析 打开一个 GIF，看看里面到底有什么：每一帧的延时和处置方式、颜色表，以及一份关于体积去了哪里的老实账。

文档与音频

拼文档、剪录音，两样都不用送出去处理。

  • PDF 合并与拆分 把文档拼起来，把一个切成好几个，把页面拖成你要的顺序。链接和书签会重新搭好，跟着它们指向的页面走；每一个成品文件在交给你之前，都会被重新打开、重新数一遍页数。
  • PDF 压缩 把文档里的图片重新压一遍，文件就小了。它先摆给你看体积到底压在哪儿，没什么可省的时候也直说。
  • PDF 涂黑 把词从 PDF 里删掉，而不是盖住。字是从绘制这一页的指令里拿走的，空出来的宽度保留着，别的东西不会移位；做好的文件还会在这里重新打开搜一遍，证明那些词不在里面。
  • 图片转 PDF 把图片合成一个 PDF，一张一页。JPEG 照片原样抄进去，画质一点不掉。
  • 文档扫描 一张纸的照片，摆正清理之后变成一份文档。四个角替你找好，倾斜给你掰正，阴影除掉。
  • 音频剪辑 边听边把值得留下的段落标出来，然后存成一段录音。切点落在精确的采样上，接缝也不会咔哒。
  • 音频编辑 倒放一段音频，变速时音高可动可不动，把录轻了的录音提上来。视频里的声音也能抽出来。

文本、编码与密码

看一看、核一核，或者就在这里生成。令牌、配置文件和密码都不会落到别人的服务器上。

  • JSON 格式化 格式化和压缩 JSON、XML、HTML、CSS 和 YAML，或者在它们之间转换。贴个 token 或者一份配置文件，不用交给任何人。
  • 文本比对 比对两段文本，逐行、逐词看清改了什么。贴一份合同或者尚未发布的代码，不用交给任何人。
  • Base64 编码解码 Base64、URL、HTML 实体、十六进制和反斜杠转义，编码或解码。贴个 token，不用交给任何人。
  • 文本与文件分享 文本与文件，经加密直连从浏览器到浏览器。哪里都不存；关掉标签页，分享即止。
  • 二维码与条形码生成 给链接、Wi-Fi 或者名片做个二维码，也可以做一个算好校验位的零售条码。SVG 或 PNG 随你拿。
  • 二维码与条形码识读 从照片、截图或摄像头读二维码，并在打开之前看到完整地址。条形码也行。
  • 哈希与校验和 算出文件的 MD5、SHA-1、SHA-256、SHA-384 或 SHA-512，再和下载页面公布的值对照。多大都行：文件是分块读的，从不整个留在内存里。
  • 密码与密码短语生成器 一个强随机密码，或者用自带词表拼出来的密码短语。由你自己的浏览器抽取，不发往任何地方。
