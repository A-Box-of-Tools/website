    图片

    压缩、改尺寸，或者抹掉照片悄悄记下的那些信息，全都不出这台机器。

    • 图片压缩 说个大小，剩下的它来算。
    • 图片缩放 说个尺寸，拉个框，挑个格式。
    • HEIC 转 JPG iPhone 拍的照片，换成什么都打得开的格式。
    • WebP 转 JPG 把网页保存的图片，变成所有软件仍然接受的格式。
    • PNG 转 WebP 同一张图片，常常减少三分之一体积，透明区域保持完整。
    • AVIF 转 JPG 把网站如今保存的格式，变成所有软件一直支持的格式。
    • 证件照制作 选择支持的国家和证件。公布的要求与指导值均有标注。
    • 图片堆栈 二十张变一张，不用传二十次，也不用 RAW 转换器。
    • 图片涂黑与打码 你遮住的那块是从文件里删掉的，不是藏在文件里。
    • EXIF 查看与清除 看看一张照片把你交代了多少，然后删掉。
    • DICOM 阅片器 CT、MR、X 光和超声，连窗宽窗位、头信息和测量一起。
    • 图片转 ICO 进去一张图，出来的是浏览器、Windows 和 Mac 各自要的每一个尺寸。
    • 图片转 Data URI 整张图变成一行文本，直接粘进 CSS 或者 HTML。
    • SVG 转图片 说个尺寸。矢量图本来就没有尺寸可丢。
    • 图片转 SVG 一个形状，一条轮廓。不该有的东西，点一下就好。
    • 身高对比图 把身高打进去，把图带走。为了画它，不会往外送任何东西。
    • 商家资料预览 把内容打进去，它就变成 Google 会画的那张卡片。为了画它，不会往外送任何东西。

    视频与动画

    剪片、转格式，或者用照片拼一段，素材都不出这台机器。

    • 视频压缩 说一个它最多能有多大。剩下的工具来算，做完先量一遍再交给你。
    • MP4 转换 不管从录屏、压制还是相机里出来的是什么，都变成 MP4 里的 H.264 和 AAC。能复制的原样复制，非改不可的才重新编码。
    • 视频旋转 转四分之一圈、半圈，或者往另一边转。使用文件头旋转时，每一帧画面保持原样。
    • 图片转视频 一个文件夹的图片，变成一段视频。
    • 视频剪切 一边看一边标出要留的段落，最后拿回一个视频。
    • 视频裁剪 把片子切到只剩要紧的那块。
    • 视频倒放 最后一帧排在最前，连声音一起。
    • 延时视频 一小时的素材，二十秒看完。
    • 视频截帧 任意位置，一张原画质静帧。
    • GIF 转 MP4 每一帧都带着 GIF 给它的延时，变成 MP4 里的 H.264。在你的机器上转，文件从不上传。
    • 视频转 GIF 挑好段落、尺寸和帧率。
    • GIF 制作 把一组图片变成一段动画。
    • GIF 拆帧 每一帧都单独存成一张 PNG。
    • GIF 分析 帧、延时、调色板，以及每个字节的去向。

    文档与音频

    拼文档、剪录音，两样都不用送出去处理。

    • PDF 合并与拆分 挪动页面，不用往服务器跑一趟。
    • PDF 压缩 文档变小，不用送去任何地方。
    • PDF 解锁 权限限制与打开密码不同。页面会说明你的 PDF 使用哪种保护。
    • PDF 加密 把文档锁上，而不是为了锁它先把它交给一个网站。
    • PDF 水印 一份写着自己去了哪里的扫描件，就没法悄悄再去别的地方。
    • PDF 涂黑 字从文件里删掉，然后再搜一遍这个文件来证明。
    • PDF 转 CSV 将检测到的 PDF 文本表格转换成电子表格可打开的行。
    • 收据与发票识别 读取照片，检查字段和裁剪结果，准备供邮件应用使用的压缩附件和合计。
    • 图片转 PDF 把你的图片装进一个文档。
    • 文档扫描 把纸拍下来，回来的是一份看着像扫描的东西。
    • 从视频里提取音频 把视频拖进来，声音就取出来了。画面从不解码，也不上传任何东西。
    • 音频剪辑 边听边标出值得留的段落。它们会合成一个文件回来，就切在你说的位置。
    • 音频编辑 倒着放、快慢随你调、把录轻了的声音提上来，全在你这台机器上。

    文本、编码与密码

    看一看、核一核，或者就在这里生成。令牌、配置文件和密码都不会落到别人的服务器上。

    • JSON 格式化 JSON、XML、HTML、CSS 和 YAML，格式化或转换。没有一个字被贴进别人的服务器。
    • YAML 转 JSON 两个方向都有，而且会告诉你各自的代价。这些都不会粘进别人的服务器。
    • XML 格式化 排开了好读的 XML，压平了好发的 XML，还有两个方向的 JSON 转换。这些都不会粘进别人的服务器。
    • 文本比对 两段文本进来，每处差异都被标出来，逐行、逐词。没有一个字被贴进别人的服务器。
    • Base64 编码解码 Base64、百分号编码、HTML 实体、十六进制和反斜杠转义，双向都行。没有一个字被贴进别人的服务器。
    • 二维码与条形码生成 打进去，就变成一个码。生成过程不往外送任何东西。
    • 二维码与条形码识读 把摄像头对准码，或者把拍下来的图丢进来。读这件事只发生在这里，别处都没有。
    • 哈希与校验和 把下载来的文件和发布方公布的那串数字对一下，不用把它发给任何人。
    • 密码与密码短语生成器 在这里生成，由你自己的浏览器生成，不发往任何地方。什么都不保存，也没有历史记录。
