这里的每一种编码都是对一串字符做算术，就在这个页面里做完。编解码器是手写的，都在 src/encode.js 里；此外别无他物。这个工具没有任何形式的网络功能，没有什么可取，也没有什么可发。这一点几乎在哪儿都不如在这里要紧：人们往在线 Base64 解码器里贴的是 token，而把 token 贴进别人的网站，等于把它交了出去。

这条隐私承诺怎么核实

  • 你贴进来的东西没有出去的路。Content-Security-Policy 里写着这个页面允许联系的每一个地址，没有一个属于本站。这里没有任何可以收走一个贴进来的 token 的接收端，就算有，代码里也没有把它送过去的东西。
  • 这里不会去取任何东西。整个 src/ 里没有 fetch，没有 XMLHttpRequest，也没有 sendBeacon。每个编码器和每个解码器，都是这个页面里接收一串字符、返回一串字符的函数。
  • 有什么不对，解码器会告诉你。浏览器自带的 atob 会接受本该拒绝的输入，然后返回一个貌似像样的结果。这里的 Base64 是手写的，用 RFC 4648 的测试向量验证；你贴的不是 Base64 时它会说出来，还会说出原因。tests/js/text-encode.test.js 里的测试验证的正是这一点。
  • Google 加载了什么，又拿不到什么。广告脚本和统计脚本来自 Google，捐助按钮来自 Buy Me a Coffee。你的文本，一个字符也没有交给它们。读取、解析、写出文本的每一行代码都由这个源提供，也都摆在仓库里。
  • 断网也照样能用。断开网络，这个工具跟原来一模一样，因为它里面从来就没有联网这一步。这是最省事的一条证明。

你可以自己核对。上面这些不用你信。这个页面是仓库里的模板和配置生成出来的，构建脚本你能读，也能自己跑一遍，跑出来的结果就提交在 dist 分支上。拿实际发给你的内容，跟你自己从源码构建出来的结果对一遍就知道了：

最值得先读的几个文件：config/site.toml 里是 Content-Security-Policy，还有 src/encode.js：这里的 Base64 用 RFC 4648 的测试向量来验证，而不是拿自己验自己；坏输入直接拒绝，而不是像 atob 那样返回一个貌似像样的结果。

如果公司的安全软件警告说有上传。 它盯着浏览器里选择文件的那一刻，而且无法知道页面是否打算把它发出去——所以在选择时就发出警告。这里什么都不会发出去：打开浏览器的开发者工具，切到网络，然后选一个文件。没有任何请求带着它，除了这个页面自己的本地预览之外，根本没有任何请求。同样的检查，你们的 IT 同事半分钟就能做完。

常见问题
 
 
 我的文本会被传到哪里去吗？ 
 不会。这个页面上的每个编码器和解码器，都是在你自己的浏览器里、你自己的硬件上运行的函数。这个工具没有任何形式的网络功能：它从不去取什么，也从不发出什么；页面的 Content-Security-Policy 里写着它允许联系的每一个地址，没有一个属于本站。这正是拿它来处理访问令牌或会话 cookie 的理由：把这类东西贴进别人的解码器，等于把它交给了对方。 
 
 
 这里的 Base64 和别处的 Base64 一样吗？ 
 一样——它是拿 RFC 4648 的测试向量来核对的，而不是拿自己核对自己。两套字母表都能解码，所以用 - 和 _ 写的 JWT，和用 + 和 / 写的一样好读；按 64 个字符折行的输入，会替你接回去。编码走的是 UTF-8 字节，所以带重音的字母或者 emoji 一来一回都安然无恙。 
 
 
 Base64 是加密吗？ 
 不是，把它当加密正是经典的误会。Base64 是一种写法：同样的字节，换一套能在 URL、邮件或 JSON 字符串里活下来的字母表写出来。谁都能把它读回去——这个页面一毫秒就做到了——所以它什么都藏不住，什么都保护不了。你手里的东西要是机密，那它需要的是编码之前的真加密，而不是拿编码来顶替。 
 
 
 为什么解码失败了？ 
 因为贴进来的东西和编解码器以为的不完全是一回事，错误信息会说清差在哪儿：Base64 字母表之外的字符、放错位置的填充、后面没跟两位十六进制数的百分号，或者能从 Base64 解出来、却不是 UTF-8 文本的字节——最后这种通常说明原始内容是个文件，不是字符串。换成浏览器自带的 atob，它会返回一个貌似像样的结果；而能被告知哪里不对，正是把东西贴进解码器的全部意义。 
 
 
 两种网址编码有什么区别？ 
 一个值，还是整个地址。编码“单个值”会转义 URL 赋予了含义的一切——斜杠、问号、和号——这正是查询串里单个参数需要的。编码“整个 URL”则让地址继续能用：斜杠和 ? 留着，只转义 URL 根本带不动的字符。拿前者去编码整个地址，地址就坏了；拿后者去编码一个值，就分不清值到哪儿结束。 
 
 
 它能处理多大的文件？ 
 这里没有设上限，因为没有哪台服务器在为上限掏钱。真正的天花板是你自己的机器：几兆字节的文本没问题；文档特别长的时候，页面会等你敲字停一下再重新编码，而不是跟你抢键盘。 
 
 
 它免费吗，需要注册吗？ 
 免费，没有账号，不用登录，没有试用期，贴多少也没有上限。本站带广告，经费就是从那儿来的，广告拿不到任何关于你文本的信息。 
 
 
 断网能用吗？ 
 能。页面加载一次之后断开网络，它照样干活。这也是证明“什么都没上传”最省事的办法，真要把你的文本送出去解码，拔线那一刻就停了。
