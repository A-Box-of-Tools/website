このリストの作り方

願望リストではありません。オンラインで最大のGIF・動画サイトのツール一覧を一通り見て作りました。人がファイルに対して実際に何をしたがっているかの目録として、これに近いものは他にありません。そのうえで、処理が手元の端末で行われ、しかも回線を抜いたままでも動き続けるように作れる項目だけを残しました。

残ったものの大半は、ブラウザがすでに備えているAPIで動きます。いくつかは使う側のツールにコーデックを同梱する必要がありますが、それは認めています。ファイルが端末から出ないことに変わりはないからです。この線を越えられないものは、約束せずに落としました。ですから下の一覧には、抜けているように見えて、わざと外してある項目がいくつかあります。

すでにあるツールは各グループの先頭に置き、完成と付けて、それぞれのページへリンクしています。その下に並ぶものはこれからで、できあがるまでリンクにはなりません。

画像

  • 画像圧縮ツール — サイズを指定するだけ。あとは自動で探します。 完成
  • 画像リサイズツール — サイズを指定し、枠を描き、形式を選ぶ。それだけです。 完成
  • HEIC→JPG変換ツール — iPhoneが作る写真を、どこでも開ける形式に。 完成
  • 証明写真作成 — 国を選ぶだけ。その国の規定を、そのまま当てはめます。 完成
  • 画像スタック — 20枚を1枚に。20回のアップロードもRAW現像ソフトもなしで。 完成
  • 画像黒塗りツール — 隠した部分はファイルから消えます。上に置かれるのではありません。 完成
  • EXIFビューアー・削除ツール — 写真が持ち主について語っていることを見て、それから外します。 完成
  • DICOMビューア — CT・MRI・レントゲン・超音波を、ウィンドウとヘッダーと計測つきで。 完成
  • 画像→ICO変換ツール — 画像を1枚入れれば、ブラウザもWindowsもMacも、求めるサイズがすべて出てきます。 完成
  • 画像→データURI変換ツール — 画像まるごとを1行のテキストに。そのままCSSやHTMLに貼れます。 完成
  • SVG→画像変換ツール — サイズを指定するだけ。ベクターには、失うサイズがそもそもありません。 完成
  • 文字入れ — 画像の上に重ねる、または上部の帯に入れる
  • AVIF — 書き出せるブラウザは1つだけ、ほかは読むだけの形式
  • DICOMの匿名化 — 画像には触れずに、患者の情報だけを外します

GIFとアニメーション

  • 動画→GIF変換ツール — 使う範囲と、大きさと、フレームレートを選ぶだけです。 完成
  • GIF作成 — 何枚かの画像を、ひとつのアニメーションにします。 完成
  • GIF分解 — すべてのコマを、1枚ずつPNGで。 完成
  • GIF解析 — コマ、表示時間、パレット、そしてバイトの行き先。 完成
  • GIFをMP4やWebMに — 同じ動きのまま、たいてい10分の1のサイズに
  • GIFを編集 — 拡大縮小、切り抜き、回転、逆再生、速さの変更
  • アニメーションWebP — 同じ動きをごくわずかなサイズで。ここで唯一、同梱のエンコーダーが要るもの

動画

  • 画像→動画変換ツール — 画像の入ったフォルダを、1本の動画に変えます。 完成
  • 動画カットツール — 再生しながら残す場所に印を付けるだけ。まとめて1本の動画で返します。 完成
  • 動画トリミングツール — 肝心なところだけを残します。 完成
  • 動画の逆再生 — 最後のコマから、音も一緒に。 完成
  • タイムラプス作成ツール — 1時間の素材が20秒に。 完成
  • 動画のコマ切り出し — どの瞬間でも、画質を落とさずに1枚。 完成
  • サイズを変える — 本当に送れる大きさまで落とします
  • 回転 — 横向きに撮れてしまった映像のために。フレームは1枚もデコードしません
  • 動画を消音 — 音だけ落として、映像には手を触れません
  • MP4に変換 — カメラから出てきたものを、実際にアップロードできる形式に
  • 字幕を焼き付ける — SRTファイルを、映像そのものに描き込みます
  • 字幕を変換 — SRT、VTT、ASS、SBV、LRCをどの向きにも。時間のずれも直せます

音声

  • Extract Audio from Video — Drop a video in and take the sound out of it. The picture is never decoded, and nothing is uploaded. 完成
  • 音声の切り出し — 再生しながら残したい場所に印を付けます。印の付いた分が1つのファイルになって、指定どおりの位置で切れて戻ってきます。 完成
  • 音声編集ツール — 逆から再生する、速さを変える、小さな録音を持ち上げる。そのすべてを手元の端末の中で。 完成
  • 形式を変換 — MP3、WAV、Opusを、どの向きにも

書類とPDF

  • PDF結合・分割 — サーバーを一往復せずに、ページを入れ替える。 完成
  • PDF圧縮ツール — どこにも送らずに、書類を軽くします。 完成
  • PDFの黒塗り — 文字はファイルから消され、そのあとファイルを検索して確かめます。 完成
  • 画像→PDF変換ツール — 手元の画像を、1つの書類にまとめます。 完成
  • 書類スキャナー — 紙を撮ってください。スキャンしたように見えるものが返ります。 完成
  • ページの回転と切り抜き — 横向きに取り込まれたスキャンを直す、余白を落とす
  • 画像を取り出す — 書類の中の画像を、元の形で抜き出します

メディアの外側

  • Height Comparison Chart — Type the heights, take the picture. Nothing is sent to draw it. 完成
  • JSONフォーマッター — JSON・XML・HTML・CSS・YAMLを、整形するか変換する。よそのサーバーに貼り付けるものは何もありません。 完成
  • YAML to JSON Converter — Both directions, and it says what each one costs. Nothing is pasted into anyone else's server. 完成
  • XML Formatter — XML laid out to read or squeezed to ship, and converted to JSON both ways. Nothing is pasted into anyone else's server. 完成
  • テキスト差分 — 2つのテキストを入れると、すべての違いが行単位・単語単位で印付きで出てきます。よそのサーバーに貼り付けるものは何もありません。 完成
  • Base64エンコーダー・デコーダー — Base64、パーセントエンコード、HTMLエンティティ、16進、バックスラッシュのエスケープを双方向で。よそのサーバーに貼り付けるものは何もありません。 完成
  • テキストとファイルの共有 — 共有はこの開いたタブの中だけに存在します。読む側は暗号化された内容をあなたのブラウザから直接受け取り、タブを閉じれば終わり。どのサーバーにも何も残りません。 完成
  • QRコード・バーコード作成ツール — 打ち込めば、そのままコードになります。作るために何かを送ることはありません。 完成
  • QRコード・バーコード読み取りツール — コードにカメラを向けるか、写った画像を置いてください。読むのはここだけ、ほかのどこでもありません。 完成
  • ハッシュとチェックサム — 配布元が出した数字とダウンロードを照らし合わせる。どこにも送らずに。 完成
  • パスワード・パスフレーズ生成 — 作るのはこのページ、動くのは手元のブラウザ。どこにも送られず、保存もされず、履歴も残りません。 完成
  • CSVとJSON — どちらの向きにも変換し、表計算が吐き出したものを整えます
  • 証明書と鍵 — 証明書や署名要求を、他人のサーバーに貼り付けずに読みます
