# スマホ写真をウェブ用に準備する方法

スマホの写真は形式が違い、必要の4倍大きく、あなたの住まいを知っています。投稿できる状態にするのは短い連鎖です——変換、構図、圧縮—そしてどの手順も手元の端末で走ります。GPSの入った写真の居場所は、まさにそこだからです。

最終更新 2026年8月26日

## 短い答え

1. **iPhoneの写真から。**HEICのファイルを[HEIC変換器](https://abox.tools/ja/heic-to-jpg/)に通し、メタデータを外す選択をします。何かを変換する前に、どの写真がGPS座標を抱えているかを教えてくれます。すでにJPEGの写真はこの手順を飛ばします。
2. **構図とサイズ。**ひとまとめにして[画像リサイザー](https://abox.tools/ja/resize-image/)へ。長辺を決めるか——たいていのページには1600ピクセル、読者が拡大するなら2000—ワンクリックで束全体を同じ縦横比に切り抜きます。
3. **予算に当てる。**仕上げは[画像圧縮](https://abox.tools/ja/compress-image/)で。画質スライダーの代わりにキロバイトの目標を受け取り、束を1つのzipで返します。

すべてブラウザの中で走ります。原本は——フル解像度、GPSも何もかも——端末を一度も離れません。それこそが、変換サイトではなく手元でやる理由です。

## メタデータの行き先

スマホ写真のひそかなリスクはピクセルではなく、札のほうです。EXIFメタデータはカメラ、時刻、そしてほぼすべての電話で、撮影場所のGPS座標を記録します。それを投稿すれば、見る人の誰もが読める形で自宅の住所を公開しているかもしれません。

この連鎖の役に立つ事実は、札の始末を勝手につけてくれることです。リサイズも圧縮も、画像をピクセルから描き直します。描き直されたピクセルは札を運びません。だから手順2や3から出てくるものは、頼まなくてもきれいです。決断が要るのは2つの場合だけ。

- **HEICの変換。**変換器はメタデータを持っていくことも、置いていくこともできます。チェックボックス1つで、どの写真にGPSが載っているかを警告してくれます。公開されるものなら何であれ、置いていってください。
- **リサイズしない写真。**ピクセルをバイト単位でそのままにしたいなら、[EXIFエディター](https://abox.tools/ja/exif-editor/)を使ってください。画像を再エンコードせずに札だけを取り除きます。[メタデータのガイド](https://abox.tools/ja/guides/remove-exif-and-gps-data/)が長い版です。

## なぜ圧縮の前にリサイズするのか

ピクセルこそが予算だからです。300 KBの枠に収まるまで強く絞られた1200万画素の写真は、同じ枠にやさしく圧縮された200万画素の写真より目に見えて悪くなります。同じキロバイトが6倍の面積に塗り広げられるからです。表示サイズを先に決めれば、圧縮は予算を、誰も見ない解像度ではなく画質に使えます。

目標に他の方法で届かないとき、圧縮は自分でもリサイズしますが、それは最後の手段の扱いです。構図をリサイザーで自分でやることが、何を切るか、どの辺が大事かという決断を、あるべき場所にとどめます。

[リサイズのガイド](https://abox.tools/ja/guides/resize-an-image/)と[圧縮のガイド](https://abox.tools/ja/guides/compress-an-image-to-a-target-size/)が、それぞれの半分をさらに掘り下げています。画質の数字が本当は何を測っているかも含めて。

![サイズ変更ツールが長辺に設定され、1600が入力され、横に定番の長辺が並んでいる。](https://abox.tools/screens/get-photos-ready-for-the-web/long-edge.webp)

まず長辺です。縦の写真と横の写真を同じように扱ってくれる設定は、これひとつだからです。

## 束をまとめて一度に

連鎖のどの道具も、フォルダーぶんのファイルを一度のドロップで受け取ります。変換器は連写も含めてすべてのHEICを処理し、リサイザーは1つの構図を全体にかけるか、写真ごとに別々に切り抜かせてくれ、圧縮は全部を1つのzipで返します。20枚の写真は1枚と比べても、あなたの注意をほとんど余計に求めません。機械の時間は手元の機械のもので、どんなアップロードよりも短く済みます。

![3行の結果。どれもメガバイト単位から150 kBほどまで落ちた写真と、そこに落ち着いた品質が並んでいる。](https://abox.tools/screens/get-photos-ready-for-the-web/quality.webp)

そのあとに品質を、まとめて一度に。順番には意味があり、その理由は上の節にあります。

## これを毎週やるなら

連鎖がここで3つか4つのページに住んでいるのはわざとです。各ページは1つの仕事をし、それぞれが単独で、何ひとつ端末を離れないことを証明します。しかしどの手順もオープンソースです。MITライセンス、道具ごとに1フォルダー、デコーダー、リサンプリング、サイズ目標の探索を説明するREADMEの付いた、依存なしのESモジュール。

写真が毎回同じ形になるなら——同じ長辺、同じ予算、同じ札剥がし——コーディングエージェントを[リポジトリ](https://github.com/A-Box-of-Tools/website)に向けて、それらのモジュールを、あなたのプリセットを焼き込んだ1つのドロップゾーンに組んでもらってください。モジュールは読まれるために書かれていて、持ち出すことこそライセンスの目的です。
