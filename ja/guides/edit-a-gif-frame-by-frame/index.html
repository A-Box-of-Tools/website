GIFをコマ単位で編集する方法

ここにGIFエディターはありませんし、要りません。アニメーションをコマにばらす分解ツールと、コマからアニメーションを組み立てるメーカーは、あいだにフォルダーをひとつ挟んだエディターです — そしてそのフォルダーこそ、あなたが画像にいつも使っている道具で編集する部分なのです。

最終更新 2026年8月26日

短い答え

  1. ばらす。 GIF分解を開いてGIFをドロップします。コマひとつひとつがそれぞれのPNGになり — 画面に見えるとおりの姿で、透明度も保ったまま — ZIPにはタイミングリストが入ります。組み直しのために書き留められた、コマごとの表示時間です。
  2. フォルダーを編集する。 消えるべきコマは削除し、変わるべきコマは好きな画像エディターで手を入れ、並べ替えたければ名前を変えます。PNGの入ったフォルダーは、何にでも通じる形式です。
  3. 組み直す。 フォルダーをGIFメーカーにドロップし、コマの表示時間を設定して — リストに頼っても構いません — パレットを選び、書き出します。

3つの手順はすべてブラウザーの中で動きます。どの時点でも何もアップロードされません。そしてここでは、それがいつも以上に重要です。人が直そうとするGIFは、何かデリケートなものが半分映り込んだ画面録画であることが、それだけ多いのですから。

編集の前に分解ツールが教えてくれること

分解ツールはコマごとに表示時間、位置、サイズ、破棄ルールを表示します。何かに触れる前にこのパネルを一度見ておく価値があります。たいていのGIFが抱えるふたつの意外な事実を説明してくれるからです。

ひとつめ。コマは必ずしも完全な絵ではありません。多くのGIFは変化したピクセルだけを、前のコマの上に継ぎ当てる形で保存しています。分解ツールは各コマを見えるとおりでも保存されたとおりでも取り出せますが、編集にはほぼ必ず見えるとおりが要ります。そうすればPNGの一枚一枚が自立するからです。ふたつめ。表示時間はひとつの数字ではなくコマごとです。オチでの間は、実在するコマに掛かった実在する時間であり、それを往復の向こうまで運ぶのがタイミングリストです。

よくある間引きなら、フォルダーの手順は省略さえできます。2コマに1枚、5コマに1枚だけ残す、残すコマにチェックを入れる、といった操作は分解ツール自体に入っています — そしてコマを半分に間引くことは、GIFが受けられるいちばん効くダイエットです。

組み直しの代償、正直に

GIFが持てるのは最大256色で、組み立てのときに選ばれます。組み直しはコマをもう一度量子化します — 共有パレットひとつか、コマごとの最適色か — 写真的な素材では、この2度目の量子化が見えることがあります。画面録画や線画、つまりいつもの積み荷では見えません。そもそも256色を使ったことがないからです。

メーカーの残りのレバーはGIF予算ガイドのものと同じです。色数を減らす、グラデーションにはフロイド–スタインバーグのディザリング、そしてループの振る舞い — 永遠か、一度か、回数指定か。

手術がうまくいったか — そしてバイトが本当はどこに住んでいるか — を見るには、結果をGIFアナライザーにドロップしてください。コマ対バイトのグラフを描いてくれます。重いコマはたいてい、誰かが切り詰められたはずの全面描き直しです。

その道のりはメーカー自身が申し出ます。書き出しが終わると、ダウンロードボタンの下の一列ができたてのGIFをそのままアナライザーへ運び、読み込み済みの状態で開きます。

毎週やるなら

ばらす、フォルダー、組み直す。手順が別々のページに住んでいるのは、各ページがひとつの仕事だけをし、それぞれが単独で、何もあなたのマシンを離れないことを証明できるからです。それでいて、すべてオープンソースです。MITライセンス、ツールごとにフォルダーひとつ、デコーダーと破棄ルールと量子化器を説明するREADMEを添えた、依存なしのESモジュール。

GIFの手術が繰り返しやってくる雑用なら、コードエージェントをリポジトリに向かわせ、分解ツールのコマ表とメーカーのエンコーダーを、コマの削除がワンクリックで済む1ページに畳み込んでもらいましょう。モジュールは読まれるために書かれており、持ち去ることこそライセンスの存在理由です。
