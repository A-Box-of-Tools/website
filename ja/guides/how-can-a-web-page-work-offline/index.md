# ウェブページはどうしてWi-Fiなしで動けるのですか？

Service workerはローカルコピーを保持できます。切断中の操作完了はローカル処理の証拠で、将来の全経路の保証ではありません。キャッシュと確認点を説明します。

最終更新 2026年10月12日

## 短い答え

Service workerは必要な資源を端末のキャッシュへ保存し、以後の要求をそのコピーから返せます。このサイトは各ツールのページ、スクリプト、ローカルエンジンを保存します。先にキャッシュの完了が必要で、ブラウザーが拒否や削除をすることもあり、更新には接続が必要な場合があります。頼る前にオフライン表示を確認してください。

キャッシュが準備できればローカル操作は切断中に動きます。その操作の場所は示しますが、全機能や後の送信までは保証しません。Service workerはキャッシュの仕組みで、単独のプライバシー境界ではありません。

## プラグを抜いても生きていることが証明するもの

アップロードのガイドの最強の検査は[プラグを抜くこと](https://abox.tools/ja/guides/is-it-safe-to-upload-files/)です。道具を読み込み、切断し、使ってみる。なぜそれで分かるのかは、正確に言っておく価値があります。ファイルをサーバーで変換する道具は、仕事をするまさにその瞬間にネットワークを必要とします。線を切れば、仕事は止まる。動き続ける道具は、仕事があなたの機械の上で起きていることを、主張ではなく実演で示したのです。そしてネットワークに届かないページは、コードが何を望もうと、ファイルをどこへも送れません。

ローカルツールはオフラインコピーの準備と接続の有無を示します。端末のファイルで実際の操作を試してください。画像取得、為替照会、共有、カメラ紹介には通信段階があり、操作する場所で説明します。

## 写しはどうやって正直であり続けるか

永久保存が贈り物になるか罠になるかは二つの問いで決まり、機構は両方に答えます。

- **写しは古びないか？**ワーカーは接続があるときに新しい版を確かめ、丸ごと入れ替えます。丸ごとなのは、写しが常に首尾一貫していなければならないからです。半分古く半分新しい、というのが、決して差し出してはならない唯一の状態です。
- **正確には何が写されたのか？**ページに要るものすべて、そしてそれ以外は何も。しかもここの各道具は、自分の写しを自分の区画に持ちます。ある道具のキャッシュにはその道具が入っており、ひとつを入れたからといって黙って十が入りはしません。写しは検分もできます。ブラウザの開発者ツールがキャッシュ内の全ファイルを列挙し、その一覧は、ページが公然と取ってきた一覧と同じものです。

結果は、訪れただけでインストールしたも同然のアプリケーションのようにふるまうページです。そしてそれは文字どおり提供されてもいます。ブラウザのアドレスバーは、ここのどの道具でもアプリとしてインストールします。その道具自身のアイコンで、その道具に直行して開き、ページ上のボタンもねだるスクリプトもなしに。同じ機構が、ショートカットの衣装を着ただけです。

## オフラインが証明しないこと

この検査は強力ですが、魔法ではありません。限界も、強さと同じだけはっきり言っておくべきです。

- **切断中の操作を証明します。**ページはデータを保存して後で送ることもできます。タブを閉じるだけでは永続的なサイト保存を消しません。経路全体を確認するなら、ソース、保存、再接続後の要求を調べます。
- **特定の機能が対象で、サイト全体ではありません。**[共有](https://abox.tools/ja/share-text/)と[リモートカメラ](https://abox.tools/ja/remote-camera/)には公開紹介サーバーが必要で、ローカルモードでも接続を使います。[画像URL](https://abox.tools/ja/images-to-video/)と任意の[オンライン為替](https://abox.tools/ja/receipt-invoice-extractor/)も各サーバーが必要です。ローカル処理部分は切断中に動きます。
- **あなたを隠しはしません。**ページを読み込んだ時点で、ウェブのあらゆるページ読み込みと同じく、サイトにはあなたのアドレスが伝わっています。オフラインはファイルの行き先の話であって、匿名性の話ではありません。

オフライン完了と、要求、ポリシー、ソースの確認を組み合わせます。切断中に完了した操作は、その時点でサーバー処理が不要でした。失敗だけでは接続の理由は分からず、どちらの結果も機能の境界の確認に代わるものではありません。
