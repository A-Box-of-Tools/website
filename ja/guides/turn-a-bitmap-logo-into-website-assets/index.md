# 簡単なビットマップロゴからウェブ素材を作る

簡単な図案から役立つウェブ素材一式を作れますが、出力ごとに確認が必要です。形を一度トレースし、必要なサイズを描画して、公開前に最小のアイコンを調べます。

最終更新 2026年10月22日

## トレースで形を保てる図案から始めます

架空の園芸サイトに、無地の背景へ葉と茎を単色で描いたビットマップのロゴがあります。必要なのは、拡大縮小できるロゴ、透明なPNG、ブラウザのタブでも見分けられるファビコンです。[画像からSVG](https://abox.tools/ja/image-to-svg/)、[SVGから画像](https://abox.tools/ja/svg-to-image/)、[画像からICO](https://abox.tools/ja/image-to-ico/)の順で使います。

各ツールの役割は、輪郭のトレース、画素への描画、アイコン素材のまとめと異なります。この方法に向くのは、単純な単色の形です。トレースツールは単一のSVGパスを作り、フルカラーのロゴ、写真、グラデーション、レイヤー付きのイラストを再構築するものではありません。そうした細部が図案の特徴なら、元のデザインデータを入手してください。すでに良いSVGがある場合は、トレースを省きます。

## 最も鮮明な元画像を選びます

手に入る最良の元ビットマップを使います。ウェブページのスクリーンショットには、圧縮の跡、色の付いた背景、無関係な文字が含まれることがあります。拡大しても、失われた細部は戻りません。この例では、葉の周囲に余白を持たせた正方形の画像を使います。

図案に含めるものを決めます。葉と茎は一緒に残しますが、園芸サイトの名前までファビコンに収める必要はありません。比較用に元画像を別に保管してください。元画像が小さかったりぼけていたりすれば、できあがる形状は拡大縮小できても、トレース自体は近似です。

## 一度トレースして輪郭を確認します

[画像からSVG](https://abox.tools/ja/image-to-svg/)でビットマップを開きます。トレースした形を元画像と比べ、葉の先端、茎との接合部、意図して設けた隙間を確認します。前景の選択と修正の操作で不要な領域を取り除き、平滑化を変えた後も結果を確認してください。

滑らかな線が、必ずしも忠実な線とは限りません。平滑化が強すぎると葉が楕円になり、弱すぎると圧縮の小さなノイズが固定した形状として残ることがあります。[トレースのガイド](https://abox.tools/ja/guides/trace-an-image-into-an-svg/)で選び方を説明しています。採用する結果を`leaf-master.svg`として保存します。今後の各サイズの画像は、小さくしたPNGを拡大せず、このマスターから作ります。

![画像からSVGで、ステンシルのビットマップ例とトレースした輪郭が並び、修正と平滑化の操作部分が表示されています。](https://abox.tools/screens/turn-a-bitmap-logo-into-website-assets/outline.webp)

ステンシルのサンプルを使ったトレースの操作部分です。ベクターを採用する前に、輪郭と隙間を比べます。形式を変えただけでは、形が正しいことにはなりません。

## 用途ごとにPNGを描画します

`leaf-master.svg`を[SVGから画像](https://abox.tools/ja/svg-to-image/)に読み込みます。この例の正方形の元画像では、透明な1024×1024のPNGを書き出し、`leaf-icon-source.png`と名付けます。これは例で使う作業サイズで、すべてのロゴに必要な条件ではありません。縦横比を保ち、余白を確認してください。正方形に押し込むために、正方形でない図案を引き伸ばさないでください。必要な余白は後でアイコンツールが加えられます。

画像化のツールで寸法を選びます。必要な画素を直接描画できるなら、別途リサイズする必要はありません。ウェブサイトのロゴ配置にもPNGが必要なら、その場所に合うサイズを書き出し、`leaf-header.png`のように用途が分かる名前にします。ベクターを使える場所のためにSVGも残してください。

書き出したPNGを開き、輪郭と透明度を確認します。白いプレビューだけでは、背景が透明かどうか分かりません。[SVGからPNGのガイド](https://abox.tools/ja/guides/convert-an-svg-to-png/)では寸法と背景の選択を説明しています。

## ウェブサイトのアイコンをまとめます

`leaf-icon-source.png`を[画像からICO](https://abox.tools/ja/image-to-ico/)に読み込みます。ウェブサイト用の出力と、必要なアイコンサイズを選んでください。生成されたICO、ウェブ用PNG、付属する参照用ファイルは一緒に保管します。それぞれの役割は[ファビコンのガイド](https://abox.tools/ja/guides/make-a-favicon/)で説明しています。

このツールはWindowsとmacOSのアプリアイコンにも対応しています。ICNSはmacOS向けの作業で使う形式です。ウェブサイトに、ツールが生成できる全形式が必要なわけではありません。用途に合う出力を選びます。パッケージを生成しても設置は済んでいません。サイトで使うパスに素材を置き、アイコンへの参照を更新してください。

![アイコンツールで、サンプル画像が選択した各出力サイズで表示されています。](https://abox.tools/screens/turn-a-bitmap-logo-into-website-assets/sizes.webp)

サンプル図案のサイズ別プレビューです。上の大きな元画像だけでなく、最小のアイコンそのものを確認します。

## 最小の版は別に判断します

16×16ピクセルのアイコンを実際の表示サイズで確認してから、大きな版も調べます。1024ピクセルではきれいな葉でも、タブのアイコンでは茎が消えたり、細い隙間が閉じたりすることがあります。元画像の画素を増やしても、16ピクセルですべての細部を見分けられるようにはできません。

小さなアイコンがうまく見えない場合は、図案に戻り、意図して単純化します。茎を太くするか、輪郭を簡潔にするかはデザイン上の判断です。変換設定を変えても、図案の特徴を代わりに決めてはくれません。図案そのものを描き直す必要があるとき、これらのツールは汎用の描画エディタの代わりにはなりません。

透明な出力は、明るい背景と暗い背景の両方で確認します。暗い葉は暗い面に溶け込むことがあります。一つの表現で両方に対応できないなら、元データから意図した別の版を用意し、必要な書き出しと確認を繰り返してください。

## 用途が分かる素材一式を渡します

| ファイル | 用途 |
| --- | --- |
| `leaf-master.svg` | 採用した拡大縮小可能な図案と、今後の書き出し元 |
| `leaf-header.png` | ページ上の配置に合わせたサイズの画像ロゴ |
| ウェブ用アイコン一式 | ICOとPNGの素材、および必要なウェブサイトの参照ファイル |

大きいアイコン用の元PNGは作業ファイルと一緒に残します。最終出力をそれぞれ開いて寸法を確認し、実際のサイトに設置したアイコンも調べてください。古いアイコンがキャッシュされているなら、新しいブラウザでのアクセスでも確認します。ファイル処理はローカルですが、公開するとサイトが配信する場所で出力を利用できるようになります。公開する意図があり、使用する権利を持つ図案を使ってください。
