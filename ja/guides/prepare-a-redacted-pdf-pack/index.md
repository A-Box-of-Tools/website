# 相手に渡す黒塗り済みPDF資料を準備する

役立つ確認用資料には、相手に必要なページを入れ、不要な私的情報を除きます。架空のワークショップ資料を使い、ページの選択から確認済みの最終添付まで進めます。

最終更新 2026年10月22日

## 資料をまとめ、私的な情報を取り除いてから仕上げます

まず[PDF結合](https://abox.tools/ja/merge-pdf/)でページを選び、順序を整えます。次に[PDFの黒塗り](https://abox.tools/ja/redact-pdf/)で、まとめた文書から私的な文字情報を取り除きます。資料の用途を伝えるのに役立つなら宛先の透かしを加え、完成したファイルを小さくする必要がある場合だけ圧縮します。

これらのツールは、ブラウザ内でファイルをローカル処理します。各段階の結果をダウンロードして次のツールに読み込ませます。続けて処理するリンクが用意されていれば、それで結果を渡すこともできます。原本と作業用コピーは、送信する添付ファイルとは別のフォルダに保管してください。

## 例：ワークショップの確認担当者に渡す4ページ

Morganが架空のワークショップ計画を確認します。元の資料には、Morganには不要な個人の電話番号と内部向けの費用も含まれています。ツールを開く前に、ページのチェックリストを作ります。

| 元ファイルのページ | 用途 |
| --- | --- |
| `outline.pdf`の1、3ページ | 概要と予定表 |
| `delivery.pdf`の2ページ | 搬入の手配 |
| `equipment.pdf`の1ページ | 機材一覧 |

この順序で4ページを出力します。不要なページを最初から除外するほうが、残してから私的な情報をすべて取り除くより確認しやすくなります。残した資料を読み手が理解できるよう、必要な文脈は保ってください。

## 1. ページを選び、順序を整えます

元のPDFを[結合ツール](https://abox.tools/ja/merge-pdf/)に読み込みます。必要なページを残し、読む順序に並べてください。ページを削除したり移動したりすると、作業一覧のページ番号も変わります。すでに変更した一覧に元の番号を当てはめず、元ファイル名と内容をチェックリストに照らして確認します。

`01-selected.pdf`を保存し、開きます。4ページであること、順序が正しいこと、予定表の欠落や余分な機材メモがないことを確認してください。「次のページを参照」などの参照も、まだ意味が通るか確認します。[結合と分割のガイド](https://abox.tools/ja/guides/merge-and-split-pdf-files/)では、ページの組み合わせで保持されるものと引き継げないものを説明しています。

## 2. まとめた資料から私的な文字情報を取り除きます

`01-selected.pdf`を[PDFの黒塗り](https://abox.tools/ja/redact-pdf/)に読み込みます。電話番号と内部向けの費用を検索し、一致した箇所を確認して、取り除く必要がある箇所をすべて選びます。ヘッダー、フッター、繰り返し記載された連絡先も確認してください。自動のパターン検出は候補を探す助けになりますが、この相手に何を見せる必要があるかは判断しません。

黒塗りツールは対応する文字の描画命令を取り除き、出力を確認してからダウンロードを提供します。通常のPDFエディタで描いた濃い四角は、その下に元の文字を残すことがあります。[PDFの黒塗りガイド](https://abox.tools/ja/guides/redact-a-pdf/)に従い、文字を読み取れないという報告が出た場合や、文書を確実に処理できない場合は中止してください。

`02-redacted.pdf`を保存し、ダウンロードしたファイルを開き直します。取り除いた箇所と、その周囲の情報を確認します。削除した値を検索し、該当する領域を選択してコピーしてみてください。有用な確認ですが、あらゆる文書に通用する証明ではありません。画像、読み取れないフォントの符号化、未対応の内容は、文字検索では見つからないことがあります。

![PDFの黒塗りツールの検索欄と、任意で使える機密情報の検出パターン。請求書の識別情報を使った例が入力されています。](https://abox.tools/screens/prepare-a-redacted-pdf-pack/find.webp)

取り除くと決めた値を検索し、一致箇所を確認します。ここに示した請求書の検索語は、別の文書にも使える完全なチェックリストではありません。

## スキャンしたページは、まず画素を黒塗りします

スキャンは画像です。検索可能なOCR文字層を取り除いても、画像上に見えている文字は消えません。検索で何も見つからないことは、スキャンの黒塗りが済んだ証拠にはなりません。

元の写真がある場合は、[画像の黒塗り](https://abox.tools/ja/redact-image/)を使ってから、書き出した画像を[画像からPDF](https://abox.tools/ja/images-to-pdf/)でまとめます。書き出した画素を確認し、その後にできあがったPDFも確認してください。この方法は[画像の黒塗り](https://abox.tools/ja/guides/redact-an-image/)と[画像をまとめるガイド](https://abox.tools/ja/guides/combine-images-into-a-pdf/)で説明しています。既存のスキャンPDFを、これらのツールへ画像として入力することはできません。適切な元画像に戻るか、その形式に対応する手順を使ってください。

## 3. 必要なら宛先と用途を加えます

`02-redacted.pdf`を[PDFの透かし](https://abox.tools/ja/watermark-pdf/)に読み込み、「ワークショップ確認用 - Morgan」を加えます。`03-marked.pdf`として保存してください。日付、図、小さな表が読めるように、すべてのページで透かしを確認します。[透かしのガイド](https://abox.tools/ja/guides/watermark-a-pdf/)では配置と、その印でできることの限界を説明しています。

透かしは、読み手に想定した用途を伝えます。転送、コピー、撮影を防ぐものではなく、黒塗りの代わりにもなりません。その表示が役に立たない場合は省きます。

## 4. 完成したファイルに必要な場合だけ圧縮します

送信先の添付サイズ上限を確認します。透かしを付けたファイルが十分に収まるなら、そのまま使います。そうでなければ、コピーを[PDF圧縮](https://abox.tools/ja/compress-pdf/)で試し、入力と結果を比較してください。短い文字主体の文書では、ほとんど小さくならないこともあります。

実際に読みやすい表示サイズで、機材の表と小さな文字を読んでください。Morganが読めなくなるなら、添付が小さくなっても改善とはいえません。[圧縮のガイド](https://abox.tools/ja/guides/make-a-pdf-smaller/)では、何によって容量が減るかを説明しています。選んだ最終版を`workshop-review-morgan.pdf`と名付けます。

## 実際に送信する添付ファイルを確認します

途中のプレビューではなく、最後にダウンロードしたファイルを開きます。操作のたびに別の出力ができているので、最後の添付ファイルを改めて確認してください。

- 最終的な順序で4ページすべてを数え、読みます。
- 削除箇所を確認し、検索とコピーの確認を繰り返します。
- 宛先の表示と、圧縮後の読みやすさを確認します。
- ファイルサイズ、プロパティ、ファイル名に意図しない情報がないか確認します。
- 添付時には作業用コピーではなく、確認済みのファイルを選びます。

最初にページを選ぶと、確認対象を絞れます。その後に黒塗りを行い、透かしと圧縮でコピーを仕上げます。相手がパスワード付きPDFを受け付け、保護が必要なら、これらの編集を終えてから保護してください。原本は別に保管し、確認済みの添付だけを送ります。
