# QRコードを作り、読めることを証明する方法

QRの高くつく失敗はコードを作ることではありません。ポスターが誤字に向かって読み取られると現地で知ることです。ここでは生成と検証はふたつの道具で、刷る前に2番目を走らせるのにかかるのは1分。印刷が発送してしまうはずだった事故を、ほぼすべて捕まえます。

[QRコード・バーコード読み取りツールを開く](https://abox.tools/ja/qr-barcode-reader/): コードにカメラを向けるか、写った画像を置いてください。読むのはここだけ、ほかのどこでもありません。

最終更新 2026年8月26日

## 短い答え

1. **作る。** [QR・バーコードメーカー](https://abox.tools/ja/qr-barcode/)を開いて用件を選び——リンク、Wi-Fiネットワーク、連絡先カード——コードが運ぶことになる正確な文字列を確認します。ページはそれを隠す代わりに見せてくれます。印刷にはSVG、画面にはPNGを書き出しましょう。
2. **1枚刷る。**実寸で、実際の紙に、二百枚の印刷の前に。
3. **証明する。**試し刷りをスマートフォンで撮り——斜めから、その場所の照明で——写真を[QR・バーコードリーダー](https://abox.tools/ja/qr-barcode-reader/)にドロップします。デコードされた中身と、リンクなら実際に到達するホストが表示されます。意図したものと一致すれば、印刷は安全です。

どちらの道具もブラウザーで動き、どこにも何も送りません。Wi-Fiコードにとってそれは、中のパスワードが他人のサイトに一度も打ち込まれていないという意味です。

![アドレスを入力したQR生成ツール。できあがったコードと、そのバージョン・誤り訂正レベル・残りの容量が出ている。](https://abox.tools/screens/make-a-qr-code-and-prove-it-scans/made.webp)

コードが、できました。

## 検証が実際に捕まえるもの

- **誤字。**いちばんよくある故障はコードではなく、中のURLです。読み返しは、貼り付けたつもりのものではなく、実際にエンコードされたものを試す唯一の点検です。
- **サイズと距離。**ホールの向こうから読むコードは、名刺の上のコードより太いモジュールが要ります。人が立つ場所から試し刷りを撮るのが正直なテストです。メーカーの誤り訂正レベルは、各レベルが密度でいくら払うかをはっきり教えてくれます。
- **色。**明るい地に暗く刷られたコードは読めます。コントラストの低いブランドパレットは、読めないことがよくあります。このリーダーはたいていのスマートフォンより粘ります。*リーダーが*写真に手こずるようなら、ロビーのいちばん古い端末に勝ち目はまったくありません。
- **折り目と反射。**リード・ソロモン訂正のおかげで、一部が隠れたコードもまだ読めます——あなたが選んだレベルまでは。風雨にさらされるポスターには最高レベルと、その代償として少し密になるコードを与える価値があります。

![同じ画像を渡した読み取りツール。コードに入っているアドレス、シンボル体系、そして画像のどこで見つけたかを報告している。](https://abox.tools/screens/make-a-qr-code-and-prove-it-scans/read.webp)

そして同じ画像を別のツールで読み返したところ。出来損ないのコードを捕まえられる試験はこれだけです。読み取り側は見つけた内容を表示するだけで、開きはしません。

## 同じリーダーを、自分のものではないコードに

検証は、他人が刷ったQRを開く安全な方法でもあります。リーダーは*何かが開くより前に*アドレス全体と実際に到達するホストを表示し、リンクを変装させる手口を名指しします。@の前のユーザー名、そっくりの字形、リダイレクト。パーキングメーターのステッカーはその検査に値しますし、学会の名札もそうです。何もあなたの代わりに開かれず、読み取った内容はどこにも送信されません。

## 毎週やるなら

作ることと確かめることがふたつのページに住んでいるのは意図的です。それぞれがひとつの仕事だけをし、それぞれが単独で、何もあなたのマシンを離れないことを証明できます。それでいて、どちらもオープンソースです。MITライセンス、依存なしのESモジュール——メーカーのエンコーダーとリーダーのリード・ソロモンデコーダー、それぞれを説明するREADMEつきで。

毎週あなたの机からコードが旅立つなら、コードエージェントを[リポジトリ](https://github.com/A-Box-of-Tools/website)に向かわせ、生成した直後に描いたコードをデコーダーへ通し返すページを頼みましょう。書き出しのたびにセルフテストが走ることになります。モジュールは読まれるために書かれており、持ち去ることこそライセンスの存在理由です。
