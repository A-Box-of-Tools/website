# 写真の要件：アイルランド、パスポート

Department of Foreign Affairsが公表し、2026-09-17に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

最終更新 2026-09-17

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | ⁦35 x 45⁩ mm、300 dpi |
| 頭、あごから頭頂まで | 70.0%から80.0% (⁦31.5–36⁩ mm)（目安） |
| 目の高さ、下から | 50.0%から60.0% (⁦22.5–27⁩ mm)（目安） |
| 背景 | 白、薄いグレー、またはクリーム色 |
| アップロードの規定 | 公表なし——これは紙焼き用です |

[この写真を作る](https://abox.tools/ja/id-photo/#ie-passport) この規定を選んだ状態で写真ツールを開きます。ブラウザで動き、写真をアップロードしません。アカウントも透かしもありません。

## この規定の補足

- 紙の申請では同一の写真が4枚必要で、そのうち2枚の裏面に証人が署名と押印をします。⁦35 x 45⁩～⁦38 x 50⁩ mmが認められます。このツールでは、証明写真機で作られる小さいほうの寸法を使います。
- オンライン申請は別の要件です。頭から胴体の中央まで入る、少なくとも ⁦715 x 951⁩ ピクセルの広い構図の写真を提出すると、フォーム側で切り抜かれます。ここで切り抜いた画像ではなく、元の写真を使ってください。
- 頭の高さの範囲が公表されていないため、代わりにICAOの数値を表示しています。この数値を外れても不適合とは判定しません。規定の文章に沿って構図を合わせれば、数値もそれに応じて決まります。

## 数値の出典

Department of Foreign Affairsより書き起こし — ireland.ie, Passport photo guidelines。2026-09-17に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
