# 写真の要件：スペイン、運転免許証

Dirección General de Tráficoが公表し、2026-09-21に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

最終更新 2026-09-21

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | ⁦26 x 32⁩ mm、300 dpi |
| 頭、あごから頭頂まで | 70.0%から80.0% (⁦22.4–25.6⁩ mm)（目安） |
| 目の高さ、下から | 50.0%から60.0% (⁦16–19.2⁩ mm)（目安） |
| 背景 | 無地で明るい色。具体的な色の指定なし |
| アップロードの規定 | 公表なし——これは紙焼き用です |

[この写真を作る](https://abox.tools/ja/id-photo/#es-driving-licence) この規定を選んだ状態で写真ツールを開きます。ブラウザで動き、写真をアップロードしません。アカウントも透かしもありません。

## この規定の補足

- DNIと同じ小さな ⁦32 x 26⁩ mmで、カラー、無地の背景です。DNIは白い背景が必要ですが、こちらは無地であれば構いません。2024年11月6日以降、DGTがすでに写真を保有していれば提出は不要で、更新を行う医療センターでもその場で撮影します。これはそれ以外の場合に使います。
- 頭の高さの範囲が公表されていないため、代わりにICAOの数値を表示しています。この数値を外れても不適合とは判定しません。規定の文章に沿って構図を合わせれば、数値もそれに応じて決まります。

## 数値の出典

Dirección General de Tráficoより書き起こし — sede.dgt.gob.es, Renovación de permiso próximo a caducar。2026-09-21に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
