# 写真の要件：カナダ、市民権

Immigration, Refugees and Citizenship Canadaが公表し、2026-09-19に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

最終更新 2026-09-19

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | ⁦50 x 70⁩ mm、300 dpi |
| 頭、あごから頭頂まで | 44.3%から51.4% (⁦31–36⁩ mm) |
| 目の高さ、下から | 55.0%から72.0% (⁦38.5–50.4⁩ mm)（目安） |
| 背景 | 白または無地の明るい色 |
| オンライン申請用の写真 | ⁦420 x 588⁩ px以上、JPEG、4.00 MBまで |

[この写真を作る](https://abox.tools/ja/id-photo/#ca-citizenship) この規定を選んだ状態で写真ツールを開きます。ブラウザで動き、写真をアップロードしません。アカウントも透かしもありません。

## この規定の補足

- アップロードする前に読んでください。カナダはオンライン申請で「何も変更せずカメラから直接保存した」ファイルを求めます。切り抜きも変更なので、写真店のファイルを確認したり紙の申請用の写真を作ったりするために使ってください。指定される最低値 ⁦420 x 540⁩ ピクセルは、規定の ⁦50 x 70⁩ mmと縦横比が合いません。⁦420 x 588⁩ なら縦横比が合い、両方の最低値も満たします。約240 kBが推奨され、上限は4 MBです。
- 目の位置が公表されていないため、頭を写真の中央に置いたときの目の位置を範囲として表示します。要件ではなく目安なので、赤く表示することはありません。

## 数値の出典

Immigration, Refugees and Citizenship Canadaより書き起こし — canada.ca, Citizenship photo specifications。2026-09-19に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
