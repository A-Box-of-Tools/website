# 写真の要件：アメリカ合衆国、パスポートとグリーンカード

U.S. Department of Stateが公表し、2026-09-17に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

最終更新 2026-09-17

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | ⁦51 x 51⁩ mm、300 dpi |
| 頭、あごから頭頂まで | 49.0%から68.6% (⁦25–35⁩ mm) |
| 目の高さ、下から | 54.9%から68.6% (⁦28–35⁩ mm)（目安） |
| 背景 | 白またはオフホワイト |
| オンラインでの写真アップロード | ⁦600 x 600⁩ px以上、JPEG、54.0 KBから10.00 MB |

[この写真を作る](https://abox.tools/ja/id-photo/#us-passport) この規定を選んだ状態で写真ツールを開きます。ブラウザで動き、写真をアップロードしません。アカウントも透かしもありません。

## この規定の補足

- 正方形で、広く使われている正方形のパスポート写真はこれだけです。⁦2 x 2⁩インチ、つまり51 x 51 mm。
- 頭部は25から35 mmのどこにあってもよく、ICAOの規則よりずっと幅があります。目の位置も割合ではなく下端からの実寸で測ります。
- 現在のアップロード規定はファイル容量だけで、54 KB～10 MBのJPEG、PNG、HEICです。以前のピクセル寸法と240 KBの上限、目の位置の指定はなくなりました。ここで作る正方形は印刷用の ⁦2 x 2⁩ インチを300 dpiにしたものですが、許容範囲内のより大きい正方形も認められます。

## 数値の出典

U.S. Department of Stateより書き起こし — travel.state.gov, Passport Photos / Uploading a Digital Photo。2026-09-17に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
