# 写真の要件：オランダ、パスポート、身分証明書、運転免許証

Rijksdienst voor Identiteitsgegevensが公表し、2026-09-17に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

最終更新 2026-09-17

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | ⁦35 x 45⁩ mm、400 dpi |
| 頭、あごから頭頂まで | 57.8%から66.7% (⁦26–30⁩ mm) |
| 目の高さ、下から | 50.0%から60.0% (⁦22.5–27⁩ mm)（目安） |
| 背景 | 白、薄いグレー、または薄い青 |
| アップロードの規定 | 公表なし——これは紙焼き用です |

[この写真を作る](https://abox.tools/ja/id-photo/#nl-passport) この規定を選んだ状態で写真ツールを開きます。ブラウザで動き、写真をアップロードしません。アカウントも透かしもありません。

## この規定の補足

- 頭の高さの範囲は26～30 mmで、数値から想像するより小さめです。写真の58～67%に相当し、ICAOの70～80%より小さくなります。ICAO規定に合わせた切り抜きではオランダの申請用として顔が大きすぎるため、この項目で確認できます。
- ほかにも2つの公表値がありますが、このツールでは使いません。耳を除いた顔の幅は16～20 mm、11歳未満の子どもは頭の高さが19 mmでも認められます。最低解像度が400 dpiのため、この写真の出力ピクセル数はほかのものより多くなります。
- 目の位置が公表されていないため、頭を写真の中央に置いたときの目の位置を範囲として表示します。要件ではなく目安なので、赤く表示することはありません。

## 数値の出典

Rijksdienst voor Identiteitsgegevensより書き起こし — Fotomatrix 2020, photo specification guidelines。2026-09-17に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
