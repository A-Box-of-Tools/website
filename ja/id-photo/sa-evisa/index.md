# 写真の要件：サウジアラビア、電子ビザ

Saudi eVisa, visa.visitsaudi.comが公表し、2026-09-19に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

最終更新 2026-09-19

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | 印刷サイズなし——この規格はウェブ書式用です |
| 頭、あごから頭頂まで | 70.0%から80.0% |
| 目の高さ、下から | 50.0%から65.0%（目安） |
| 背景 | 白一色 |
| オンライン申請用の写真 | ちょうど⁦200 x 200⁩ px、JPEG、5.0 KBから100.0 KB |

[この写真を作る](https://abox.tools/ja/id-photo/#sa-evisa) この規定を選んだ状態で写真ツールを開きます。ブラウザで動き、写真をアップロードしません。アカウントも透かしもありません。

## この規定の補足

- サウジアラビアの観光電子ビザは、正確に ⁦200 x 200⁩ ピクセル、5～100 KBの正方形で、白い背景、顔が写真の70～80%を占め、両耳が見える写真を求めています。同じ文章には頭の高さがインチでも示されていますが、200ピクセルのファイルには物理的なインチ寸法がないため、ここでは割合を使います。この小ささでは顔以外の細部は残らないので、鮮明な写真から始めてください。
- 目の位置が公表されていないため、頭を写真の中央に置いたときの目の位置を範囲として表示します。要件ではなく目安なので、赤く表示することはありません。

## 数値の出典

Saudi eVisa, visa.visitsaudi.comより書き起こし — Photo Specifications。2026-09-19に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
