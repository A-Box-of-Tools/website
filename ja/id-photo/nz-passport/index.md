# 写真の要件：ニュージーランド、パスポート

Department of Internal Affairsが公表し、2026-09-17に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

最終更新 2026-09-17

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | 印刷サイズなし——この規格はウェブ書式用です |
| 頭、あごから頭頂まで | 70.0%から80.0%（目安） |
| 目の高さ、下から | 50.0%から60.0%（目安） |
| 背景 | 無地の白または薄いグレー |
| オンライン申請用の写真 | ⁦900+ x 1200+⁩ px、⁦4500 x 6000⁩まで、JPEG、250.0 KBから5.00 MB |

[この写真を作る](https://abox.tools/ja/id-photo/#nz-passport) この規定を選んだ状態で写真ツールを開きます。ブラウザで動き、写真をアップロードしません。アカウントも透かしもありません。

## この規定の補足

- この項目で印刷物を作らないのは意図的です。ニュージーランドはデジタル写真を求め、印刷した写真のスキャンは認めないと明記しているため、印刷用シートを無効にしています。
- 縦横比は3:4で、ヨーロッパの印刷写真の ⁦35 x 45⁩ とは異なります。ファイルには上下限があり、250 KB～5 MB、少なくとも ⁦900 x 1200⁩ ピクセル、最大 ⁦4500 x 6000⁩ ピクセルです。
- 頭の高さの範囲が公表されていないため、代わりにICAOの数値を表示しています。この数値を外れても不適合とは判定しません。規定の文章に沿って構図を合わせれば、数値もそれに応じて決まります。

## 数値の出典

Department of Internal Affairsより書き起こし — passports.govt.nz, Passport photos。2026-09-17に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
