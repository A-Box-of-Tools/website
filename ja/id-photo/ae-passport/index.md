# 写真の要件：アラブ首長国連邦、パスポートと身分証明書

Federal Authority for Identity, Citizenship, Customs & Port Securityが公表し、2026-09-19に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

最終更新 2026-09-19

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | ⁦35 x 45⁩ mm、300 dpi |
| 頭、あごから頭頂まで | 70.0%から80.0% (⁦31.5–36⁩ mm) |
| 目の高さ、下から | 50.0%から60.0% (⁦22.5–27⁩ mm)（目安） |
| 背景 | 無地で明るい色。具体的な色の指定なし |
| アップロードの規定 | 公表なし——これは紙焼き用です |

[この写真を作る](https://abox.tools/ja/id-photo/#ae-passport) この規定を選んだ状態で写真ツールを開きます。ブラウザで動き、写真をアップロードしません。アカウントも透かしもありません。

## この規定の補足

- アラブ首長国連邦は幅だけを公表しています。35～40 mmで、顔が写真の70～80%を占めることが求められます。高さはないため、現地の写真店が提供する ⁦35 x 45⁩ を使います。背景は無地で明るい色とだけ指定されています。
- 目の位置が公表されていないため、頭を写真の中央に置いたときの目の位置を範囲として表示します。要件ではなく目安なので、赤く表示することはありません。

## 数値の出典

Federal Authority for Identity, Citizenship, Customs & Port Securityより書き起こし — Personal Photo Specifications。2026-09-19に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
