# 写真の要件：中国、運転免許証

北京市公安局公安交通管理局が公表し、2026-09-21に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | ⁦22 x 32⁩ mm、300 dpi |
| 頭、あごから頭頂まで | 59.4%から68.8% (⁦19–22⁩ mm) |
| 目の高さ、下から | 50.0%から62.0% (⁦16–19.8⁩ mm)（目安） |
| 背景 | 白一色 |

## この規定の補足

- 運転免許証の「1インチ」写真は ⁦22 x 32⁩ mmで、この一覧の写真店の1インチサイズより幅が狭くなります。頭の高さ19～22 mm、幅14～16 mm、白い背景、カラー、6か月以内の撮影、制服なしです。これは北京の交通警察の数値ですが、ほかの都市も同じ寸法を公表しています。
- 目の位置が公表されていないため、頭を写真の中央に置いたときの目の位置を範囲として表示します。要件ではなく目安なので、赤く表示することはありません。

## 数値の出典

北京市公安局公安交通管理局より書き起こし — 驾驶人相片要求。2026-09-21に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
