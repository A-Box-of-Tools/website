# 写真の要件：インド、パスポート

Ministry of External Affairsが公表し、2026-08-20に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

最終更新 2026-08-20

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | ⁦51 x 51⁩ mm、300 dpi |
| 頭、あごから頭頂まで | 49.0%から68.6% (⁦25–35⁩ mm) |
| 目の高さ、下から | 54.9%から68.6% (⁦28–35⁩ mm) |
| 背景 | 白一色 |
| アップロードの規定 | 公表なし——これは紙焼き用です |

[この写真を作る](https://abox.tools/ja/id-photo/#in-passport) この規定を選んだ状態で写真ツールを開きます。ブラウザで動き、写真をアップロードしません。アカウントも透かしもありません。

## この規定の補足

- Passport Sevaは無地の白背景に2 x 2インチの写真を求めます。アメリカと同じ枠です。
- インドの多くの書類が「パスポートサイズ」と言うときに指すのは35 x 45 mmの紙焼きで、この一覧では別の項目になっています。二つは取り替えがききません。

## 数値の出典

Ministry of External Affairsより書き起こし — Passport Seva, photo specifications。2026-08-20に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
