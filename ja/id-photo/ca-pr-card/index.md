# 写真の要件：カナダ、永住権とPRカード

Immigration, Refugees and Citizenship Canadaが公表し、2026-09-19に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

最終更新 2026-09-19

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | ⁦50 x 70⁩ mm、300 dpi |
| 頭、あごから頭頂まで | 44.3%から51.4% (⁦31–36⁩ mm) |
| 目の高さ、下から | 55.0%から72.0% (⁦38.5–50.4⁩ mm)（目安） |
| 背景 | 白一色 |
| オンライン申請用の写真 | ⁦715 x 1000⁩ px以上、JPEG、4.00 MBまで |

[この写真を作る](https://abox.tools/ja/id-photo/#ca-pr-card) この規定を選んだ状態で写真ツールを開きます。ブラウザで動き、写真をアップロードしません。アカウントも透かしもありません。

## この規定の補足

- ほぼすべてのほかの規定が6か月以内を求めるのに対し、ここでは12か月以内の写真が認められます。背景は白のみで、白い服は背景に溶け込むため避けるよう記載されています。オンラインでは ⁦715 x 1000⁩～⁦2000 x 2800⁩ ピクセル、4 MB以下のファイル1個です。適切なスキャンは認められますが、印刷写真をスマートフォンで撮ったものは認められません。紙の申請では印刷写真が2枚必要で、自宅印刷は認められません。
- この規定では、髪を含めず頭蓋骨の頂点まで頭の高さを測ります。このツールの点は、写真に見える髪の頂点を検出します。髪にボリュームがあると測定値が大きくなるため、許容範囲の下半分を目安にしてください。
- 目の位置が公表されていないため、頭を写真の中央に置いたときの目の位置を範囲として表示します。要件ではなく目安なので、赤く表示することはありません。

## 数値の出典

Immigration, Refugees and Citizenship Canadaより書き起こし — canada.ca, Permanent resident photos。2026-09-19に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
