# 写真の要件：日本、マイナンバーカード

地方公共団体情報システム機構が公表し、2026-09-21に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | ⁦35 x 45⁩ mm、300 dpi |
| 頭、あごから頭頂まで | 71.1%から80.0% (⁦32–36⁩ mm)（目安） |
| 目の高さ、下から | 50.0%から60.0% (⁦22.5–27⁩ mm)（目安） |
| 背景 | 無地で明るい色。具体的な色の指定なし |
| オンライン申請用の写真 | ⁦480 x 617⁩ px以上、JPEG、20.0 KBから7.00 MB |

[この写真を作る](https://abox.tools/ja/id-photo/#jp-mynumber) この規定を選んだ状態で写真ツールを開きます。ブラウザで動き、写真をアップロードしません。アカウントも透かしもありません。

## この規定の補足

- 郵送は ⁦45 x 35⁩ mmの印刷写真で、裏面に氏名と生年月日を書きます。オンラインはRGBのJPEG、20 KB～7 MB、各辺480～6000ピクセルです。縦横比は指定されていないため、ここでは印刷写真の比率を使います。図の顔の高さ34 mm、許容差2 mmは目安と明記されているので、目安として表示します。白黒も認められます。画像編集ソフトを使った写真は受け付けられない場合があるため、サイトの例と比較してください。
- 頭の高さの範囲が公表されておらず、写真の縦横比も一般的なものとは異なるため、ICAOの数値はそのまま使えません。表示する範囲は規定の文章から読み取った大まかな目安であり、外れても不適合とは判定しません。

## 数値の出典

地方公共団体情報システム機構より書き起こし — マイナンバーカード総合サイト、顔写真のチェックポイント。2026-09-21に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
