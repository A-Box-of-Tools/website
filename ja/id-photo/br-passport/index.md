# 写真の要件：ブラジル、パスポート

Ministério das Relações Exterioresが公表し、2026-09-19に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

最終更新 2026-09-19

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | ⁦50 x 70⁩ mm、300 dpi |
| 頭、あごから頭頂まで | 44.3%から51.4% (⁦31–36⁩ mm) |
| 目の高さ、下から | 55.0%から72.0% (⁦38.5–50.4⁩ mm)（目安） |
| 背景 | 白一色 |
| アップロードの規定 | 公表なし——これは紙焼き用です |

[この写真を作る](https://abox.tools/ja/id-photo/#br-passport) この規定を選んだ状態で写真ツールを開きます。ブラウザで動き、写真をアップロードしません。アカウントも透かしもありません。

## この規定の補足

- この規定では、髪を含めず頭蓋骨の頂点まで頭の高さを測ります。このツールの点は、写真に見える髪の頂点を検出します。髪にボリュームがあると測定値が大きくなるため、許容範囲の下半分を目安にしてください。
- ブラジルの ⁦5 x 7⁩ cmは、国外の領事館と5歳未満の子ども向けです。ブラジル国内では、それ以上の年齢の人は連邦警察が窓口で撮影します。以前のパスポートに使った写真は認められません。
- 目の位置が公表されていないため、頭を写真の中央に置いたときの目の位置を範囲として表示します。要件ではなく目安なので、赤く表示することはありません。

## 数値の出典

Ministério das Relações Exterioresより書き起こし — Especificações da Fotografia para o Pedido de Passaporte。2026-09-19に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
