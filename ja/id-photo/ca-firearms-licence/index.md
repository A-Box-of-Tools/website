# 写真の要件：カナダ、銃器免許（PAL）

Royal Canadian Mounted Policeが公表し、2026-09-21に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

最終更新 2026-09-21

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | ⁦45 x 57⁩ mm、300 dpi |
| 頭、あごから頭頂まで | 52.6%から78.9% (⁦30–45⁩ mm) |
| 目の高さ、下から | 50.0%から68.0% (⁦28.5–38.8⁩ mm)（目安） |
| 背景 | 白または無地の明るい色 |
| オンライン申請用の写真 | ⁦531 x 673⁩ px以上、JPEG、200.0 KBから6.00 MB |

[この写真を作る](https://abox.tools/ja/id-photo/#ca-firearms-licence) この規定を選んだ状態で写真ツールを開きます。ブラウザで動き、写真をアップロードしません。アカウントも透かしもありません。

## この規定の補足

- 独自の ⁦45 x 57⁩ mmで、頭の高さは少なくとも30 mmです。上限は公表されていないため、表示する範囲の上端はこのツールで設定しています。ファイルは200 KB～6 MBのJPGです。1年以内の写真で白黒も認められますが、色付きの度付きレンズは目が見えていても不可です。初回申請では保証人が印刷写真の裏面に署名します。
- 目の位置が公表されていないため、頭を写真の中央に置いたときの目の位置を範囲として表示します。要件ではなく目安なので、赤く表示することはありません。

## 数値の出典

Royal Canadian Mounted Policeより書き起こし — Photo requirements for a firearms licence。2026-09-21に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
