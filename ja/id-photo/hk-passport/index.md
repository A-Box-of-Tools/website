# 写真の要件：香港、パスポート

Immigration Department, HKSARが公表し、2026-09-19に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

最終更新 2026-09-19

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | ⁦40 x 50⁩ mm、300 dpi |
| 頭、あごから頭頂まで | 64.0%から72.0% (⁦32–36⁩ mm) |
| 目の高さ、下から | 50.0%から60.0% (⁦25–30⁩ mm)（目安） |
| 背景 | 白一色 |
| アップロードの規定 | 公表なし——これは紙焼き用です |

[この写真を作る](https://abox.tools/ja/id-photo/#hk-passport) この規定を選んだ状態で写真ツールを開きます。ブラウザで動き、写真をアップロードしません。アカウントも透かしもありません。

## この規定の補足

- ほとんどの国より幅も高さも大きい ⁦40 x 50⁩ mmで、頭の高さは一般的な32～36 mmです。⁦35 x 45⁩ より顔の周囲に余白ができます。写真をレーザー刻印するため、極端に暗い服も明るい服も避けるよう助言されています。
- 目の位置が公表されていないため、頭を写真の中央に置いたときの目の位置を範囲として表示します。要件ではなく目安なので、赤く表示することはありません。

## 数値の出典

Immigration Department, HKSARより書き起こし — Photograph Requirements for Travel Document。2026-09-19に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
