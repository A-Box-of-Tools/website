# 写真の要件：オーストラリア、パスポート

Australian Passport Officeが公表し、2026-08-20に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

最終更新 2026-08-20

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | ⁦35 x 45⁩ mm、300 dpi |
| 頭、あごから頭頂まで | 71.1%から80.0% (⁦32–36⁩ mm) |
| 目の高さ、下から | 50.0%から60.0% (⁦22.5–27⁩ mm) |
| 背景 | 薄いグレー一色 |
| アップロードの規定 | 公表なし——これは紙焼き用です |

[この写真を作る](https://abox.tools/ja/id-photo/#au-passport) この規定を選んだ状態で写真ツールを開きます。ブラウザで動き、写真をアップロードしません。アカウントも透かしもありません。

## この規定の補足

- ⁦35 x 45⁩ mmの紙焼きに、無地の明るい背景と、顎から頭頂まで32から36 mmの顔。
- 紙の申請では紙焼きが2枚求められます。下のシート書き出しはまさにそのためのものです。

## 数値の出典

Australian Passport Officeより書き起こし — passports.gov.au, Photo guidelines。2026-08-20に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
