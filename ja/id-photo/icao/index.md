# 写真の要件：ICAO標準、あらゆる生体認証旅券類

International Civil Aviation Organizationが公表し、2026-08-20に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

最終更新 2026-08-20

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | ⁦35 x 45⁩ mm、300 dpi |
| 頭、あごから頭頂まで | 70.0%から80.0% (⁦31.5–36⁩ mm) |
| 目の高さ、下から | 50.0%から60.0% (⁦22.5–27⁩ mm) |
| 背景 | 薄いグレー一色 |
| 機械読み取り用の画像 | ⁦413 x 531⁩ px以上、JPEG、ファイルサイズの規定なし |

[この写真を作る](https://abox.tools/ja/id-photo/#icao) この規定を選んだ状態で写真ツールを開きます。ブラウザで動き、写真をアップロードしません。アカウントも透かしもありません。

## この規定の補足

- ⁦35 x 45⁩ mmの枠は世界の大半が発給の基準にしているもので、頭部の高さ70〜80パーセント、目の位置が高さの半分から五分の三のあいだ、というのが以下のすべての規格の元になっている形です。
- Doc 9303は保存画像で両目の中心間が90ピクセル以上あることも求めますが、いまのスマホ写真から413 x 531を切り出せば余裕で満たせます。

## 数値の出典

International Civil Aviation Organizationより書き起こし — Doc 9303, Machine Readable Travel Documents, Part 3。2026-08-20に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
