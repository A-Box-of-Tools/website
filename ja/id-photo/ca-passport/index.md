# 写真の要件：カナダ、パスポート

Immigration, Refugees and Citizenship Canadaが公表し、2026-08-20に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

最終更新 2026-08-20

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | ⁦50 x 70⁩ mm、300 dpi |
| 頭、あごから頭頂まで | 44.3%から51.4% (⁦31–36⁩ mm) |
| 目の高さ、下から | 55.0%から72.0% (⁦38.5–50.4⁩ mm)（目安） |
| 背景 | 白一色 |
| アップロードの規定 | 公表なし——これは紙焼き用です |

[この写真を作る](https://abox.tools/ja/id-photo/#ca-passport) この規定を選んだ状態で写真ツールを開きます。ブラウザで動き、写真をアップロードしません。アカウントも透かしもありません。

## この規定の補足

- 形が唯一の例外です。⁦50 x 70⁩ mmで、ここにあるどれよりも縦長で細いので、別の国向けに切り出したものはそのままでは入りません。
- 顔の高さは顎から頭頂まで31から36 mm。カナダは目の位置を公表していないので、ここに出る範囲は頭が枠の中央にある場合に導かれるものです。規則ではなく目安として扱ってください。
- 写真店が裏面に日付とスタジオ名を印刷する必要があり、これはどんな道具も代わりにはできません。

## 数値の出典

Immigration, Refugees and Citizenship Canadaより書き起こし — canada.ca, Photo requirements for passports。2026-08-20に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
