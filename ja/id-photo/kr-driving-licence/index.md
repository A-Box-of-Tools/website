# 写真の要件：韓国、運転免許証

한국도로교통공단が公表し、2026-09-21に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | ⁦35 x 45⁩ mm、300 dpi |
| 頭、あごから頭頂まで | 71.1%から80.0% (⁦32–36⁩ mm) |
| 目の高さ、下から | 50.0%から60.0% (⁦22.5–27⁩ mm)（目安） |
| 背景 | 白一色 |
| オンライン申請用の写真 | ちょうど⁦413 x 531⁩ px、JPEG、500.0 KBまで |

[この写真を作る](https://abox.tools/ja/id-photo/#kr-driving-licence) この規定を選んだ状態で写真ツールを開きます。ブラウザで動き、写真をアップロードしません。アカウントも透かしもありません。

## この規定の補足

- 印刷用はパスポートと同じで、頭頂からあごまで32～36 mm、白い背景、写真用紙のみ、歯を見せず、編集なしです。オンラインは特に厳密で、500 KB以下のJPG、⁦413 x 531⁩ ピクセルが指定されます。幅395～431、高さ507～550の範囲外は受け付けられません。
- 目の位置が公表されていないため、頭を写真の中央に置いたときの目の位置を範囲として表示します。要件ではなく目安なので、赤く表示することはありません。

## 数値の出典

한국도로교통공단より書き起こし — 안전운전 통합민원, 허용되는 사진 규격。2026-09-21に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
