# 写真の要件：イギリス、パスポート

HM Passport Officeが公表し、2026-08-20に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

最終更新 2026-08-20

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | ⁦35 x 45⁩ mm、300 dpi |
| 頭、あごから頭頂まで | 64.4%から75.6% (⁦29–34⁩ mm) |
| 目の高さ、下から | 50.0%から60.0% (⁦22.5–27⁩ mm) |
| 背景 | 薄いグレーまたはクリーム |
| オンライン申請用のデジタル写真 | ⁦600 x 750⁩ px以上、JPEG、50.0 KBから10.00 MB |

[この写真を作る](https://abox.tools/ja/id-photo/#uk-passport) この規定を選んだ状態で写真ツールを開きます。ブラウザで動き、写真をアップロードしません。アカウントも透かしもありません。

## この規定の補足

- 頭部は顎から頭頂までで測り、29から34 mmでなければなりません。ICAOの範囲よりはっきり短いので、ICAOの規則で切り出した写真が頭が大きすぎるとしてここで断られることがあります。
- デジタルの規則には上限だけでなく下限もあります。50 KB未満は小さすぎるとして受け付けられません。

## 数値の出典

HM Passport Officeより書き起こし — gov.uk, Passport photo requirements。2026-08-20に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
