# 写真の要件：インド、SSC / UPSCオンライン願書の写真

Staff Selection Commission / UPSCが公表し、2026-08-20に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

最終更新 2026-08-20

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | 印刷サイズなし——この規格はウェブ書式用です |
| 頭、あごから頭頂まで | 60.0%から80.0%（目安） |
| 目の高さ、下から | 52.0%から68.0%（目安） |
| 背景 | 白一色 |
| オンライン申請用の写真 | ちょうど⁦200 x 230⁩ px、JPEG、20.0 KBから50.0 KB |

[この写真を作る](https://abox.tools/ja/id-photo/#in-exam-photo) この規定を選んだ状態で写真ツールを開きます。ブラウザで動き、写真をアップロードしません。アカウントも透かしもありません。

## この規定の補足

- これらの願書が実際に通すかどうかを決めるのは三つの数字です。⁦200 x 230⁩ピクセル、JPEG、そして20～50 KBの範囲です。両端とも見られます。12 KBのファイルは小さすぎるとして弾かれ、60 KBのものは大きすぎるとして弾かれます。
- 頭と肩の入れ方は寸法ではなく言葉で書かれているので、ここの範囲は願書の見本画像から起こした目安です。
- 印刷サイズはありません。印刷するものがないからです。これはウェブ書式用のファイルで、シート書き出しはこの規格では無効になります。

## 数値の出典

Staff Selection Commission / UPSCより書き起こし — Notice of Examination, photograph and signature specifications。2026-08-20に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
