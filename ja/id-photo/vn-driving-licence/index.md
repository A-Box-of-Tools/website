# 写真の要件：ベトナム、運転免許証

Cục Cảnh sát giao thông, Bộ Công anが公表し、2026-09-21に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | ⁦30 x 40⁩ mm、300 dpi |
| 頭、あごから頭頂まで | 65.0%から80.0% (⁦26–32⁩ mm)（目安） |
| 目の高さ、下から | 50.0%から62.0% (⁦20–24.8⁩ mm)（目安） |
| 背景 | 白一色 |
| オンライン申請用の写真 | ⁦473 x 630⁩ px以上、JPEG、700.0 KBまで |

[この写真を作る](https://abox.tools/ja/id-photo/#vn-driving-licence) この規定を選んだ状態で写真ツールを開きます。ブラウザで動き、写真をアップロードしません。アカウントも透かしもありません。

## この規定の補足

- オンラインでの免許証の交換や再交付向けです。白い背景の ⁦3 x 4⁩ cm、少なくとも ⁦473 x 630⁩ ピクセル、700 KB以下です。省のページが青を指定していても、警察のポータルは白を指定しています。白と黒の服を避け、頭の傾きを5度以内にし、太いフレームの眼鏡や濃い色の眼鏡は外してください。
- 頭の高さの範囲が公表されておらず、写真の縦横比も一般的なものとは異なるため、ICAOの数値はそのまま使えません。表示する範囲は規定の文章から読み取った大まかな目安であり、外れても不適合とは判定しません。

## 数値の出典

Cục Cảnh sát giao thông, Bộ Công anより書き起こし — Cổng dịch vụ công cấp đổi, cấp lại giấy phép lái xe。2026-09-21に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
