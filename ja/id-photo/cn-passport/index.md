# 写真の要件：中国、パスポートとビザ

National Immigration Administrationが公表し、2026-08-20に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

最終更新 2026-08-20

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | ⁦33 x 48⁩ mm、300 dpi |
| 頭、あごから頭頂まで | 58.3%から68.8% (⁦28–33⁩ mm) |
| 目の高さ、下から | 50.0%から62.0% (⁦24–29.8⁩ mm)（目安） |
| 背景 | 白一色 |
| オンラインビザ申請へのアップロード | ちょうど⁦354 x 472⁩ px、JPEG、40.0 KBから120.0 KB |

[この写真を作る](https://abox.tools/ja/id-photo/#cn-passport) この規定を選んだ状態で写真ツールを開きます。ブラウザで動き、写真をアップロードしません。アカウントも透かしもありません。

## この規定の補足

- ⁦33 x 48⁩ mmの枠で、ほかのほとんどの国で使われる35 x 45より細く、頭部は顎から頭頂まで28から33 mmです。
- アップロードには上限だけでなく下限もあります。ちょうど354 x 472ピクセルで40 KBから120 KB。これは同じ枠を272 dpiにしたものです。

## 数値の出典

National Immigration Administrationより書き起こし — Published photograph standard for exit and entry documents。2026-08-20に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
