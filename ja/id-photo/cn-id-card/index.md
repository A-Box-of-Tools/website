# 写真の要件：中国、身分証明書

北京市公安局が公表し、2026-09-21に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

最終更新 2026-09-21

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | ⁦26 x 32⁩ mm、300 dpi |
| 頭、あごから頭頂まで | 60.0%から72.0% (⁦19.2–23⁩ mm)（目安） |
| 目の高さ、下から | 50.0%から62.0% (⁦16–19.8⁩ mm)（目安） |
| 背景 | 白一色 |
| アップロードの規定 | 公表なし——これは紙焼き用です |

[この写真を作る](https://abox.tools/ja/id-photo/#cn-id-card) この規定を選んだ状態で写真ツールを開きます。ブラウザで動き、写真をアップロードしません。アカウントも透かしもありません。

## この規定の補足

- 身分証明書はどのパスポートサイズよりも小さい ⁦26 x 32⁩ mmです。白い背景、枠なしで、頭が写真の約3分の2を占め、両耳の付け根の間で測る顔の幅は15 mm、許容差は1 mmです。制服と白い服は不可で、普段眼鏡をかける人は着用します。多くの警察署は自分たちで撮影するか指定の写真店を案内するので、印刷前に確認してください。
- 頭の高さの範囲が公表されておらず、写真の縦横比も一般的なものとは異なるため、ICAOの数値はそのまま使えません。表示する範囲は規定の文章から読み取った大まかな目安であり、外れても不適合とは判定しません。

## 数値の出典

北京市公安局より書き起こし — 居民身份证照片标准，引《居民身份证制证用数字相片技术要求》GA461—2004。2026-09-21に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
