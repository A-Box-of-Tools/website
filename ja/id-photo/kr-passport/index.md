# 写真の要件：韓国、パスポート

외교부 (Ministry of Foreign Affairs)が公表し、2026-09-17に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

最終更新 2026-09-17

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | ⁦35 x 45⁩ mm、300 dpi |
| 頭、あごから頭頂まで | 71.1%から80.0% (⁦32–36⁩ mm) |
| 目の高さ、下から | 50.0%から60.0% (⁦22.5–27⁩ mm)（目安） |
| 背景 | 白一色 |
| オンライン申請用の写真 | ちょうど⁦413 x 531⁩ px、JPEG、ファイルサイズの規定なし |

[この写真を作る](https://abox.tools/ja/id-photo/#kr-passport) この規定を選んだ状態で写真ツールを開きます。ブラウザで動き、写真をアップロードしません。アカウントも透かしもありません。

## この規定の補足

- この規定では、髪を含めず頭蓋骨の頂点まで頭の高さを測ります。このツールの点は、写真に見える髪の頂点を検出します。髪にボリュームがあると測定値が大きくなるため、許容範囲の下半分を目安にしてください。
- 韓国は、ほかの国ではあまり明記されない2点を確認します。ソフトウェアで背景を切り抜いたり置き換えたりしないことと、髪を除いた頭蓋骨の頂点まで頭の高さを測ることです。オンライン申請の推奨値は ⁦413 x 531⁩ ピクセルで、この印刷サイズを300 dpiにした値です。
- 目の位置が公表されていないため、頭を写真の中央に置いたときの目の位置を範囲として表示します。要件ではなく目安なので、赤く表示することはありません。

## 数値の出典

외교부 (Ministry of Foreign Affairs)より書き起こし — 여권안내 — 여권사진 규격 안내 <2022. 10. 개정>。2026-09-17に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
