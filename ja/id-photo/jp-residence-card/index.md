# 写真の要件：日本、在留カード

出入国在留管理庁が公表し、2026-09-21に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

最終更新 2026-09-21

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | ⁦30 x 40⁩ mm、300 dpi |
| 頭、あごから頭頂まで | 55.0%から70.0% (⁦22–28⁩ mm) |
| 目の高さ、下から | 45.0%から60.0% (⁦18–24⁩ mm)（目安） |
| 背景 | 無地で明るい色。具体的な色の指定なし |
| アップロードの規定 | 公表なし——これは紙焼き用です |

[この写真を作る](https://abox.tools/ja/id-photo/#jp-residence-card) この規定を選んだ状態で写真ツールを開きます。ブラウザで動き、写真をアップロードしません。アカウントも透かしもありません。

## この規定の補足

- パスポートより小さく、独自の数値があります。⁦30 x 40⁩ mm、髪の頂点からあごまで25 mm、許容差3 mm、頭上の余白は5 mmです。帽子なし、背景と影なし、6か月以内の撮影で、裏面に氏名を書きます。修整は常に禁止され、鏡像の写真も認められません。スマートフォンの前面カメラは、設定を変えないと鏡像を保存することがあります。
- 目の位置が公表されていないため、頭を写真の中央に置いたときの目の位置を範囲として表示します。要件ではなく目安なので、赤く表示することはありません。

## 数値の出典

出入国在留管理庁より書き起こし — 提出写真の規格。2026-09-21に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
