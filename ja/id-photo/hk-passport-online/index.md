# 写真の要件：香港、パスポート、オンライン申請

Immigration Department, HKSARが公表し、2026-09-19に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

最終更新 2026-09-19

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | 印刷サイズなし——この規格はウェブ書式用です |
| 頭、あごから頭頂まで | 60.0%から75.0%（目安） |
| 目の高さ、下から | 50.0%から62.0%（目安） |
| 背景 | 白一色 |
| オンライン申請用の写真 | ⁦1200 x 1600⁩ px以上、JPEG、5.00 MBまで |

[この写真を作る](https://abox.tools/ja/id-photo/#hk-passport-online) この規定を選んだ状態で写真ツールを開きます。ブラウザで動き、写真をアップロードしません。アカウントも透かしもありません。

## この規定の補足

- 印刷写真を特定の解像度にしたものではありません。オンライン申請では少なくとも ⁦1200 x 1600⁩ ピクセル、5 MB以下のJPEGが必要です。印刷用の4:5に対し、こちらは3:4なので、印刷物を作らない独立した規定です。
- 頭の高さの範囲が公表されておらず、写真の縦横比も一般的なものとは異なるため、ICAOの数値はそのまま使えません。表示する範囲は規定の文章から読み取った大まかな目安であり、外れても不適合とは判定しません。

## 数値の出典

Immigration Department, HKSARより書き起こし — Photograph Requirements for Travel Document。2026-09-19に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
