# 写真の要件：ポーランド、パスポートと身分証明書

Ministerstwo Spraw Wewnętrznych i Administracjiが公表し、2026-09-17に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

最終更新 2026-09-17

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | ⁦35 x 45⁩ mm、300 dpi |
| 頭、あごから頭頂まで | 68.9%から80.0% (⁦31–36⁩ mm) |
| 目の高さ、下から | 44.4%から66.7% (⁦20–30⁩ mm) |
| 背景 | 無地の白または薄いグレー |
| オンライン申請用の写真 | ⁦492 x 633⁩ px以上、JPEG、2.50 MBまで |

[この写真を作る](https://abox.tools/ja/id-photo/#pl-passport) この規定を選んだ状態で写真ツールを開きます。ブラウザで動き、写真をアップロードしません。アカウントも透かしもありません。

## この規定の補足

- この規定では、髪を含めず頭蓋骨の頂点まで頭の高さを測ります。このツールの点は、写真に見える髪の頂点を検出します。髪にボリュームがあると測定値が大きくなるため、許容範囲の下半分を目安にしてください。
- ポーランドは、珍しく目の位置を写真の下端からの距離で公表しています。20～30 mmです。また、髪にボリュームがある場合は、顔自体を小さくしない限り、髪の一部が写真の外に出てもよいとされています。
- 身分証明書のオンライン申請は、少なくとも ⁦492 x 633⁩ ピクセル、2.5 MB以下のファイルで行えます。ここで作るアップロード用画像もこの値です。パスポートは12歳未満の子どもを除きオンライン申請できず、その子ども用は ⁦768 x 1004⁩ を求めています。

Ministerstwo Spraw Wewnętrznych i Administracjiより書き起こし — Nowe zdjęcia do paszportu, instrukcja wykonywania zdjęć。2026-09-17に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
