# 写真の要件：イタリア、身分証明書

Ministero dell’Internoが公表し、2026-09-21に確認したこの書類の写真規定と、顔写真を誰にも送らずに規定を満たす写真を作る方法です。

最終更新 2026-09-21

## 数値

| 測るもの | この規定の公表値 |
| --- | --- |
| 印刷サイズ | ⁦35 x 45⁩ mm、300 dpi |
| 頭、あごから頭頂まで | 70.0%から80.0% (⁦31.5–36⁩ mm) |
| 目の高さ、下から | 51.1%から68.9% (⁦23–31⁩ mm) |
| 背景 | 白または無地の明るい色 |
| アップロードの規定 | 公表なし——これは紙焼き用です |

[この写真を作る](https://abox.tools/ja/id-photo/#it-id-card) この規定を選んだ状態で写真ツールを開きます。ブラウザで動き、写真をアップロードしません。アカウントも透かしもありません。

## この規定の補足

- 電子身分証明書は、イタリアのパスポートにはない数値を公表しています。顔が70～80%を占め、目の位置は下端から23～31 mmです。背景は無地で、薄い青、ベージュ、薄い茶色、薄いグレー、白が推奨されます。背景を除去したり頭をまっすぐにしたりする切り抜きや、修整も禁止されています。撮影時にまっすぐな構図にして、このツールは周囲を整えるだけに使ってください。

## 数値の出典

Ministero dell’Internoより書き起こし — Carta d’identità elettronica, Modalità di acquisizione delle foto。2026-09-21に確認。規則は変わります。上の数字は、目の前の書式と突き合わせるためのものです。

## ツールがこの数値をどう使うか

- 書類の縦横比に切り抜きを固定し、頭と目の範囲を枠内に描きます。規定を読むだけでなく、自分の写真で確認できます。
- 画像を測って頭頂、あご、両方の瞳を見つけます。顔モデルをダウンロードせず、この規定に対して頭が大きすぎるか小さすぎるかをミリ単位で示します。
- 背景色と明るさの均一性を読み取り、問題がある場合はどちらに原因があるかを示します。
- 解像度をファイルに記録した正確なミリ寸法の写真、切り取り線入りのシート、この規定の画素数とファイルサイズに合わせた提出用ファイルを書き出します。
