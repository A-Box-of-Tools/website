Sie müssen uns nicht glauben. Öffnen Sie die DevTools, sehen Sie im Tab „Netzwerk“ zu und erzeugen Sie ein PDF. Keine einzige Anfrage trägt ein Bild, ein Vorschaubild oder einen Dateinamen. Oder trennen Sie die Internetverbindung und erzeugen Sie trotzdem eines.

So lässt sich das Datenschutzversprechen nachprüfen

  • Ihre Bilder haben keinen Weg nach draußen. In der Content-Security-Policy steht jede Adresse, die diese Seite kontaktieren darf, und keine einzige davon gehört uns. Dieses Werkzeug fügt der Liste auch nichts hinzu, denn es hat gar keine eigene Netzfunktion, nicht einmal eine optionale. Es gibt hier keinen Endpunkt, an dem Ihre Dateien landen könnten, und im Code steht auch nichts, das sie dorthin schicken würde, gäbe es einen.
  • Das PDF wird hier geschrieben. Ein PDF ist eine Liste von Objekten und eine Tabelle, wo jedes beginnt, und src/pdf.js schreibt beides. Es wird keine Bibliothek nachgeladen und nichts auf einem Server gerendert, und die fertige Datei geht aus dem Arbeitsspeicher direkt in einen Download.
  • Dem Dokument wird nichts über Sie erzählt. Die meisten Werkzeuge stempeln einem PDF einen Zeitstempel und den Namen des Programms auf, das es erzeugt hat. Dieses schreibt Titel, Autor und Datum nur, wenn Sie sie selbst eintippen. Die Dateinamen Ihrer Bilder tauchen im Dokument nie auf, und etwas über Ihr Gerät ebenso wenig.
  • Was Google lädt und was Google nicht bekommt. Die Werbe- und Messskripte kommen von Google. Keinem von beiden wird irgendetwas über Ihre Bilder übergeben, weder eine Datei noch ein Vorschaubild, ein Name, eine Größe oder eine Anzahl. Jede Zeile, die ein Bild liest, dekodiert oder schreibt, kommt von dieser Domain selbst und steht im Repository.
  • Was der Spenden-Button lädt und was er nicht bekommt. Der Button „Buy me a coffee“ in der Kopfzeile wird von einem Skript von cdnjs.buymeacoffee.com gezeichnet und holt seine Schrift von Google Fonts. Mehr als ein Link ist er nicht. Er meldet keinen Besuch, und über Sie oder Ihre Bilder bekommt er nichts. Solange Sie ihn nicht anklicken, passiert nichts, und was Sie damit ansteuern, ist die Seite von jemand anderem.
  • Es funktioniert offline. Trennen Sie die Netzverbindung, und alles auf dieser Seite arbeitet weiter. Einen einfacheren Beweis gibt es nicht, denn ein Werkzeug, das Ihre Bilder wegschickt, um daraus anderswo ein Dokument machen zu lassen, bliebe an dieser Stelle stehen.

Prüfen Sie es selbst. Nichts davon müssen Sie uns glauben. Ein Build-Skript erzeugt diese Seite aus den Vorlagen und der Konfiguration im Repository, und dieses Skript können Sie lesen und selbst ausführen. Das Ergebnis liegt im Branch dist. Vergleichen Sie also, was ausgeliefert wird, mit dem, was ein Build der Quellen hervorbringt:

Zuerst lesenswert sind config/site.toml für die Content-Security-Policy, sowie src/pdf.js und src/document.js für das gesamte Schreiben der Datei, das nie ans Netz geht.

    So machen Sie aus Bildern ein PDF
    1. Wählen Sie Ihre Bilder aus. Ziehen Sie einen Ordner auf das Auswahlfeld oder suchen Sie die Dateien von Hand heraus. Der Browser liest sie direkt von Ihrer Festplatte, und dabei geht nichts nach draußen.
    2. Bringen Sie die Seiten in die richtige Reihenfolge und drehen Sie, was gedreht werden muss. Aus einem Bild wird eine Seite, in der gezeigten Reihenfolge. Verschieben lässt sich eine Kachel am Griff oder über die Pfeile. Die Drehknöpfe drehen eine Seite um jeweils eine Vierteldrehung, und genau das braucht ein quer eingelesener Scan meistens.
    3. Wählen Sie eine Seitengröße. „Seite an jedes Bild anpassen“ macht jede Seite exakt so groß wie ihr Bild. Nichts wird beschnitten, und weiße Streifen bleiben auch keine übrig. Die benannten Größen, also A4, Letter, Legal und die übrigen, legen jedes Bild stattdessen auf eine feste Seite, mit Rand, wenn Sie einen möchten.
    4. PDF erzeugen und herunterladen. Das Dokument wird auf Ihrem eigenen Gerät geschrieben. Wie lange es dauert, hängt daher von Ihrer Hardware ab und nicht von einer Warteschlange. Die fertige Datei geht direkt in die Downloads Ihres Browsers.

    Fragen

    Werden meine Bilder irgendwohin hochgeladen?

    Nein. Ihr eigener Browser liest die Bilder auf Ihrer eigenen Hardware und schreibt dort auch das PDF. Eine Serverseite hat dieses Werkzeug nicht, und in der Content-Security-Policy der Seite steht jede Adresse, die sie kontaktieren darf; keine davon gehört uns. Anders als einige der übrigen Werkzeuge hier hat dieses nicht einmal eine optionale Netzfunktion.

    Kostet die Umwandlung ins PDF Qualität?

    Bei einem JPEG nicht, jedenfalls in der Standardeinstellung. PDF kann JPEG-Daten direkt aufnehmen, eine Fotografie wandert also Byte für Byte in das Dokument. Sie wird nie dekodiert und nie erneut komprimiert, und das Bild im PDF ist das Bild aus der Datei. Andere Formate müssen neu kodiert werden, weil PDF keinen Filter dafür hat. Es sei denn, Sie wählen die verlustfreie Einstellung, die sie exakt speichert und dafür eine größere Datei kostet.

    Welche Bildformate kann ich verwenden?

    Jedes Standbild, das Ihr Browser dekodieren kann, in der Praxis also JPG, PNG, WebP, GIF, AVIF und auf Apple-Geräten HEIC. Eine eigene Liste, die aktuell gehalten werden müsste, gibt es hier nicht, denn das Dekodieren ist Sache des Browsers und nicht unsere.

    Kann ich Seitengröße und Reihenfolge der Seiten wählen?

    Ja. Seiten können A4, Letter, Legal, A3, A5, Tabloid, eine selbst eingetippte Größe oder exakt die Größe des jeweiligen Bildes sein. Ziehen Sie die Kacheln, um sie umzusortieren, sortieren Sie nach Name oder Datum, drehen Sie beliebige um eine Vierteldrehung und setzen Sie einen Rand in Millimetern.

    Wie viele Bilder kann ich in ein PDF packen?

    Im Werkzeug ist keine Grenze eingebaut. Die praktische Obergrenze setzt der Arbeitsspeicher Ihres Geräts, denn das fertige Dokument wird dort zusammengesetzt, bevor Sie es herunterladen. Als Erstes bekommen das ein paar hundert Handy-Fotos in voller Auflösung zu spüren. Wer in den Einstellungen die längste Seite verkleinert, schiebt diese Grenze weit nach hinten.

    Enthält das PDF meine Dateinamen oder einen Zeitstempel?

    Nein, es sei denn, Sie wollen es. Der Dokumentinformationsblock bleibt leer bis auf den Namen dieses Werkzeugs. Keine Dateinamen, kein Gerätename, kein Benutzername und kein Erstellungsdatum, solange Sie das Häkchen dafür nicht setzen. Das ist Absicht, denn ein PDF ist etwas, das Menschen anderen Menschen schicken.

    Ist es kostenlos, und brauche ich ein Konto?

    Es ist kostenlos, und es gibt kein Konto, keine Anmeldung und keine Testphase. Bezahlt wird die Seite über Werbung, und den Anzeigen wird nichts über Ihre Bilder übergeben.

    Funktioniert es offline?

    Ja. Laden Sie die Seite einmal, trennen Sie dann die Internetverbindung, und sie arbeitet weiter. Das ist zugleich der einfachste Beweis dafür, dass nichts hochgeladen wird. Ein Werkzeug, das Ihre Bilder wegschickt, um daraus anderswo ein Dokument machen zu lassen, bliebe in dem Moment stehen, in dem Sie den Stecker ziehen.
