Wie sich der Datenschutz nachprüfen lässt

  • Ihre Bilder haben keinen Weg nach draußen. Die Content-Security-Policy nennt jede Adresse, die diese Seite kontaktieren darf, und keine davon gehört zu dieser Seite. Dieses Werkzeug fügt der Liste nichts hinzu: Es hat keine eigene Netzfunktion, nicht einmal eine optionale. Es gibt hier keinen Endpunkt, an dem Ihre Dateien gesammelt werden könnten, und nichts im Code, das sie senden würde, gäbe es einen.
  • Das PDF wird hier geschrieben. Ein PDF ist eine Liste von Objekten und eine Tabelle, wo jedes beginnt, und src/pdf.js schreibt beides. Es wird keine Bibliothek nachgeladen, nichts auf einem Server gerendert, und die fertige Datei geht aus dem Arbeitsspeicher direkt an einen Download.
  • Dem Dokument wird nichts über Sie erzählt. Die meisten Werkzeuge stempeln einem PDF einen Zeitstempel und den Namen des Programms auf, das es erzeugt hat. Dieses schreibt Titel, Autor und Datum nur, wenn Sie sie eintippen; die Dateinamen Ihrer Bilder tauchen im Dokument nie auf, und etwas über Ihr Gerät ebenso wenig.
  • Was Google lädt - und was es nicht bekommt. Die Werbe- und Messskripte kommen von Google. Keinem von beiden wird irgendetwas über Ihre Bilder übergeben: keine Datei, kein Vorschaubild, kein Name, keine Größe, keine Anzahl. Jede Zeile, die ein Bild liest, dekodiert oder schreibt, wird von dieser Herkunft ausgeliefert und ist im Repository aufgeführt.
  • Was der Spenden-Button lädt - und was er nicht bekommt. Der Button „Buy me a coffee“ in der Kopfzeile wird von einem Skript von cdnjs.buymeacoffee.com gezeichnet und holt seine Schrift von Google Fonts. Er ist ein Link und nicht mehr: Er meldet keinen Besuch, und ihm wird nichts über Sie oder Ihre Bilder übergeben. Es passiert nichts, solange Sie ihn nicht anklicken, und was Sie damit ansteuern, ist die Seite von jemand anderem.
  • Es funktioniert offline. Trennen Sie die Netzverbindung, und alles auf dieser Seite arbeitet weiter. Das ist der einfachste Beweis von allen: Ein Werkzeug, das Ihre Bilder wegschickt, um daraus ein Dokument machen zu lassen, würde stehen bleiben.

Prüfen Sie es selbst. Nichts davon müssen Sie uns glauben. Diese Seite wird aus den Vorlagen und der Konfiguration im Repository von einem Build-Skript erzeugt, das Sie lesen und selbst ausführen können, und das Ergebnis liegt im Branch dist — Sie können also vergleichen, was ausgeliefert wird, mit dem, was ein Build der Quellen hervorbringt:

    3 Das PDF erzeugen

    PDF herunterladen

    Aus Bildern ein PDF machen

    1. Wählen Sie Ihre Bilder. Ziehen Sie einen Ordner auf das Auswahlfeld oder wählen Sie die Dateien von Hand. Der Browser liest sie direkt von Ihrer Festplatte; dabei wird nichts irgendwohin gesendet.
    2. Bringen Sie die Seiten in die richtige Reihenfolge und drehen Sie, was gedreht werden muss. Aus einem Bild wird eine Seite, in der gezeigten Reihenfolge. Ziehen Sie eine Kachel an ihrem Griff, um sie zu verschieben, oder nehmen Sie die Pfeile; die Drehknöpfe drehen eine Seite um jeweils eine Vierteldrehung, und genau das braucht ein quer eingelesener Scan meistens.
    3. Wählen Sie eine Seitengröße. „Seite an jedes Bild anpassen“ macht jede Seite exakt so groß wie ihr Bild — nichts wird beschnitten, es gibt keine weißen Streifen. Die benannten Größen — A4, Letter, Legal und die übrigen — platzieren jedes Bild stattdessen auf einer festen Seite, mit Rand, wenn Sie einen möchten.
    4. PDF erzeugen und herunterladen. Das Dokument wird auf Ihrem eigenen Gerät geschrieben, wie lange es dauert, hängt also von Ihrer Hardware ab und nicht von einer Warteschlange. Die fertige Datei geht direkt in die Downloads Ihres Browsers.

    Fragen

    Werden meine Bilder irgendwohin hochgeladen?

    Nein. Ihre Bilder werden von Ihrem eigenen Browser auf Ihrer eigenen Hardware gelesen, und das PDF wird dort geschrieben. Dieses Werkzeug hat keine Serverseite, und die Content-Security-Policy der Seite nennt jede Adresse, die sie kontaktieren darf — keine davon gehört zu dieser Seite. Anders als einige der übrigen Werkzeuge hier hat dieses überhaupt keine optionale Netzfunktion.

    Kostet die Umwandlung ins PDF Qualität?

    Bei einem JPEG nicht, in der Standardeinstellung. PDF kann JPEG-Daten direkt aufnehmen, eine Fotografie wird also Byte für Byte in das Dokument kopiert: Sie wird nie dekodiert und nie erneut komprimiert, und das Bild im PDF ist das Bild aus der Datei. Andere Formate müssen neu kodiert werden, weil PDF keinen Filter dafür hat — es sei denn, Sie wählen die verlustfreie Einstellung, die sie exakt speichert, um den Preis einer größeren Datei.

    Welche Bildformate kann ich verwenden?

    Jedes Standbild, das Ihr Browser dekodieren kann, in der Praxis also JPG, PNG, WebP, GIF, AVIF und auf Apple-Geräten HEIC. Es gibt hier keine eigene Liste, die aktuell gehalten werden müsste, denn das Dekodieren ist Sache des Browsers und nicht unsere.

    Kann ich Seitengröße und Reihenfolge der Seiten wählen?

    Ja. Seiten können A4, Letter, Legal, A3, A5, Tabloid, eine selbst eingetippte Größe oder exakt die Größe des jeweiligen Bildes sein. Ziehen Sie die Kacheln, um sie umzusortieren, sortieren Sie nach Name oder Datum, drehen Sie beliebige um eine Vierteldrehung und setzen Sie einen Rand in Millimetern.

    Wie viele Bilder kann ich in ein PDF packen?

    Im Werkzeug ist keine Grenze eingebaut. Die praktische Obergrenze ist der Arbeitsspeicher Ihres Geräts, denn das fertige Dokument wird dort zusammengesetzt, bevor Sie es herunterladen. Ein paar hundert Handy-Fotos in voller Auflösung sind das Erste, was sie zu spüren bekommt; die längste Seite in den Einstellungen zu verkleinern verschiebt diese Grenze weit nach hinten.

    Enthält das PDF meine Dateinamen oder einen Zeitstempel?

    Nein, es sei denn, Sie wollen es. Der Dokumentinformationsblock bleibt leer bis auf den Namen dieses Werkzeugs: keine Dateinamen, kein Gerätename, kein Benutzername und kein Erstellungsdatum, sofern Sie das Häkchen dafür nicht setzen. Das ist Absicht — ein PDF ist etwas, das Menschen anderen Menschen schicken.

    Ist es kostenlos, und brauche ich ein Konto?

    Es ist kostenlos, und es gibt kein Konto, keine Anmeldung und keine Testphase. Die Seite trägt Werbung, und die bezahlt sie; den Anzeigen wird nichts über Ihre Bilder übergeben.

    Funktioniert es offline?

    Ja. Laden Sie die Seite einmal, trennen Sie dann die Internetverbindung, und sie arbeitet weiter. Das ist zugleich der einfachste Beweis dafür, dass nichts hochgeladen wird: Ein Werkzeug, das Ihre Bilder wegschickt, um daraus ein Dokument machen zu lassen, würde in dem Moment stehen bleiben, in dem Sie den Stecker ziehen.
