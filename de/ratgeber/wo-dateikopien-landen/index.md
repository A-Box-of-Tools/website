# Wo landen Ihre Dateikopien?

Lokale Verarbeitung beschreibt, was im Werkzeug geschieht. Gespeicherte, synchronisierte und geteilte Kopien haben eigene Ziele. Verfolgen Sie ein unbedenkliches Handout, um diese Grenzen zu erkennen.

Zuletzt aktualisiert 22. Oktober 2026

## Mit einer unbedenklichen Datei beginnen

Lokale Verarbeitung beschreibt, wo ein Werkzeug Ihre Datei bearbeitet. Der Speicherort Ihres Browsers sowie Cloud-Synchronisierung und Sicherungseinstellungen bestimmen, was anschließend mit der gespeicherten Ausgabe geschieht. Das Schließen des Werkzeugs verwaltet diese Kopien nicht für Sie. Der [Ratgeber zu Uploads für die Verarbeitung](https://abox.tools/de/ratgeber/ist-das-hochladen-von-dateien-sicher/) erklärt diese erste Grenze; dieser Ratgeber verfolgt die gespeicherten Dateien.

Stellen Sie sich `workshop-handout.pdf` mit einem erfundenen Zeitplan und einer Zeichnung vor. Sie exportieren eine kleinere Fassung als `workshop-handout-small.pdf` und kopieren sie anschließend in einen Veranstaltungsordner. Schon bevor eine Sicherung berücksichtigt wird, gibt es ein Original, einen heruntergeladenen Export und eine weitere gespeicherte Kopie.

Lernen Sie Ihre Umgebung mit einer ähnlich unbedenklichen Datei kennen. Sie sollen wissen, wo nützliche Kopien liegen, welche Konten oder Geräte darauf zugreifen können und welche Zwischendateien ihre Aufgabe erfüllt haben.

## Die heruntergeladene Ausgabe finden

Suchen Sie die exportierte Datei in Ihrer Dateiverwaltung und notieren Sie ihren vollständigen Ordnerpfad. Leiten Sie den Speicherort weder aus dem Dateinamen noch daraus ab, dass der Browser die Datei geöffnet hat.

In Chrome können Sie einen Standardordner für Downloads wählen oder bei jedem Download nach einem Ziel fragen lassen. Gewöhnlich ist der Downloadordner des Benutzers voreingestellt, doch Einstellungen können das ändern. Googles [Download-Dokumentation](https://support.google.com/chrome/answer/95759?hl=en) unterscheidet den Browsereintrag von der Datei: Wenn Sie einen Eintrag aus der Downloadliste entfernen, bleibt die gespeicherte Datei auf dem Computer.

Notieren Sie für das Beispiel `Downloads/workshop-handout-small.pdf`. Haben Sie die Datei an einen anderen Ort kopiert, führen Sie diesen zweiten Speicherort gesondert auf. Öffnen Sie beide Dateien, bevor Sie eine davon als überflüssig einstufen.

## Prüfen, ob der Zielordner synchronisiert wird

Ein Ordner, den Sie in der Dateiverwaltung sehen, kann auch mit einem Cloud-Konto verbunden sein. Prüfen Sie seinen tatsächlichen Pfad und die Einstellungen des Synchronisierungsprogramms. Der Name „Dokumente“ bedeutet nicht automatisch, dass die Datei nur auf diesem Computer liegt.

OneDrive kann ausgewählte Ordner sichern und ihren Inhalt auf anderen Geräten verfügbar machen. Microsoft erklärt in seiner [Dokumentation zur Ordnersicherung](https://support.microsoft.com/en-us/onedrive/back-up-your-folders-with-onedrive), wie Sie die einbezogenen Ordner erkennen. Das gilt, wenn die Funktion eingerichtet ist; nicht jeder Dokumentenordner wird automatisch synchronisiert.

Angenommen, der Veranstaltungsordner liegt in einem Dokumentenordner, der mit OneDrive gesichert wird. Ergänzen Sie das Cloud-Konto in Ihrer Bestandsliste. Prüfen Sie auch die Freigaben. Zu wissen, wo eine Datei liegt, und zu wissen, wer darauf zugreifen kann, sind getrennte Fragen.

## Eine kleine Bestandsliste der Kopien anlegen

Erfassen Sie, was Sie tatsächlich gefunden haben, und markieren Sie unklare Speicherorte zur späteren Prüfung. Ihre Umgebung kann weniger oder mehr Einträge als dieses Beispiel enthalten.

| Speicherort und Kopie | Zu treffende Entscheidung |
| --- | --- |
| Projektordner: ursprüngliches Handout | Behalten, falls es für spätere Änderungen benötigt wird |
| Downloads: verkleinerter Export | Nach Prüfung der gewählten Veranstaltungskopie beurteilen |
| Veranstaltungsordner: geprüfter Export | Als Arbeitsfassung für die Veranstaltung behalten |
| Cloud-Konto: synchronisierter Ordner, falls aktiviert | Konto und Freigaberechte prüfen |
| Sicherung: frühere Fassungen, falls erfasst | Zweck und Aufbewahrung prüfen |
| Papierkorb: gelöschte Exporte, falls aufbewahrt | Nur die betreffenden Einträge prüfen |

Gleiche Namen belegen nicht, dass zwei Dateien dieselbe Fassung enthalten. Prüfen Sie den Inhalt und bestimmen Sie die gewünschte Kopie, bevor Sie einen Zwischenexport entfernen.

## Sicherungen und frühere Fassungen einbeziehen

Sicherungen sollen verhindern, dass der Inhalt einer Arbeitsdatei durch Verlust oder Änderung endgültig verloren geht. Das ist ein nützlicher Schutz. Es bedeutet zugleich, dass eine ältere Fassung nach dem Ersetzen der aktuellen weiter verfügbar sein kann.

Der Windows-Dateiversionsverlauf kann nach entsprechender Einrichtung Fassungen auf einem externen Laufwerk oder einem Netzwerkspeicher ablegen. Microsoft erklärt Umfang und Wiederherstellung in [Sichern und Wiederherstellen mit dem Dateiversionsverlauf](https://support.microsoft.com/en-us/windows/experience/backup-recovery/backup-and-restore-with-file-history).

Prüfen Sie, welche Ordner Ihre Sicherung erfasst und wie lange sie Fassungen aufbewahrt. Notieren Sie das, statt Sicherungsordner zu löschen, um bei einem Dokument aufzuräumen. Eine Sicherung kann die einzige wiederherstellbare Kopie anderer Arbeiten enthalten. Verwenden Sie auf einem verwalteten Computer das Verfahren Ihrer Organisation, wenn Aufbewahrungsfristen geändert oder Unterlagen entfernt werden sollen.

## Verstehen, was eine Entfernungsaktion verändert

Unterschiedliche Aktionen betreffen unterschiedliche Speicherorte. Wenn Sie eine OneDrive-Datei nur online verfügbar machen, werden ihre heruntergeladenen Inhalte vom Gerät entfernt, während die Cloud-Datei erhalten bleibt. Das Löschen einer synchronisierten Datei kann dagegen die Cloud und andere synchronisierte Geräte betreffen. Microsoft erklärt die Unterschiede in seiner [Dokumentation zu Dateien bei Bedarf](https://support.microsoft.com/en-us/onedrive/save-disk-space-with-onedrive-files-on-demand-for-windows). Prüfen Sie die Wirkung, bevor Sie damit eine Kopie verwalten.

Gelöschte Dateien können wiederherstellbar bleiben. OneDrive hat einen eigenen Papierkorb; die Aufbewahrung hängt vom Kontotyp und den Einstellungen ab. Eine ausschließlich in der Cloud liegende Datei muss nicht im Papierkorb des Computers erscheinen. Dazu gibt es Microsofts [Anleitung zur Wiederherstellung gelöschter Dateien](https://support.microsoft.com/en-us/onedrive/restore-your-onedrive-files).

Wenn eine Datei aus einem sichtbaren Ordner entfernt wurde, steht nur fest, was an diesem Speicherort geschehen ist. Das belegt nicht, dass getrennte Exporte, Sicherungen oder bereits weitergegebene Kopien ebenfalls verschwunden sind.

## Festlegen, was bleibt, und es prüfen

Bewahren Sie im Workshop-Beispiel die für spätere Bearbeitung benötigte Vorlage und die geprüfte Veranstaltungskopie auf. Prüfen Sie den überzähligen Download erst, nachdem Sie sich vergewissert haben, dass der beibehaltene Export korrekt geöffnet wird. Lassen Sie nützliche Sicherungen ihrer vorgesehenen Aufbewahrungsregel folgen und verändern Sie unklare Einträge erst, wenn Sie sie verstehen.

- Öffnen Sie die Datei, die bleiben soll, und prüfen Sie ihren Inhalt.
- Prüfen Sie Ordner, Cloud-Konto und Freigaben.
- Entfernen Sie nur bestimmte Kopien, deren Zweck erfüllt ist, nachdem Sie die Wirkung dieser Aktion geprüft haben.
- Notieren Sie Sicherungen oder andere Speicherorte, die noch untersucht werden müssen.

Wählen Sie beim nächsten Export das Ziel bewusst und geben Sie ihm einen eindeutigen Dateinamen. Wiederholen Sie die Prüfung beim Abschluss der Aufgabe, solange Sie noch wissen, welche Dateien Originale, Versuche und Endfassungen waren.
