Ratgeber

Zu jedem Werkzeug ein Ratgeber. Geschrieben für alle, denen jemand eine Größe oder ein Format vorgegeben hat und die vorher wissen möchten, was der Regler eigentlich tut, den sie gleich bewegen. Alles, was hier beschrieben wird, passiert auf Ihrem eigenen Gerät.

Einer je Werkzeug: worum es geht, welche Einstellung zählt und was sie kostet.

Werkzeuge verketten

Aufgaben, die zwei oder drei Werkzeuge nacheinander brauchen. In welcher Reihenfolge, und warum die Reihenfolge zählt.

  • So machen Sie ein GIF aus einem Teil eines Videos Erst die Sekunden schneiden, die zählen, dann nur diese umwandeln. Wann die Zeitleiste des GIF-Konverters reicht, wann der Videoschneider zuerst drankommt, und warum jede GIF-Sekunde so teuer ist.
  • So erstellen Sie ein Boomerang-Video Den Moment schneiden, die Kopie umkehren, beide zusammenfügen und schleifen lassen. Drei Werkzeuge nacheinander, alle im Browser, und die Reihenfolge, die die ganze Arbeit auf eine Minute bringt.
  • So verwandeln Sie ein langes Video in einen Zeitraffer Aus einer Stunde Material eine anschaubare Minute: wie man die Geschwindigkeit wählt, warum die Ziellänge besser ist als Kopfrechnen, und wann das Ergebnis ein GIF werden sollte.
  • So machen Sie ein Video-Thumbnail aus genau dem richtigen Bild Bildgenau zum richtigen Augenblick steppen, verlustfrei sichern, auf das Format der Plattform bringen und unter ihr Byte-Limit kommen. Drei Browser-Werkzeuge nacheinander, und das Material verlässt Ihr Gerät nie.
  • So bearbeiten Sie ein GIF Bild für Bild Ein GIF in seine Einzelbilder zerlegen, Bilder streichen oder umsortieren und es mit erhaltenem Timing neu bauen. Was die Rundreise übersteht, was die Palette kostet, und wie man sieht, warum ein GIF schwer ist.
  • So scannen Sie mehrere Seiten in ein kleines PDF Jede Seite fotografieren, ein PDF bekommen, mit vorhandenen Dokumenten zusammenführen und schrumpfen, bis es sich versenden lässt. Drei Browser-Werkzeuge nacheinander, und die Unterlagen verlassen das Telefon nie.
  • So machen Sie Handyfotos fertig fürs Web HEIC zu JPEG, GPS entfernt, für die Seite skaliert und auf ein Budget komprimiert: die ganze Kette im Browser, und die Originale verlassen Ihr Gerät nie.
  • So erstellen Sie einen QR-Code und beweisen, dass er scannt Den Code erzeugen, dann mit dem Leser derselben Seite prüfen: die genaue Nutzlast, den echten Link, in Druckgröße und vom Foto, vor der Auflage. Alles im Browser, nichts hochgeladen.
  • So räumen Sie ein Sprachmemo auf, bevor Sie es verschicken Die tote Luft und die Fehlstarts wegschneiden, dann den Pegel auf Vollaussteuerung heben. Zwei Browser-Werkzeuge nacheinander, in der Reihenfolge, die die Qualität bewahrt, und die Aufnahme verlässt Ihr Gerät nie.
  • So vergleichen Sie zwei JSON-Dateien Beide Dateien gleich formatieren, die Schlüssel sortieren, dann vergleichen. Warum ein roher JSON-Vergleich fast nur Rauschen ist, wie Sie beide Seiten im Browser in Normalform bringen, und was davon in die Patch-Datei gelangt.
