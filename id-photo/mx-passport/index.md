# Photo requirements: Passport, Mexico

The published rule for this document’s photograph — from Secretaría de Relaciones Exteriores, as it was read on 2026-09-19 — and a way to make one that meets it without sending your face to anybody.

Last updated 2026-09-19

## The figures

| What is measured | What this rule publishes |
| --- | --- |
| Print size | ⁦35 x 45⁩ mm at 300 dpi |
| Head, chin to crown | 70.0% to 80.0% (⁦31.5–36⁩ mm) (guidance) |
| Eye line, from the bottom | 50.0% to 60.0% (⁦22.5–27⁩ mm) (guidance) |
| Background | Plain white |
| Upload rule | none published — this one is a print |

## What else this rule says

- Three things here are stricter than the usual: the photograph may be no more than thirty days old, glasses come off altogether, and a grey background is named as a reason for refusal — it has to be white.
- No head-height band is published for this one, so the ICAO figures are shown in its place and are never marked as a failure. Frame it the way the rule describes in words and the numbers follow.

## Where these figures come from
