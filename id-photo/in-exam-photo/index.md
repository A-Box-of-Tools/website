# Photo requirements: IBPS online form photo, India

The published rule for this document’s photograph — from Institute of Banking Personnel Selection, as it was read on 2026-10-12 — and a way to make one that meets it without sending your face to anybody.

Last updated 2026-10-12

## The figures

| What is measured | What this rule publishes |
| --- | --- |
| Print size | no print size — this rule is for a web form |
| Head, chin to crown | 60.0% to 80.0% (guidance) |
| Eye line, from the bottom | 52.0% to 68.0% (guidance) |
| Background | Plain white |
| Online application photo | exactly ⁦200 x 230⁩ px (guidance), JPEG, 20.0 KB to 50.0 KB |

## What else this rule says

- The cited IBPS CRP PO/MT XIII notice prefers ⁦200 x 230⁩ pixels and requires a JPEG between 20 and 50 KB. This preset writes that preferred size. It is an example from that examination notice; read the current notice for your own application before using it.
- The head-and-shoulders framing is described in words rather than measured, so the bands here are guidance drawn from the sample images on the forms.
- There is no print size, because there is nothing to print: this is a file for a web form. The sheet export is switched off for it.

## What the tool does with them

- Locks the crop to this document’s shape, and draws the head and eye bands inside it, so you can see the rule on your own photograph instead of reading about it.
- Finds the crown, the chin and both pupils by measuring the picture — no face model is downloaded — and says in millimetres whether the head is too large or too small for this rule.
- Reads the background colour and how evenly it is lit, and says which of the two is the problem when there is one.
- Writes the print at the exact millimetres with the resolution in the file, a sheet of them with cut marks, and the upload file at the pixel and file size this rule states.
