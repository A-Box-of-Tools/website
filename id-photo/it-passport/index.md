# Photo requirements: Passport, Italy

The published rule for this document’s photograph — from Polizia di Stato, as it was read on 2026-09-17 — and a way to make one that meets it without sending your face to anybody.

Last updated 2026-09-17

## The figures

| What is measured | What this rule publishes |
| --- | --- |
| Print size | ⁦35 x 45⁩ mm at 300 dpi |
| Head, chin to crown | 70.0% to 80.0% (⁦31.5–36⁩ mm) |
| Eye line, from the bottom | 50.0% to 60.0% (⁦22.5–27⁩ mm) (guidance) |
| Background | White, light grey or light blue |
| Upload rule | none published — this one is a print |

## What else this rule says

- Italy publishes a width and nothing else: 35 to 40 mm, with the face filling 70 to 80 per cent of it. No height is stated anywhere, so this uses the ⁦35 x 45⁩ that Italian booths and photo shops sell.
- No eye line is published, so the band shown is where the eyes fall on a head sitting centred in the frame. It is guidance rather than a requirement, and is never painted red.

## Where these figures come from

Transcribed from Polizia di Stato — Le fotografie per il passaporto, conformi allo standard ICAO. Checked 2026-09-17. Rules change; the figures above are what to check against the form in front of you.
