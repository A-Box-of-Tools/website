# Photo requirements: Passport and identity card, United Arab Emirates

The published rule for this document’s photograph — from Federal Authority for Identity, Citizenship, Customs & Port Security, as it was read on 2026-09-19 — and a way to make one that meets it without sending your face to anybody.

Last updated 2026-09-19

## The figures

| What is measured | What this rule publishes |
| --- | --- |
| Print size | ⁦35 x 45⁩ mm at 300 dpi |
| Head, chin to crown | 70.0% to 80.0% (⁦31.5–36⁩ mm) |
| Eye line, from the bottom | 50.0% to 60.0% (⁦22.5–27⁩ mm) (guidance) |
| Background | Plain and light — no colour is published |
| Upload rule | none published — this one is a print |

## What else this rule says

- The Emirates publish a width and no height — 35 to 40 mm, with the face filling 70 to 80 per cent of the photograph — so this uses the ⁦35 x 45⁩ that a studio there sells. The background is described only as plain and light-coloured.
- No eye line is published, so the band shown is where the eyes fall on a head sitting centred in the frame. It is guidance rather than a requirement, and is never painted red.

## Where these figures come from

Transcribed from Federal Authority for Identity, Citizenship, Customs & Port Security — Personal Photo Specifications. Checked 2026-09-19. Rules change; the figures above are what to check against the form in front of you.
