接下來做什麼

下面兩份清單上的每一項，都得在你的瀏覽器裡運作，都得不上傳東西。過不了這一關，名字根本上不了榜。兩個數字沒寫死在任何地方，是建置腳本從清單上數出來的。

19 項計畫中 · 29 項已完成

這份清單是怎麼定出來的

這不是許願單。做法是把網上最大那家 GIF 和影片站點的工具列表從頭到尾過一遍，那份列表大概是現存最接近「人們到底想拿檔案做什麼」的一份目錄，然後只留下那些能做到在你自己機器上完成、拔了網路線也照常運作的條目。

留下來的絕大多數，靠瀏覽器本來就帶的介面就夠了。少數幾個得把編解碼器打包進唯一用到它的那個工具裡，這也算過關，檔案照樣不出這台機器。達不到這條線的寧可不寫，所以下面幾個看著很明顯的空缺，是故意空著的。

已經做出來的排在各自分組最前面，標著已完成，點進去就是它自己的頁面。下面的都還沒做，做出來之前不會變成連結。

每一類檔案，以及能拿它做什麼

Not built yet. Listed so you can see where this is going.

Images

  • 图片压缩 — 说个大小，剩下的它来算。 已完成
  • 图片缩放 — 说个尺寸，拉个框，挑个格式。 已完成
  • HEIC 转 JPG — iPhone 拍的照片，换成什么都打得开的格式。 已完成
  • 证件照制作 — 选好国家，它就照那个国家的规定，一字不差地办。 已完成
  • 图片涂黑与打码 — 你遮住的那块是从文件里删掉的，不是藏在文件里。 已完成
  • EXIF 查看与清除 — 看看一张照片把你交代了多少，然后删掉。 已完成
  • 图片转 ICO — 进去一张图，出来的是浏览器、Windows 和 Mac 各自要的每一个尺寸。 已完成
  • 图片转 Data URI — 整张图变成一行文本，直接粘进 CSS 或者 HTML。 已完成
  • SVG 转图片 — 说个尺寸。矢量图本来就没有尺寸可丢。 已完成
  • Add text — over the picture, or in a caption box above it
  • AVIF — the format one browser writes and the rest only read
  • DICOM anonymizer — take the patient out of a scan without touching the scan

GIF & animation

  • 视频转 GIF — 挑好段落、尺寸和帧率。 已完成
  • GIF 制作 — 把一组图片变成一段动画。 已完成
  • GIF 拆帧 — 每一帧都单独存成一张 PNG。 已完成
  • GIF 分析 — 帧、延时、调色板，以及每个字节的去向。 已完成
  • GIF to MP4 or WebM — the same animation, usually a tenth of the size
  • Edit a GIF — resize, crop, rotate, reverse it, or change how fast it plays
  • Animated WebP — the same animation at a fraction of the size — and the one here that needs a vendored encoder

Video

  • 图片转视频 — 一个文件夹的图片，变成一段视频。 已完成
  • 视频剪切 — 一边看一边标出要留的段落，最后拿回一个视频。 已完成
  • 视频裁剪 — 把片子切到只剩要紧的那块。 已完成
  • 视频倒放 — 最后一帧排在最前，连声音一起。 已完成
  • 延时视频 — 一小时的素材，二十秒看完。 已完成
  • 视频截帧 — 任意位置，一张原画质静帧。 已完成
  • Resize — down to a size that will actually send
  • Rotate — for the clip that was filmed sideways — and not one frame is decoded to do it
  • Mute a video — drop the sound and leave the picture untouched
  • Convert to MP4 — whatever came off the camera, as the file that will actually upload
  • Burn in subtitles — an SRT file drawn into the picture
  • Subtitle converter — SRT, VTT, ASS, SBV and LRC in any direction, and timings that can be shifted

Audio

  • 音频剪辑 — 边听边标出值得留的段落。它们会合成一个文件回来，就切在你说的位置。 已完成
  • 音频编辑 — 倒着放、快慢随你调、把录轻了的声音提上来，全在你这台机器上。 已完成
  • Convert format — MP3, WAV and Opus, in any direction

Documents & PDF

  • PDF 合并与拆分 — 挪动页面，不用往服务器跑一趟。 已完成
  • PDF 压缩 — 文档变小，不用送去任何地方。 已完成
  • 图片转 PDF — 把你的图片装进一个文档。 已完成
  • Rotate & crop pages — fix a scan that came in sideways, or trim its margins
  • Extract images — pull the pictures back out of a document
  • Redact a PDF — take the words out, rather than drawing a black box over them
  • Document scanner — a photo of a page, straightened and cleaned up into a document

Beyond media

  • 文本与代码 — 把它排好，看清改了什么，编码它，或者换成另一种格式。没有一个字被贴进别人的服务器。 已完成
  • 二维码与条形码生成 — 打进去，就变成一个码。生成过程不往外送任何东西。 已完成
  • 二维码与条形码识读 — 把摄像头对准码，或者把拍下来的图丢进来。读这件事只发生在这里，别处都没有。 已完成
  • 哈希与校验和 — 把下载来的文件和发布方公布的那串数字对一下，不用把它发给任何人。 已完成
  • 密码与密码短语生成器 — 在这里生成，由你自己的浏览器生成，不发往任何地方。什么都不保存，也没有历史记录。 已完成
  • CSV & JSON — convert either way, and tidy up what the spreadsheet exported
  • Certificates & keys — read a certificate or a signing request without pasting it into someone's server
