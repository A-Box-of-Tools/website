接下來做什麼

下面兩份清單上的每一項，都得在你的瀏覽器裡運作，都得不上傳東西。過不了這一關，名字根本上不了榜。兩個數字沒寫死在任何地方，是構建指令碼從清單上數出來的。

這份清單是怎麼定出來的

這不是許願單。做法是把網上最大那家 GIF 和影片網站的工具列表從頭到尾過一遍，那份列表大概是現存最接近「人們到底想拿檔案做什麼」的一份目錄，然後只留下那些能做到在你自己機器上完成、拔了網線也照乾的條目。

留下來的絕大多數，靠瀏覽器本來就帶的介面就夠了。少數幾個得把編解碼器打包進唯一用到它的那個工具裡，這也算過關，檔案照樣不出這臺機器。達不到這條線的寧可不寫，所以下面幾個看起來很明顯的空缺，是故意空著的。

已經做出來的排在各自分組最前面，標著已完成，點進去就是它自己的頁面。下面的都還沒做，做出來之前不會變成連結。

每一類檔案，以及能拿它做什麼

都還沒做。列在這裡，好讓你看清這個站要往哪裡走。

圖片

  • 圖片壓縮 — 說個大小，剩下的它來算。 已完成
  • 圖片縮放 — 說個尺寸，拉個框，挑個格式。 已完成
  • HEIC 轉 JPG — iPhone 拍的照片，換成什麼都打得開的格式。 已完成
  • 證件照製作 — 選好國家，它就照那個國家的規定，一字不差地辦。 已完成
  • 圖片堆疊 — 二十張變一張，不用傳二十次，也不用 RAW 轉換器。 已完成
  • 圖片塗黑與打碼 — 你遮住的那塊是從檔案裡刪掉的，不是藏在檔案裡。 已完成
  • EXIF 檢視與清除 — 看看一張照片把你交代了多少，然後刪掉。 已完成
  • DICOM 閱片器 — CT、MR、X 光和超音波，連窗寬窗位、頭資訊和測量一起。 已完成
  • 圖片轉 ICO — 進去一張圖，出來的是瀏覽器、Windows 和 Mac 各自要的每一個尺寸。 已完成
  • 圖片轉 Data URI — 整張圖變成一行文字，直接貼進 CSS 或者 HTML。 已完成
  • SVG 轉圖片 — 說個尺寸。向量圖本來就沒有尺寸可丟。 已完成
  • 加文字 — 壓在畫面上，或者放進畫面上方的文字條裡
  • AVIF — 只有一個瀏覽器寫得出來、其餘只能讀的格式
  • DICOM 去標識 — 把病人的資訊從影像裡拿掉，影像本身一動不動

GIF 與動圖

  • 影片轉 GIF — 挑好段落、尺寸和幀率。 已完成
  • GIF 製作 — 把一組圖片變成一段動畫。 已完成
  • GIF 拆幀 — 每一幀都單獨存成一張 PNG。 已完成
  • GIF 分析 — 幀、延時、調色盤，以及每個位元組的去向。 已完成
  • GIF 轉 MP4 或 WebM — 同一段動畫，通常只有原來的十分之一大
  • 編輯 GIF — 縮放、裁剪、旋轉、倒放，或者改播放速度
  • 動態 WebP — 還是那段動畫，體積只剩零頭——也是這裡唯一需要內建編碼器的一個

影片

  • 圖片轉影片 — 一個資料夾的圖片，變成一段影片。 已完成
  • 影片剪輯 — 一邊看一邊標出要留的段落，最後拿回一個影片。 已完成
  • 影片裁剪 — 把片子切到只剩要緊的那塊。 已完成
  • 影片倒放 — 最後一幀排在最前，連聲音一起。 已完成
  • 延時影片 — 一小時的素材，二十秒看完。 已完成
  • 影片截幀 — 任意位置，一張原畫質靜幀。 已完成
  • 縮放 — 壓到一個真的發得出去的尺寸
  • 旋轉 — 給那些拍橫了的片段——而且一幀都不用解碼
  • 把影片靜音 — 只去掉聲音，畫面原封不動
  • 轉成 MP4 — 不管從相機裡出來的是什麼，都變成傳得上去的那種檔案
  • 壓制字幕 — 把一個 SRT 檔案畫進畫面裡
  • 字幕轉換 — SRT、VTT、ASS、SBV、LRC 互轉，時間軸也能整體挪

音訊

  • 音訊剪輯 — 邊聽邊標出值得留的段落。它們會合成一個檔案回來，就切在你說的位置。 已完成
  • 音訊編輯 — 倒著放、快慢隨你調、把錄輕了的聲音提上來，全在你這臺機器上。 已完成
  • 格式轉換 — MP3、WAV 和 Opus，轉哪個方向都行

文件與 PDF

  • PDF 合併與拆分 — 挪動頁面，不用往伺服器跑一趟。 已完成
  • PDF 壓縮 — 文件變小，不用送去任何地方。 已完成
  • PDF 塗黑 — 字從檔案裡刪掉，然後再搜一遍這個檔案來證明。 已完成
  • 圖片轉 PDF — 把你的圖片裝進一個文件。 已完成
  • 文件掃描 — 把紙拍下來，回來的是一份看起來像掃描的東西。 已完成
  • 旋轉與裁剪頁面 — 把掃橫了的件扶正，或者切掉頁邊
  • 提取圖片 — 把文件裡的圖片重新取出來

媒體之外

  • JSON 格式化 — JSON、XML、HTML、CSS 和 YAML，格式化或轉換。沒有一個字被貼進別人的伺服器。 已完成
  • 文字比對 — 兩段文字進來，每處差異都被標出來，逐行、逐詞。沒有一個字被貼進別人的伺服器。 已完成
  • Base64 編碼解碼 — Base64、百分號編碼、HTML 實體、十六進位和反斜槓轉義，雙向都行。沒有一個字被貼進別人的伺服器。 已完成
  • 文字與檔案分享 — 分享只活在這個開著的分頁裡。讀的人從你的瀏覽器直接取得加密內容，關掉分頁就結束——任何伺服器上都不留一點東西。 已完成
  • QR Code 與條碼產生 — 打進去，就變成一個碼。產生過程不往外送任何東西。 已完成
  • QR Code 與條碼識讀 — 把鏡頭對準碼，或者把拍下來的圖丟進來。讀這件事只發生在這裡，別處都沒有。 已完成
  • 雜湊與校驗和 — 把下載來的檔案和釋出方公佈的那串數字對一下，不用把它發給任何人。 已完成
  • 密碼與密碼短語產生器 — 在這裡產生，由你自己的瀏覽器產生，不發往任何地方。什麼都不儲存，也沒有歷史記錄。 已完成
  • CSV 與 JSON — 兩個方向都能轉，順手把表格匯出的東西理乾淨
  • 證書與金鑰 — 讀一份證書或簽名請求，不用把它貼進別人的伺服器
