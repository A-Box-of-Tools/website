指南

一個工具一篇。寫給那些被人要求交出某個大小、某種格式，又想弄明白手上這個設定到底在動什麼的人。這裡講的每一步，都發生在你自己的機器上。

把工作做完

一個工具一篇：這件事要做什麼，哪個設定真管用，代價又是什麼。

  • 怎麼把圖片壓到指定的檔案大小 上傳框要 500 KB，你的照片有 4 MB。一個大小限制到底要你付出什麼，先動哪個設定，以及 PNG 為什麼不像 JPEG 那樣能壓。
  • 怎麼改圖片尺寸而不把它弄壞 改畫素尺寸時畫面到底經歷了什麼：為什麼縮小安全、放大不安全，框的比例跟照片對不上該怎麼辦，以及什麼時候其實該裁而不是縮。
  • 怎麼拍一張不會被退回來的證件照 證件照真正被量的是什麼——頭部高度、眼睛的位置、背景——哪個國家要哪些數字，以及怎麼滿足網上表格卡的畫素和 KB 限制。
  • 怎麼做一個到十六畫素還看得清的網站圖示 favicon.ico 裡到底該裝哪幾個尺寸，iPhone、安卓和 Mac 另外要哪些檔案，以及為什麼一個在海報上好好的 logo，到了十六畫素就沒了。
  • 怎麼把 SVG 轉成合適尺寸的 PNG 向量圖自己沒有畫素尺寸，所以這個數字由你定。螢幕、應用圖示和印刷各自的數字從哪裡來，以及一張圖紙變成畫素那一刻會發生什麼變化。
  • 什麼時候該把圖片塞進 CSS，什麼時候不該 data URI 的代價在哪裡，base64 為什麼多出三分之一而 gzip 又還不回來，SVG 為什麼絕不該用 base64，以及那個只坑內聯 SVG、還一聲不吭的引號問題。
  • 一張照片把你交代了多少，以及怎麼把它刪掉 手機拍的照片通常帶著精確的拍攝地點、精確到秒的時間，還有相機的序列號。裡面到底有什麼，誰讀得到，以及怎麼在不動畫面的前提下把它們清掉。
  • 圖片怎麼塗黑，才能讓被遮住的那塊真的沒了 大多數軟體畫出來的黑色方塊只是壓在圖片上面，隨手就能挪開。真正的塗黑和只是遮住差在哪裡，打過碼的文字為什麼能被讀回來，以及發出去之前怎麼檢查一個檔案。
  • 怎麼堆疊照片來壓雜訊，或者把人去掉 堆疊把一串連拍合成一張。用哪種手法，取決於你想失去什麼：雜訊、路人，還是微距那淺得可憐的景深。每種手法怎麼運作、代價是什麼，以及 RAW 檔案在這裡是什麼位置。
  • 怎麼開啟一個 DICOM 檔案，以及裡面有什麼 醫院給的光碟裡都有什麼，檔案為什麼沒有字尾，怎麼在瀏覽器裡開啟一份 .dcm 影像，窗寬窗位到底在做什麼，以及一份影像除了影像之外還帶著關於病人的哪些東西。
  • 手機存下的那張照片，和那個什麼都打不開的格式 iPhone 把照片存成 HEIC，而半個網際網路打不開它。這個格式是什麼，為什麼只有 Safari 解得了，轉換要拿畫質換多少，以及怎麼做到不把照片交給任何人。
  • 怎麼合併、拆分和重排 PDF 頁面 把幾個 PDF 合到一起、把一個切成好幾個、把頁面挪來挪去：重排之後什麼留得下、什麼是任何工具都帶不過去的，以及為什麼這些事都不必把你的檔案傳到別處。
  • 怎麼把 PDF 塗黑，讓文字真的消失 在 PDF 閱讀器裡畫的黑塊，通常把詞原封不動地留在了下面，複製貼上就能拿回去。真正的塗黑拿掉的是什麼，詞在頁面之外藏身的四個地方，以及發出去之前怎麼檢查一個檔案。
  • 怎麼給 PDF 瘦身，以及有些為什麼壓不動 一份 PDF 的體積到底壓在哪裡，掃描檔為什麼能小 80% 而合同幾乎紋絲不動，這裡的 DPI 是什麼意思，以及壓縮工具絕不該對你的文件做什麼。
  • 怎麼把多張圖片合成一個 PDF 把照片或者掃描檔做成一個 PDF：頁面大小、順序和旋轉，JPEG 為什麼進去時可以一點不掉畫質，以及這份 PDF 會向收件人交代些什麼。
  • 怎麼用手機掃描文件 一張紙的照片和這張紙的掃描檔之間差在哪裡：傾斜、不勻的光，還有檔案大小。照片怎麼拍，之後要修什麼，以及為什麼這些都不需要伺服器。
  • 怎麼把一個資料夾的圖片做成影片 用照片做一段 MP4 投影片：幀率和停留時間各管什麼，比例不對的照片怎麼辦，以及成品為什麼沒有配樂。
  • 怎麼用圖片做一個動圖 GIF 把一組圖片變成一個動圖 GIF：GIF 到底能放多快、調色盤那個選項改的是什麼，以及真正能讓檔案變小的三件事。
  • 怎麼剪影片而不重新編碼 剪一段片子可以一個位元組的畫質都不掉。為什麼下刀的位置有時候比你標的早，關鍵幀跟這有什麼關係，以及什麼時候該認下那次重新編碼。
  • 怎麼把影片畫面裁成另一個形狀 把片子裁成方圖、9:16 直式，或者精確到畫素的一個框。各家平臺要哪個比例，為什麼剪時長不用重編而裁畫面非重編不可，以及這一下的代價。
  • 怎麼把影片倒過來放 把片子反著放：倒放對畫面和聲音都做了什麼，為什麼它繞不開重新編碼，為什麼比剪輯慢，以及動手之前該先做哪一步。
  • 怎麼把影片裡的一幀存成圖片 按原解析度從片子裡取一張靜幀：為什麼暫停後的截圖不是同一張圖、該存成什麼格式，以及怎麼正好停在你想要的那一幀。
  • 怎麼剪音訊而不掉音質 一刀落在哪裡、為什麼音訊能剪得準而影片不能、為什麼接縫有時會「咔」一聲，以及那五毫秒的淡入淡出到底在做什麼。
  • 怎麼做一個到了別人手機上還掃得出來的 QR Code 糾錯等級該選哪個，QR Code 周圍那圈白為什麼是碼的一部分，印多大合適，還有免費產生器的「動態碼」日後要你付出什麼。
  • 怎樣用校驗和核對下載的檔案 在 Windows、macOS、Linux 或瀏覽器裡比對 MD5 與 SHA-256 校驗和的辦法，對上了究竟證明了什麼，以及那個讓整件事白做的錯誤。
  • 怎麼把影片做成 GIF 該挑哪一段、多寬、每秒幾幀，影片做成 GIF 為什麼會大出十倍，以及什麼時候壓根不該用 GIF。
  • 怎麼把 GIF 拆成一幀一幀 把動圖 GIF 的每一幀存成 PNG：為什麼有些幀只是畫面裡的一小塊、透明會怎麼樣，以及怎麼把時間留住，好把它再拼回去。
  • 一個 GIF 裡到底裝著什麼 幀、延時、處置方式和調色盤都講清楚：瀏覽器為什麼不認最短的延時，以及怎麼查出一個 GIF 的體積究竟花在了哪裡。
  • 怎麼不把 JSON 交給任何人也能格式化 在自己的瀏覽器裡排版、檢查和壓縮 JSON：一個格式化工具絕不該改動你檔案的哪些地方、錯誤資訊該怎麼讀，以及你把東西貼進哪個框裡為什麼要緊。
  • 如何不上傳就在裝置間分享文字與檔案 把文字或檔案經直連加密通道從一個瀏覽器送到另一個——不用寄信給自己，不留聊天紀錄，不需要帳號，也沒有哪台伺服器留著副本。

工具接力

要接連用上兩三個工具的工作：按什麼順序用，順序又為什麼要緊。

  • 怎樣把影片的一段做成 GIF 先剪出要緊的那幾秒，再只轉換那一段。什麼時候 GIF 轉換器內建的時間軸就夠用，什麼時候該先用影片剪輯器剪，以及 GIF 的每一秒為什麼那麼貴。
  • 怎樣做一個迴旋鏢影片 剪出瞬間，倒轉副本，把兩段接起來迴圈。三個工具連著用，全在瀏覽器裡，還有一個把整件事壓進一分鐘的次序。
  • 怎麼把長影片變成延時攝影 一小時的素材濃縮成看得下去的一分鐘：怎麼選速度，為什麼直接說成片多長比做除法更好，以及什麼時候成品該做成 GIF。
  • 怎麼從正好那一幀做影片封面圖 逐幀走到正確的瞬間，無損儲存，裁成平臺的形狀，壓到位元組上限的正下方。三個瀏覽器工具接力，素材從不離開你的電腦。
  • 怎麼逐幀編輯 GIF 把 GIF 拆成一幀一幀，刪掉或重排，再在保住節奏的前提下重組。往返一趟什麼能活下來、調色盤的代價是什麼、以及怎麼看清一個 GIF 為什麼重。
  • 怎樣把多頁掃成一個小 PDF 每頁拍一張，得到一個 PDF，和已有的文件併到一起，再縮到發得出去為止。三個瀏覽器工具連著用，紙面材料從頭到尾不離開手機。
  • 怎樣把手機照片弄妥了再上網 HEIC 轉 JPEG，抹掉 GPS，按頁面縮好尺寸，再按預算壓縮：整條鏈子都在瀏覽器裡，原圖從不離開你的機器。
  • 怎麼做一個 QR Code，並證明它掃得出來 產生 QR Code，再用同一個網站的識別器驗證：一字不差的內容、真正的連結，按印刷尺寸、用一張照片，在批次印刷之前。全在瀏覽器裡，什麼都不上傳。
  • 怎麼在發出去之前整理好語音備忘錄 剪掉空白和口誤重來的開頭，再把音量提到滿格線的正下方。兩個瀏覽器工具接力，按保住音質的順序來，錄音從不離開你的電腦。
  • 怎樣比對兩個 JSON 檔案 兩個檔案用同一種方式格式化，鍵排好序，再比對。為什麼生比 JSON 幾乎全是噪音，怎麼在瀏覽器裡把兩邊化成規範形，以及什麼能一路留到補丁裡。

上傳之前

把檔案交給一個網站，到底等於交出了什麼，以及這一步是不是非做不可。
