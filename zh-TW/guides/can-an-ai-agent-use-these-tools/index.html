AI 智慧體能用這些工具嗎？

能。這些都是普通網頁，沒有帳號，沒有驗證碼，每個控制元件都寫著名字，智慧體開它們和開別的頁面沒有兩樣。值得寫一頁的是背後那個問題：你把一件檔案上的工作交給智慧體，檔案去了哪裡？答案完全取決於智慧體的瀏覽器跑在哪裡。

最後更新 2026年8月27日

先說結論

能。這裡的每個工具都是普通網頁：一個選檔案的框，幾個寫著名字的控制元件，一個下載按鈕。沒有帳號要登入，沒有驗證碼要解，沒有哪一步非得是個人。帶瀏覽器的 AI 智慧體開這些頁面，和開別的頁面一個開法。這個站本來為人做的幾件事，順帶也便宜了智慧體，最後一節會數一數。

不過「它按不按得動按鈕」是小問題。值得寫一頁的是：這個站的承諾，就是你的檔案從不離開你的機器那一句，在按按鈕的機器不是你的時候，還算不算數？答案是，這個承諾要麼完整地經得住託付，要麼完全經不住，分界只有一條，就是智慧體的瀏覽器跑在哪裡。

智慧體分兩種，分界只有一條

會用工具的智慧體有兩副樣子。兩者的差別，比這一頁其餘所有內容都要緊。

本地的智慧體跑在你的機器上。裝在你電腦裡的助手是這樣，操縱你眼前這個瀏覽器的也是這樣。這樣的智慧體在這裡開啟一個工具、把你的檔案遞給它，工作就發生在這些頁面一貫發生工作的地方：一個瀏覽器裡，你自己的硬體上。檔案從你的磁碟讀出，在你瀏覽器的記憶體裡處理，再寫回你的磁碟。託付這件事，沒有改動位元組走的路。設定是 AI 挑的，檔案照舊哪裡也沒去。

雲上的智慧體把瀏覽器跑在它廠商的電腦上。你往對話裡附上一個檔案，智慧體在別處的一臺虛擬機器裡運作，它拿這些工具做的一切都發生在那邊。工具依然一字不差地守著承諾，檔案走不出它所在的那個瀏覽器。可那個瀏覽器不是你的，而且上傳在你附上檔案的那一刻就已經發生了，比任何工具被開啟都早。先於頁面發生的上傳，頁面收不回來。

所以這個站反覆問的那個問題，就是這工作到底用不用得著我的檔案出門，並不因為換了智慧體運作就消失。它只是往前挪了一步，挪到挑智慧體這件事上。本地智慧體開一個整個活在瀏覽器裡的工具，是難得的一種搭配：託付不花一分隱私。AI 運作，檔案在家。

怎麼把活交給智慧體

智慧體運作，最好的交代和交給同事的一樣：哪個工具，哪個檔案，做完了長什麼樣。幾個管用的路數。

  • 說結果，別只說工具。「開啟 abox.tools/compress-image/，把這張照片壓到 200 KB 以下」，等於把頁面要問的那個數字提前交給了智慧體。圖片壓縮工具就認一個指名道姓的目標大小，智慧體最能忠實執行的，恰好是這種指令。
  • 把地圖給它。這個站釋出了 llms.txt：每個工具、每篇指南，各配一行說明，純文字，一次抓取就是全部。讀過它的智慧體不用爬任何頁面，就知道這裡有什麼。
  • 讓它讀自己站著的那頁。每個工具的常見問題就寫在頁面裡，每個工具的指南只隔一個連結。看上去拿不準某個設定的智慧體，可以讓它先讀指南。給人的建議，也是這一句。
  • 連環的工作它最拿手。這個站的流程指南寫給人的那些活，掃描完拼成一個 PDF，先清 EXIF 再改尺寸，恰恰是智慧體最擅長的：每一步的產出就是下一步的原料，中間沒有一處要人拿主意。

哪些不該託付

這裡的每個工具，智慧體都開得動。但有兩處，開動不等於做完，剩下的部分應該留在你手裡。

決定什麼不能被看見。塗黑工具會把你蓋住的部分刪掉。可挑出該蓋什麼，那才是這件事本身。漏看一行的智慧體，交出來的是一份看起來完工、其實沒完工的檔案。塗黑的操作儘可以讓智慧體來，結果在發去任何地方之前，要你自己過目。那些工具的指南給人類操作者立的，就是這條規矩。

開啟讀到的東西。這個站的 QR Code 識讀器拒絕開啟它解出來的內容，因為讀和跟著走是兩個動作。同樣的分界也值得立給智慧體：在檔案裡讀到碼、連結或地址的智慧體，應該報告它，而不是訪問它。還有一層，操縱你自己瀏覽器的智慧體，手裡握著那個瀏覽器登入著的一切。這是用打量任何工具的那種眼光打量它的理由，下一節就說這個。

承諾，智慧體也驗得了

上傳那篇指南教的四項檢查，拔網線、盯網路面板、讀 Content-Security-Policy、讀程式碼，智慧體全做得來，而且比人做還順手：讀一個 CSP 頭，或者在下發的原始碼裡搜 fetch 呼叫，本來就是機器活。要是你習慣先讓智慧體驗一驗工具再信它，這個站就打算被這麼驗。這些檢查倚仗的離線行為，有自己的一頁。

這個站為智慧體做的事，都是故意做的，也都是為所有人做的。每個控制元件都寫著名字，因為螢幕閱讀器要名字，智慧體讀的是同一批名字。頁面上沒有帳號，沒有彈窗，沒有要繞著走的同意牆。原始碼公開，釋出時沒有構建那一層，智慧體審的程式碼就是跑著的程式碼。llms.txt 則是一次抓取裡裝下的整個箱子。這些沒有一樣是為機器添的。對用螢幕閱讀器的人可讀的頁面，結果對其餘一切也可讀，如此而已。

劃一條老實的線：這一頁講的是用這些工具的智慧體，不是智慧體本身。智慧體的廠商看得見什麼，你的指令、你的截圖、有時還有你的檔案，是另一個問題。這組指南繞來繞去總會到的那個習慣，用在它身上也正合適：問一問，真正需要離開你機器的是什麼，以什麼樣子離開。
