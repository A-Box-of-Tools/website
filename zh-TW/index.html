一箱子工具，都不走伺服器

一個工具只做一件事，全程在你的瀏覽器裡跑。檔案留在你自己的機器上，沒有東西要傳，沒有帳號要註冊，也沒人在旁邊記你做了什麼。

這些工具免費，以後也一樣。要是哪個真幫你省了事，全站開口跟你要點什麼的地方，就這一處。

  • 檔案不出你這台機器 打開、讀取、處理，全是你自己的瀏覽器在做，用的是你自己的硬體。每個工具的 Content-Security-Policy 都把允許連的地址列全了，裡面沒有一個是我們的。
  • 連你檔案的資訊也傳不出去 檔案本身不傳，縮圖、檔案名稱、大小、選了幾個，一樣不傳。這裡沒有哪個工具去讀這些，另一頭也沒有伺服器等著收。
  • 斷網照樣能用 把工具打開一次，然後拔掉網路線，它照常運作，跟連網時沒有差別。這一步很難作假。真要把檔案送出去處理，斷網當場就停。

上面這些不用你信。 怎麼判斷一個工具是不是真需要你的檔案 裡有四項你自己動手就能做的檢查，用在本站管用，用在別家也一樣。

圖片

壓縮、改尺寸，或者抹掉照片悄悄記下的那些資訊，全都不出這台機器。

  • 🗜️ 图片压缩 你说要多大，100 KB、2 MB 都行，它去找刚好够到这个数的最轻一档压缩。
  • 📐 图片缩放 精确到像素、按百分比，或者定个长边，顺路还能裁一刀、换个格式。一张图或者一整个文件夹都行。
  • 📱 HEIC 转 JPG iPhone 拍的照片，换成什么都打得开的格式。解码在你自己的机器上，不在谁的服务器上。
  • 🛂 证件照制作 选一个国家和一种证件，裁切框就会按那条规定取头高和眼线。按精确的毫米和分辨率打印，附带 10 × 15 拼版，并把上传文件压进办事门户的 KB 区间。
  • ⬛ 图片涂黑与打码 把图片的一部分涂黑、打码或者模糊掉。被遮的像素在文件写出来之前就被覆盖，不会留下一层可以挪开的东西。
  • 🏷️ EXIF 查看与清除 看清一张照片里藏着的位置、相机和机身序列号，想改哪条改哪条，或者一键清光。
  • 🔖 图片转 ICO 网站图标、Windows 应用图标，或者 macOS 的 .icns，每个尺寸都装在一个文件里，下载前先看 16 像素下什么样。
  • 📋 图片转 Data URI 位图走 base64，SVG 走百分号编码，外面那圈 CSS 规则或者<img> 标签也一并写好。
  • 🖼️ SVG 转图片 SVG 自己没有像素尺寸，所以这个数字由你定，32 也好 8000 也好，一样锐利。

影片與動畫

剪片、轉格式，或者用照片拼一段，素材都不出這台機器。

  • 🎞️ 图片转视频 把一个文件夹的图片做成 MP4 幻灯片。编码在你自己的机器上跑，用的是你自己的硬件。
  • 🎞️ 视频剪切 一边看一边把值得留的段落标出来，再把它们存成一个视频。画面帧是搬过去的，不是重编的，所以什么都不会丢。
  • ✂️ 视频裁剪 在片子上拉个框，切到只剩这块。发帖用方的，手机上看用竖的，或者精确到像素填一个框。
  • ⏪️ 视频倒放 把片子反过来放，画面和声音都算在内，而且不用把它发到任何地方去。
  • ⏩️ 延时视频 把长片子变成短片子，几小时压成几秒钟，而且不往任何地方送。
  • 🎞️ 视频截帧 把视频的任意一帧存成图片，尺寸就是视频本身的尺寸。可以一张一张地截，也可以每隔几秒截一张。
  • 🎞️ 视频转 GIF 标出你要的那几秒，挑好宽度和帧率，拿到一张 GIF 动图，配色板、抖动一并办好。
  • 🎬 GIF 制作 把图片排好顺序，说清楚每张停多久，就能拿到一个 GIF 动图。颜色和压缩都是在你自己的机器上算出来的。
  • 📑 GIF 拆帧 把动图拆开：每一帧存成单独的 PNG，透明保留下来，时长另外记下。解压 GIF 这件事发生在你自己的机器上。
  • 🔍 GIF 分析 打开一个 GIF，看看里面到底有什么：每一帧的延时和处置方式、颜色表，以及一份关于体积去了哪里的老实账。

文件與音訊

拼接文件、剪輯錄音，兩樣都不用送出去處理。

  • 📑 PDF 合并与拆分 把文档拼起来，把一个切成好几个，把页面拖成你要的顺序。链接和书签会重新搭好，跟着它们指向的页面走；每一个成品文件在交给你之前，都会被重新打开、重新数一遍页数。
  • 📈 PDF 压缩 把文档里的图片重新压一遍，文件就小了。它先摆给你看体积到底压在哪儿，没什么可省的时候也直说。
  • 📄 图片转 PDF 把图片合成一个 PDF，一张一页。JPEG 照片原样抄进去，画质一点不掉。
  • 🎧️ 音频剪辑 边听边把值得留下的段落标出来，然后存成一段录音。切点落在精确的采样上，接缝也不会咔哒。
  • 🎚️ 音频编辑 倒放一段音频，变速时音高可动可不动，把录轻了的录音提上来。视频里的声音也能抽出来。

文字、代碼與密碼

看一看、核一核，或者就在這裡產生。令牌、設定檔和密碼都不會落到別人的伺服器上。

  • 📝 文本与代码 一个 JSON 格式化器、一个比对器、一个编码器和一个转换器，都在同一页上。贴个 token 或者一份配置文件，不用交给任何人。
  • 🔳 二维码与条形码生成 给链接、Wi-Fi 或者名片做个二维码，也可以做一个算好校验位的零售条码。SVG 或 PNG 随你拿。
  • 🔍 二维码与条形码识读 从照片、截图或摄像头读二维码，并在打开之前看到完整地址。条形码也行。
  • 🔑 哈希与校验和 算出文件的 MD5、SHA-1、SHA-256、SHA-384 或 SHA-512，再和下载页面 公布的值对照。多大都行：文件是分块读的，从不整个留在内存里。
  • 🔑 密码与密码短语生成器 一个强随机密码，或者用自带词表拼出来的密码短语。由你自己的浏览器 抽取，不发往任何地方。
