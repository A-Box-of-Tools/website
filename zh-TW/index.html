一箱子工具，都不走伺服器

一個工具只做一件事，全程在你的瀏覽器裡跑。檔案留在你自己的機器上，沒有東西要傳，沒有帳號要註冊，也沒人在旁邊記你做了什麼。

這些工具免費，以後也一樣。要是哪個真幫你省了事，全站開口跟你要點什麼的地方，就這一處。

  • 檔案不出你這臺機器 開啟、讀取、處理，全是你自己的瀏覽器在做，用的是你自己的硬體。每個工具的 Content-Security-Policy 都把允許聯的地址列全了，裡面沒有一個是我們的。
  • 連你檔案的資訊也傳不出去 檔案本身不傳，縮圖、檔名、大小、選了幾個，一樣不傳。這裡沒有哪個工具去讀這些，另一頭也沒有伺服器等著收。
  • 斷網照樣能用 把工具開啟一次，然後拔掉網線，它照常運作，跟聯網時沒有區別。這一步很難作假。真要把檔案送出去處理，斷網當場就停。

上面這些不用你信。 怎麼判斷一個工具是不是真需要你的檔案裡有四項你自己動手就能做的檢查，用在本站管用，用在別家也一樣。

沒有符合的工具。

圖片

壓縮、改尺寸，或者抹掉照片悄悄記下的那些資訊，全都不出這臺機器。

  • 圖片壓縮 你說要多大，100 KB、2 MB 都行，它去找剛好夠到這個數的最輕一檔壓縮。
  • 圖片縮放 精確到畫素、按百分比，或者定個長邊，順路還能裁一刀、換個格式。一張圖或者一整個資料夾都行。
  • HEIC 轉 JPG iPhone 拍的照片，換成什麼都打得開的格式。解碼在你自己的機器上，不在誰的伺服器上。
  • 證件照製作 選一個國家和一種證件，裁切框就會按那條規定取頭高和眼線。按精確的毫米和解析度列印，附帶 10 × 15 拼版，並把上傳檔案壓進辦事門戶的 KB 區間。
  • 圖片堆疊 把一串連拍合成一張：取平均值抹掉雜訊，取中位數甩掉路人，或者取最亮做星軌。RAW 檔案不用轉換器也讀得了。
  • 圖片塗黑與打碼 把圖片的一部分塗黑、打碼或者模糊掉。被遮的畫素在檔案寫出來之前就被覆蓋，不會留下一層可以挪開的東西。
  • EXIF 檢視與清除 看清一張照片裡藏著的位置、相機和機身序列號，想改哪條改哪條，或者一鍵清光。
  • DICOM 閱片器 在你自己的機器上開啟 CT、MR、X 光或超音波影像。調好窗寬窗位，翻完整套序列，按毫米測量，讀遍頭資訊裡的每一個標籤。
  • 圖片轉 ICO 網站圖示、Windows 應用圖示，或者 macOS 的 .icns，每個尺寸都裝在一個檔案裡，下載前先看 16 畫素下什麼樣。
  • 圖片轉 Data URI 點陣圖走 base64，SVG 走百分號編碼，外面那圈 CSS 規則或者<img> 標籤也一併寫好。
  • SVG 轉圖片 SVG 自己沒有畫素尺寸，所以這個數字由你定，32 也好 8000 也好，一樣銳利。
  • Height Comparison Chart Put two adults, a child and a doorway on the same ruler — in centimetres or feet and inches — and download it as a PNG or an SVG.

影片與動畫

剪片、轉格式，或者用照片拼一段，素材都不出這臺機器。

  • 圖片轉影片 把一個資料夾的圖片做成 MP4 投影片。編碼在你自己的機器上跑，用的是你自己的硬體。
  • 影片剪輯 一邊看一邊把值得留的段落標出來，再把它們存成一個影片。畫面幀是搬過去的，不是重編的，所以什麼都不會丟。
  • 影片裁剪 在片子上拉個框，切到只剩這塊。發帖用方的，手機上看用直的，或者精確到畫素填一個框。
  • 影片倒放 把片子反過來放，畫面和聲音都算在內，而且不用把它發到任何地方去。
  • 延時影片 把長片子變成短片子，幾小時壓成幾秒鐘，而且不往任何地方送。
  • 影片截幀 把影片的任意一幀存成圖片，尺寸就是影片本身的尺寸。可以一張一張地截，也可以每隔幾秒截一張。
  • 影片轉 GIF 標出你要的那幾秒，挑好寬度和幀率，拿到一張 GIF 動圖，配色板、抖動一併辦好。
  • GIF 製作 把圖片排好順序，說清楚每張停多久，就能拿到一個 GIF 動圖。顏色和壓縮都是在你自己的機器上算出來的。
  • GIF 拆幀 把動圖拆開：每一幀存成單獨的 PNG，透明保留下來，時長另外記下。解壓 GIF 這件事發生在你自己的機器上。
  • GIF 分析 開啟一個 GIF，看看裡面到底有什麼：每一幀的延時和處置方式、顏色表，以及一份關於體積去了哪裡的老實帳。

文件與音訊

拼文件、剪錄音，兩樣都不用送出去處理。

  • PDF 合併與拆分 把文件拼起來，把一個切成好幾個，把頁面拖成你要的順序。連結和書籤會重新搭好，跟著它們指向的頁面走；每一個成品檔案在交給你之前，都會被重新開啟、重新數一遍頁數。
  • PDF 壓縮 把文件裡的圖片重新壓一遍，檔案就小了。它先擺給你看體積到底壓在哪裡，沒什麼可省的時候也直說。
  • PDF 塗黑 把詞從 PDF 裡刪掉，而不是蓋住。字是從繪製這一頁的指令裡拿走的，空出來的寬度保留著，別的東西不會移位；做好的檔案還會在這裡重新開啟搜一遍，證明那些詞不在裡面。
  • 圖片轉 PDF 把圖片合成一個 PDF，一張一頁。JPEG 照片原樣抄進去，畫質一點不掉。
  • 文件掃描 一張紙的照片，擺正清理之後變成一份文件。四個角替你找好，傾斜給你掰正，陰影除掉。
  • Extract Audio from Video Drop an MP4, MOV or WebM in and save the sound on its own. Only the audio track is decoded — the picture is never read, and the file never leaves your machine.
  • 音訊剪輯 邊聽邊把值得留下的段落標出來，然後存成一段錄音。切點落在精確的取樣上，接縫也不會咔噠。
  • 音訊編輯 倒放一段音訊，變速時音高可動可不動，把錄輕了的錄音提上來。影片裡的聲音也能抽出來。

文字、編碼與密碼

看一看、核一核，或者就在這裡產生。令牌、配置檔案和密碼都不會落到別人的伺服器上。

  • JSON 格式化 格式化和壓縮 JSON、XML、HTML、CSS 和 YAML，或者在它們之間轉換。貼個 token 或者一份配置檔案，不用交給任何人。
  • YAML to JSON Converter Turn YAML into JSON or JSON into YAML, and be told what the trip costs. Paste a deployment config without handing it to anybody.
  • XML Formatter Lay XML out to read it, squeeze it flat to ship it, or turn it into JSON and back. Paste an invoice or a feed without handing it to anybody.
  • 文字比對 比對兩段文字，逐行、逐詞看清改了什麼。貼一份合同或者尚未釋出的程式碼，不用交給任何人。
  • Base64 編碼解碼 Base64、URL、HTML 實體、十六進位和反斜槓轉義，編碼或解碼。貼個 token，不用交給任何人。
  • 文字與檔案分享 文字與檔案，經加密直連從瀏覽器到瀏覽器。哪裡都不存；關掉分頁，分享即止。
  • QR Code 與條碼產生 給連結、Wi-Fi 或者名片做個 QR Code，也可以做一個算好校驗位的零售條碼。SVG 或 PNG 隨你拿。
  • QR Code 與條碼識讀 從照片、截圖或鏡頭讀 QR Code，並在開啟之前看到完整地址。條碼也行。
  • 雜湊與校驗和 算出檔案的 MD5、SHA-1、SHA-256、SHA-384 或 SHA-512，再和下載頁面公佈的值對照。多大都行：檔案是分塊讀的，從不整個留在記憶體裡。
  • 密碼與密碼短語產生器 一個強隨機密碼，或者用內建詞表拼出來的密碼短語。由你自己的瀏覽器抽取，不發往任何地方。
