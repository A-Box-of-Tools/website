2 See what is on it

A PDF can be locked in two ways that look alike and are not. One is an open password, which nobody can get past without the password. The other is a set of restrictions — no printing, no copying, no editing — on a file that opens for everybody, where the lock is a request your reader has agreed to honour rather than anything cryptographic. This says which of the two this document has.
