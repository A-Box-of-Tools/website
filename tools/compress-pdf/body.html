2 See where the size is

"Compress a PDF" is two different jobs sharing one name. A scan is a stack of photographs, and re-encoding them is worth most of the file. A contract is text and fonts, which whatever made it already compressed — there is no eighty per cent hiding in it, and no tool can find one. Which of the two you have is not a matter of opinion, so here it is before anything is touched.

    3 Say how hard to squeeze

    A PDF records how large each picture is drawn, so this tool can measure what the page actually uses rather than guess. A 4000-pixel scan placed across eight inches of paper is carrying 500 pixels to the inch; at 150 it prints the same and looks the same on screen. Pixels nobody can see are spent first, because they cost nothing.
