This list shows Direct and Cloud relay shares offered to your selected local network or private group. Local-network matching uses a public IPv4 address or IPv6 subnet; shared gateways can include strangers and different routes can hide nearby devices. A private group uses its code instead. Join starts a connection request in a new tab; browsing alone does not connect. Private shares still need the sharer’s approval.

1 Write it, or attach it

Files use the same encrypted connection as the text, up to 200 MB apiece, with up to 256 files in one share. Readers see the list and fetch each file only if they ask for it.

2 Name the link

The name is the address, short enough to say across a room. Discoverable shares list it in your selected local network or private group. Keep Private on for anything sensitive.

For devices on the same Wi-Fi or Ethernet. Internet is still needed to introduce the browsers; this mode uses no public address-discovery server or relay. VPNs and browser settings can affect the network path. The copied link carries this setting. In Direct mode, choose Local network or join a private group to make your share discoverable. About discoverable shares

A discoverable share lists its name in the local network or private group selected above. Keep Private on, especially on shared networks. With Private off, anyone who sees the name can connect and read without your approval. Uncheck Discoverable to share only by link.

The draft is kept only in this browser, so it is still here next time — unless you mark it one-off, in which case nothing is kept anywhere at all.

No server content storage

Text and files travel encrypted from this tab to each reader. Cloud relay, when selected, forwards encrypted packets through Cloudflare. The rendezvous introduces the browsers and lists discoverable link names; it never sees the text or files. Closing this tab ends the share and clears readers’ open pages too — though what someone already copied or downloaded is theirs.
