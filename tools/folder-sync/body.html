            What is shared, and how the connection works

            Before you press Sync now, the two devices exchange file lists: every file’s path, size and last-modified date in the chosen folders. When two files have the same size but different dates, each device reads its own copy to compare a fingerprint of the contents, and only the fingerprint is exchanged.

            Sync now copies files over an encrypted WebRTC connection made directly between the two devices. Nothing is uploaded, and there is no relay: both devices must share a network they can reach each other on. The introduction service, rendezvous.abox.tools, carries only the setup messages that connect them.

            A received file is written to a temporary copy first and replaces the old file only once all of it has arrived, so a cancelled or broken sync never leaves a half-written file. Nothing is ever deleted: a file missing on one side is copied to it, unless you choose to leave it alone.

            Writing a file gives it today’s date, because a web page cannot set the date a file was changed. The next comparison recognises the copies as equal by their contents.
