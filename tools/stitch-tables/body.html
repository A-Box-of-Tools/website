2 Choose how to stitch

Method

The first number makes invoice-001 match paid/001. Leading zeroes matter: 001 and 1 stay different. Before and after use the first separator; a missing separator gives no match.

Stacking uses exact, trimmed headings and keeps extra columns. With headings off in either table it uses column position. Side by side keeps every row from the longer table.

Blank matching values never match. Repeated keys produce every matching combination; the summary reports them. Original cell values stay unchanged.

Choose a row from each table, then add the pair. Each row can belong to one pair. Unpaired rows follow your “Rows to keep” setting.

    3 Review and export

    The preview shows the first 100 rows and 20 columns. Copy and download include the whole result, up to 20,000 rows and 500,000 cells.

    Protection adds an apostrophe before cells starting with =, +, -, @, a tab or a line break, including negative numbers. Turn it off to export the original cell text. This affects headings too.
