    2 Say how big it should be

    This is the one question a vector cannot answer for you. An SVG has no pixels in it — it has instructions for drawing, and it will follow them at any size you name. The number below is not a limit you are pushing against, the way it would be with a photograph; 4000 pixels from a 24 pixel icon is exactly as sharp as 24 was.

    Every file on the list is multiplied from its own size, so a batch of icons drawn at different sizes stays in proportion to each other.

    The height follows from the shape of the drawing.

    The width follows from the shape of the drawing.

    Whichever side is longer becomes this and the other follows, so a wide logo and a tall one come out the same size on their long edge.

    3 Pick the format

    JPEG and WebP only; PNG has no quality dial because it is lossless. Flat colour and hard edges — which is most of what an SVG is made of — are exactly what a lossy encoder handles worst, so this sits higher here than it would for a photograph.

    4 Look at it, then save it

    The preview is drawn by the same code that writes the file, from the file you chose, on this machine. What it is worth checking for is the two things that change when a drawing becomes pixels: a hairline that was half a pixel wide and has gone grey, and any text, which is drawn in a font this machine has rather than one fetched from the web.
