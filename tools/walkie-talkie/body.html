One voice, nearby listeners

Broadcast your microphone to phones and computers on the same Wi-Fi or local network. One host speaks; everyone else listens, with only Mute and Leave controls.

Start on the host computer

  1. Download and extract the local broadcast package.
  2. Install Python 3.10 or newer if it is not already available.
  3. Open a terminal in the extracted folder and run python helper.py.
  4. Open the host address printed by the helper, start the channel, and share its listener link or QR code.
Download local broadcast package

Keep the helper running on the host computer. Receivers need only their browser. The helper handles setup on the host computer; voice goes directly between browsers. There is no public introduction or audio relay, and no accounts or recordings.

What to expect on a local network

Devices must be able to reach one another. Guest Wi-Fi and networks with device isolation may prevent connections. Each listener uses a separate connection from the host, so start with a small group.

Use a trusted local network. The helper uses HTTP for connection setup, so others on the network may be able to observe invitation tokens and setup messages. Anyone with a listener link can join while the channel is open. Live audio is encrypted between browsers.

Receivers start listening automatically. If a browser blocks audio, the same Unmute button starts playback. A receiver retries a missing host every second while its browser is active; background tabs and sleeping devices may retry more slowly.

The host microphone stops when its page is hidden or the channel ends. Bring the host page back and choose Start channel to resume. Restarting the helper creates new invitation links.
