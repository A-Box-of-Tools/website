    How devices connect

    Opening this page asks the pairing service for live channels grouped by public IPv4 address or IPv6 subnet and website origin. Shared gateways can include strangers, and VPNs can hide devices that are physically nearby. Starting with Show this channel nearby selected shares its name and listener invitation with that group. Hiding or ending the host removes its listing.

    An internet pairing service introduces the browsers using connection metadata. Live voice is encrypted and travels directly between them. There is no audio relay or recording.

    Use a trusted local network where devices can reach one another. Guest Wi-Fi, device isolation, and some VPNs or firewalls may prevent a connection. This tool uses no public STUN or TURN servers.

    The host needs microphone permission and a secure page. Start with a small group, because each receiver uses its own connection from the host.

    Receivers wait for a missing host and check once a second while their pairing connection is open. Background tabs, sleeping devices, and an interrupted internet connection may reconnect more slowly.
