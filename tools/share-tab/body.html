    How to pair

    Automatic uses online invitations unless your browser reports no internet. You can override that hint here. A viewer link keeps online pairing; manual blocks need a fresh exchange with the host. Both methods use the same reachable Wi-Fi, Ethernet or hotspot. The method stays fixed while sharing or connecting.

    For use without internet, open this HTTPS page on both devices beforehand and wait for each offline indicator to say ready. Connect the devices to a reachable local network yourself; this tool does not set one up. Exchange the blocks using a local method, such as files transferred by Bluetooth or USB through your devices. Blocks contain network addresses; share them only with the person you expect. The host must still approve the viewer before video starts.

        What is shared, and how the connection works

        The browser captures the selected tab’s picture, including visible signed-in content. Close private panels before sharing. Tab audio, your microphone and your camera are not requested. Selecting another browser tab does not automatically share it.

        A control connection carries the viewer’s request. Video is attached only after host approval and the viewer’s acknowledgement. Viewer actions have no remote-control path to the host.

        Both methods use a direct encrypted connection with no public STUN server or internet relay. Online pairing uses rendezvous.abox.tools for setup messages, never video or viewer notes. Offline pairing uses manually exchanged connection blocks and makes no introduction-service connection.

        Nearby discovery is optional in Online mode. A host can list their invitation code, and a viewer can ask the introduction service for matching listings. Matching uses the public IPv4 address or IPv6 network prefix, page address and tool, not a scan of your Wi-Fi. A match does not prove that a device is trusted or reachable. Offline mode has no nearby discovery.

        Use the same reachable Wi-Fi, Ethernet or hotspot. This page does not create a hotspot, Wi-Fi Direct or Bluetooth connection. Network isolation, firewalls, VPN routes and browser local-network permissions can block a connection. Local address settings do not prove that traffic stays inside a building.

        Before losing internet, load this HTTPS tool on both devices and wait for offline ready. The website you show must already be loaded or otherwise work offline. Files you save for the manual exchange contain connection addresses; remove them when no longer needed.

        Stop sharing, use the browser’s Stop sharing control, or close this page to end capture. Hiding this control tab while browsing the selected tab keeps sharing where the browser permits. When capture ends, choosing a tab again always needs a new click and browser permission.
