    2 Say what the icon is for

    An icon file is not one picture, it is several: the same logo drawn again at each size the thing reading it asks for. Which sizes those are is not a matter of taste — a browser wants three of them, an application on a high-DPI laptop wants ten, a Mac wants its own ten, and something written before Windows Vista wants them stored a different way entirely.

    3 Check it at the size it will be seen

    This is the part worth looking at before you download anything. A logo that reads perfectly at 512 pixels is sixteen pixels across in a browser tab, and the thin parts of it — the strokes in a wordmark, a hairline border, a gradient — do not survive that. Every square below is drawn at its real size from the file you chose.
