    2 Say where it is going

    A data URI on its own is rarely what anybody wants. What they want is the line that goes in the stylesheet — so pick the line, and the picture arrives inside it already quoted, which is the part that is easy to get wrong and that fails only for SVGs.

    The alt text is left empty on purpose. Only you know whether the picture carries meaning or is decoration, and a description guessed from a file name is worse for somebody using a screen reader than no description at all.
