1 Choisissez les photos

Une photo par page, prise de n'importe où au-dessus. La page entière doit être dans le cadre, et les quatre coins doivent être visibles ou presque ; tout le reste, l'inclinaison, l'ombre, le bureau sur lequel elle est posée, c'est ce à quoi sert cet outil. Ajoutez-en plusieurs et elles deviennent les pages d'un même document, dans l'ordre où vous les ajoutez.

    2 Placez les coins sur la page

    Choisissez une photo : elle apparaîtra ici, ses quatre coins déjà trouvés.

    Appuyez n'importe où sur la photo et le coin le plus proche vient sous votre doigt ; faites-le glisser jusqu'au coin de la page. Tab atteint un coin au clavier, les flèches le déplacent d'un pixel et Shift de dix. Rien ici n'est définitif : le scan est pris là où les quatre coins finissent.
