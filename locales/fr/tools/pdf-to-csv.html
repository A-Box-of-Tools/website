Retirer le mot de passe sur votre machine

Les banques verrouillent souvent les relevés avec votre date de naissance ou les derniers chiffres du compte. Ces méthodes créent une copie déverrouillée ; revenez ici avec elle : son texte sera conservé, ce dont cet outil a besoin.

  • Le Déverrouilleur de PDF sur ce site — saisissez le mot de passe : il est retiré dans ce navigateur, sans envoi. C’est la seule méthode ici qui ne réécrit rien sur les pages ; les mots restent exactement là où la banque les a placés.
  • Windows — ouvrez le PDF dans Chrome ou Edge, saisissez le mot de passe, puis Imprimer et choisissez Enregistrer en PDF comme imprimante.
  • macOS — ouvrez-le dans Aperçu, saisissez le mot de passe, puis Fichier → Exporter au format PDF.

N’utilisez aucun autre site proposant de le déverrouiller. Cela enverrait le relevé, précisément ce que cette page évite. La page liée ci-dessus n’en fait pas partie : elle n’a aucun serveur où envoyer un fichier et fonctionne encore sans réseau.

Ce fichier est une photographie : que faire à la place

Le fichier ne contient aucun texte — ses pages sont des images issues d’un scanner ou d’un téléphone. Lire les lettres d’une image est un autre travail que lire un tableau dans du texte ; cet outil ne prétend pas le faire. Par ordre approximatif d’efficacité :

  • Demandez les données à votre banque plutôt que le papier. Presque toutes les banques en ligne fournissent le même relevé en CSV, OFX ou QIF. Cela évite toute conversion et reste plus précis que la lecture d’une image.
  • Demandez à l’expéditeur le PDF original plutôt qu’un scan du document imprimé.
  • Ou lisez l’image sur votre machine. L’Outil Capture d’écran de Windows, Texte en direct de macOS et la fonction Reconnaître le texte d’Acrobat le font sans envoi. Vérifiez ensuite chaque montant visuellement : un chiffre mal lu ressemble à un nombre, pas à une erreur.

2 Vérifiez ce qui a été lu

Un PDF ressemble à un ensemble de tableaux mais contient du texte placé sur une page ; les colonnes sont des bandes de papier restées vides. Chaque tableau ci-dessous a donc été déduit. Lorsqu’il comporte un solde courant, la ligne au-dessus indique quelles comparaisons concordent et quelles lignes n’ont pas pu être vérifiées. La concordance contrôle les variations nettes ; des erreurs qui se compensent peuvent passer.
