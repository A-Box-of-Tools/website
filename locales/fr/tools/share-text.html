2 Nommez le lien

Le nom est l’adresse, assez court pour le dire à travers une pièce. Les partages visibles l’affichent dans le réseau local ou le groupe privé sélectionné. Gardez Privé activé pour tout contenu sensible.

Pour des appareils sur le même réseau Wi-Fi ou Ethernet. Internet reste nécessaire pour la mise en relation ; ce mode n’utilise ni serveur public de découverte d’adresses ni relais. Les VPN et les réglages du navigateur peuvent modifier le chemin. Le lien copié conserve ce choix. En connexion directe, choisissez Réseau local ou rejoignez un groupe privé pour rendre le partage visible. Les partages par relais cloud peuvent aussi apparaître si Visible est activé.

À propos des partages visibles

Un partage visible affiche son nom dans le réseau local ou le groupe privé sélectionné ci-dessus. Gardez Privé activé, surtout sur les réseaux partagés. Si Privé est désactivé, toute personne voyant le nom peut se connecter et lire sans votre approbation. Décochez Visible pour partager uniquement par lien.

Le brouillon ne reste que dans ce navigateur, il sera donc encore là la prochaine fois — sauf marqué éphémère, auquel cas il n'est nulle part.

Aucun contenu stocké sur un serveur

Le texte et les fichiers sont chiffrés entre votre navigateur et chaque lecteur. La connexion directe est choisie par défaut. Si vous choisissez le relais cloud, les paquets chiffrés passent par Cloudflare, qui ne peut pas lire leur contenu. Le service de mise en relation transporte la préparation et les noms de liens visibles, jamais les textes ou fichiers. Nous ne stockons aucun contenu partagé sur un serveur. Fermer l’onglet termine la source ; les lecteurs effacent leur vue après l’avis de fin ou la détection d’une panne. Les copies déjà enregistrées leur restent.

Recherche de la personne qui partage…

La connexion directe échange les adresses réseau nécessaires pour joindre les appareils. Le relais cloud utilise des adresses de relais ; Cloudflare voit les adresses des deux appareils et les métadonnées du trafic. Ce n’est pas une garantie d’anonymat. Vérifiez le choix de connexion avant de choisir explicitement Se connecter.

Aucun serveur public de découverte d’adresses ni relais internet n’est utilisé. Les VPN et les réglages du navigateur peuvent modifier le trajet réseau.
