1 Montrez-lui le code

Une photo, une capture d'écran, ou la caméra. Quel que soit votre choix, l'image est lue ici, dans cette page, sur votre machine — rien n'est envoyé, et une image de la caméra est examinée puis jetée, pas enregistrée.

{% include "partials/file-picker.html" %}

Vous pouvez aussi coller une image directement avec Ctrl+V — une capture d'un code déjà affiché à l'écran est la voie la plus rapide.

La caméra

Le voyant de la caméra est ici l'indicateur honnête : il est allumé tant que des images arrivent et éteint dès que vous arrêtez. Rien de ce qu'il y a entre ces deux moments n'est écrit sur le disque, et il n'y a dans la Content-Security-Policy de cette page aucune adresse vers laquelle une image pourrait partir.
