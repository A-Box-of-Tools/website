2 Consulta su protección

Un PDF puede tener dos protecciones distintas. Una es la contraseña de apertura, necesaria para leerlo. La otra son las restricciones de impresión, copia o edición en un archivo que cualquiera puede abrir. Estas últimas son peticiones que el lector acepta respetar, no una barrera criptográfica. Aquí ves qué tipo tiene este documento.
