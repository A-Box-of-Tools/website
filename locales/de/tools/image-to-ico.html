    2 Sagen, wofür das Symbol ist

    Eine Symboldatei ist nicht ein Bild, sondern mehrere: dasselbe Logo, neu gezeichnet in jeder Größe, die das lesende Programm verlangt. Welche Größen das sind, ist keine Geschmacksfrage. Ein Browser will drei davon, eine Anwendung auf einem hochauflösenden Notebook zehn, ein Mac seine eigenen zehn, und etwas, das vor Windows Vista geschrieben wurde, will sie ganz anders gespeichert haben.

    3 In der Größe prüfen, in der es zu sehen sein wird

    Diesen Teil sollten Sie sich ansehen, bevor Sie irgendetwas herunterladen. Ein Logo, das bei 512 Pixeln perfekt lesbar ist, wird im Browser-Tab sechzehn Pixel breit, und die dünnen Stellen daran überleben das nicht, also die Striche eines Schriftzugs, eine Haarlinie als Rahmen oder ein Verlauf. Jedes Quadrat unten wird in seiner echten Größe aus der von Ihnen gewählten Datei gezeichnet.
