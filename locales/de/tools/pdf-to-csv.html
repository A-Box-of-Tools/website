Das Passwort entfernen, auf Ihrem eigenen Gerät

Banken sperren einen Auszug oft mit Ihrem Geburtsdatum oder den letzten Ziffern einer Kontonummer. Jeder dieser Wege ergibt eine entsperrte Kopie; bringen Sie sie hierher zurück, und sie hat noch ihren Text, und den braucht dieses Werkzeug.

  • Der PDF-Entsperrer auf dieser Seite — tippen Sie das Passwort dort ein, und es wird in diesem Browser entfernt, ohne dass etwas hochgeladen wird. Er ist der einzige dieser Wege, der auf der Seite nichts neu schreibt, die Wörter bleiben also genau dort, wo Ihre Bank sie gesetzt hat.
  • Windows — öffnen Sie das PDF in Chrome oder Edge, tippen Sie das Passwort ein, dann Drucken, und wählen Sie Als PDF speichern als Drucker.
  • macOS — öffnen Sie es in der Vorschau, tippen Sie das Passwort ein, dann Ablage → Als PDF exportieren.

Benutzen Sie keine andere Website, die anbietet, es zu entsperren. Das hieße, den Auszug hochzuladen, und genau das zu vermeiden ist der Grund, warum es diese Seite gibt. Die oben verlinkte Seite gehört nicht dazu: Sie hat keinen Server, an den etwas hochgeladen werden könnte, und sie arbeitet auch mit getrennter Netzverbindung weiter.

Dieses hier ist ein Foto, und was Sie stattdessen tun können

In der Datei ist kein Text — ihre Seiten sind Bilder, aus einem Scanner oder von einem Telefon. Buchstaben aus einem Bild zu lesen ist eine andere Aufgabe, als eine Tabelle aus Text zu lesen, und dieses Werkzeug tut nicht so, als könnte es das. Ungefähr in der Reihenfolge, wie gut sie funktionieren:

  • Bitten Sie Ihre Bank um die Daten statt um das Papier. Fast jede Online-Bank gibt Ihnen denselben Auszug als CSV, OFX oder QIF. Das überspringt diese Seite ganz und ist genauer, als jede Umwandlung irgendeines Bildes sein könnte.
  • Bitten Sie den Absender um das ursprüngliche PDF statt um einen Scan des Ausdrucks.
  • Oder lesen Sie das Bild auf Ihrem eigenen Gerät. Das Snipping Tool von Windows, das in macOS eingebaute Live Text und Text erkennen in Acrobat tun das alle, ohne etwas hochzuladen. Prüfen Sie danach jeden Betrag mit dem Auge: Eine falsch gelesene Ziffer sieht nicht aus wie ein Fehler, sie sieht aus wie eine Zahl.

2 Prüfen, was es gelesen hat

Ein PDF sieht aus, als enthielte es Tabellen, und tut es nicht: Es enthält Text, der an Positionen auf einer Seite gesetzt ist, und die Spalten sind Papierstreifen, die niemand gedruckt hat. Jede Tabelle unten wurde also erschlossen und nicht gelesen. Wo eine von ihnen einen laufenden Saldo führt, ist die Zeile über den Tabellen das Werkzeug, das seine eigene Arbeit prüft — jede Zeile bewiesen an der Zeile davor.
