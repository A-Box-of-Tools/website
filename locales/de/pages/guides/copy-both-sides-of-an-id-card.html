Die kurze Antwort

Fotografieren Sie Vorder- und Rückseite der Karte auf einer Unterlage, die dunkler ist als sie, von gerade oben und ohne Spiegelung. Öffnen Sie das Werkzeug Ausweiskopie, fügen Sie die beiden Fotos hinzu, prüfen Sie auf jedem die gefundenen Ecken und speichern Sie das PDF. Drucken Sie es mit dem Drucker auf 100% oder „Tatsächliche Größe“ und legen Sie die Karte auf das Papier. Beide sollten gleich groß sein.

Wenn die Kopie an eine Website geht statt an einen Drucker, wählen Sie „Kein Blatt“ und ein JPEG, und Sie bekommen ein einziges Bild beider Seiten zum Hochladen.

Die beiden Fotos machen

Vier Dinge, geordnet danach, wie viel sie ausmachen:

  1. Keine Spiegelung. Die meisten Karten sind laminiert oder glänzend, und eine Deckenlampe oder der Blitz des Handys hinterlässt einen weißen Fleck, wo der Name oder die Nummer stehen sollte. Was unter einer Spiegelung liegt, kann nichts zurückholen, weil es nie fotografiert wurde. Schalten Sie den Blitz aus, und kippen Sie die Karte oder treten Sie zur Seite, bis der Fleck von ihr herunterwandert.
  2. Ein Hintergrund, der nicht die Farbe der Karte hat. Die Karte wird an ihren Kanten gefunden, und eine Kante ist dort, wo eine Sache in eine andere übergeht. Eine helle Karte auf einem weißen Schreibtisch hat fast keine Kante, die sich finden ließe; auf einem dunklen Tisch, einem Buchdeckel oder einer Jeans hat sie ringsum eine saubere.
  3. Füllen Sie das Bild. Das Kleingedruckte auf einer Karte ist klein. Eine Karte, die ein Drittel des Fotos füllt, kann zu weich zum Lesen herauskommen. Schritt 2 des Werkzeugs sagt, wie viel Detail jedes Foto hat, in Punkten pro Zoll bei Originalgröße der Karte; unter etwa 150 verschwimmt die Schrift.
  4. Ungefähr von gerade oben. Es muss nicht exakt sein, denn den Winkel herauszurechnen ist der Zweck des Werkzeugs. Aber eine fast von der Kante her fotografierte Karte ist überwiegend Verkürzung, und es bleibt nicht viel Karte zum Geraderücken übrig.

Warum eine Kopie in der falschen Größe herauskommt

Fast immer wegen einer einzigen Einstellung im Druckdialog. „An Seite anpassen“, „Auf Seitengröße verkleinern“ oder „Auf Papiergröße skalieren“ macht das ganze Blatt um ein paar Prozent kleiner, damit es in die Ränder des Druckers passt, und die Karte darauf schrumpft mit. Eine Karte, die in der Datei genau 85,6 Millimeter breit war, kommt mit etwa 82 heraus. Wählen Sie stattdessen „Tatsächliche Größe“ oder 100%.

Das PDF, das dieses Werkzeug speichert, setzt jede Seite in den eigenen Maßen der Datei in die Größe der Karte, sodass es bei 100% auf jedem Drucker in dieser Größe herauskommt. Eine Bilddatei ist weniger verlässlich: Die Kopie hält ihre eigene Auflösung fest, und manche Programme drucken danach, aber viele Fotobetrachter passen jedes Bild an das Papier an, was auch immer darin steht. Nehmen Sie zum Drucken das PDF.

Die andere Ursache ist das Foto selbst. Eine schräg fotografierte Karte ist am entfernten Ende schmaler, und ein Werkzeug, das einfach das sichtbare Rechteck ausschneidet und in einen Kasten streckt, liefert eine Karte, die unauffällig gestaucht ist. Hier werden die vier Ecken auf ein Rechteck in der genauen Form der Karte abgebildet, sodass jede Linie, die auf der Karte gerade ist, auch auf der Kopie gerade ist.

Wenn die Ecken falsch sitzen

Die Ecken sind ein Ausgangspunkt. Tippen Sie irgendwo auf das Foto, und die nächste kommt zu Ihrem Finger; ziehen Sie sie auf die Karte. Karten haben abgerundete Ecken, setzen Sie also jede dorthin, wo sich die beiden geraden Kanten treffen würden, und nicht auf die Rundung. Über die Tastatur erreicht Tab eine Ecke, und die Pfeiltasten bewegen sie.

Der übliche Grund, warum es schiefgeht, ist eine Karte auf einer Unterlage von fast ihrer eigenen Farbe. Ein dunklerer Hintergrund behebt das, oder Sie ziehen die Ecken auf den Rand der Karte.

Wenn eine Seite auf dem Kopf oder hochkant herauskommt, bringen die Schaltflächen zum Drehen sie in Ordnung. Manche Führerscheine sind hochkant statt quer bedruckt; drehen Sie diese Seite einmal, dann wird sie hochkant auf das Blatt gesetzt.

Vermerken, wofür die Kopie ist

Eine Kopie Ihres Ausweises ist das meiste von dem, was jemand braucht, um in Ihrem Namen ein Konto zu eröffnen, eine Wohnung zu mieten oder einen Vertrag abzuschließen. Die Kopie, die Sie einem Vermieter geben, ist am sichersten, wenn sie nur für diesen Vermieter gewesen sein kann. Geben Sie etwa „Kopie nur für die Wohnungsbewerbung Musterstraße 12, März 2027“ unter „Vermerk quer über die Karte“ ein, und er wird in schrägen Zeilen über beide Seiten geschrieben.

Er wird in das Bild der Karte selbst gezeichnet und nicht auf das PDF gelegt, und deshalb lässt er sich hinterher nicht aus der Kopie löschen. Halten Sie ihn so hell, dass die Karte lesbar bleibt, denn die Person, der Sie die Kopie geben, muss sie trotzdem lesen können. Ein Amt, das keine markierte Kopie annehmen kann, wird das sagen.

Warum das keinen Server braucht

Alles hier, also die Karte finden, geraderücken, anordnen und das PDF schreiben, ist Rechnen auf Pixeln, die der Browser bereits dekodiert hat. Für einen Server gibt es nichts zu tun, also hat das Werkzeug keinen. Die Seite kann die Fotos nirgendwohin senden, und sie funktioniert bei abgeschaltetem Netz. Bei diesem Dokument zählt das mehr als bei jedem anderen.
