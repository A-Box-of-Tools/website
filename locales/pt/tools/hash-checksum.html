2 Os checksums

MD5 e SHA-256 são calculados por padrão, porque juntos cobrem quase toda página de download que existe. Se você marcar outro, o arquivo é lido de novo para ele: a leitura é a metade lenta, então tudo que estiver marcado antes de escolher o arquivo sai de uma passada só.

3 Compare com o que deveria ser

Cole o checksum que a página de download te deu. A forma não importa: hexadecimal puro, a saída do sha256sum, um arquivo SHA256SUMS inteiro, a forma SHA256 (arquivo) = …, ou o atributo integrity de uma tag de script. Qual algoritmo é sai do comprimento, então não há o que escolher.
