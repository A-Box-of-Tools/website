1 Escolha a imagem

O print de um extrato bancário, a foto de um passaporte, uma conta com um endereço nela: as imagens que precisam de tarja são justamente as que não deveriam ser enviadas ao servidor de um estranho para isso. Esta aqui o navegador lê direto do seu disco.

2 Cubra o que ninguém deve ver

Escolha uma imagem e ela aparece aqui para você desenhar em cima.

Arraste sobre a imagem para desenhar uma caixa. Arraste a caixa para movê-la, use as alças para mudar o tamanho, ou chegue nela com Tab e trabalhe com as setas: Alt com as setas muda o tamanho e Delete remove. O que você vê embaixo de cada caixa é o resultado de verdade: a prévia é desenhada pelo mesmo código que escreve o arquivo, no tamanho da tela.

O que uma caixa nova faz

    3 Salve a cópia tarjada

    A imagem é decodificada em pixels, as caixas são escritas por cima desses pixels, e o resultado é codificado como um arquivo novo. Não há camada, anotação nem registro de onde as caixas estavam, porque os pixels cobertos deixam de existir antes de o codificador receber qualquer coisa.

    Para a tarja não faz diferença: os pixels já foram embora quando o codificador os vê. Isso decide só quanto custa o resto da imagem e como ele é comprimido.
