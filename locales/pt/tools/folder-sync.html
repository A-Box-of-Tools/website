            O que é compartilhado e como a conexão funciona

            Antes de você pressionar Sincronizar agora, os dois dispositivos trocam listas de arquivos: o caminho, o tamanho e a data da última modificação de cada arquivo das pastas escolhidas. Quando dois arquivos têm o mesmo tamanho mas datas diferentes, cada dispositivo lê a própria cópia para comparar uma impressão digital do conteúdo, e só a impressão digital é trocada.

            Ao pressionar Sincronizar agora, os arquivos são copiados por uma conexão WebRTC criptografada feita diretamente entre os dois dispositivos. Nada é enviado a um servidor, e não há retransmissão: os dois dispositivos precisam compartilhar uma rede em que consigam se alcançar. O serviço de apresentação, rendezvous.abox.tools, leva só as mensagens de preparação que conectam os dois.

            Um arquivo recebido é gravado primeiro numa cópia temporária e só substitui o arquivo antigo depois de chegar inteiro, então uma sincronização cancelada ou interrompida nunca deixa um arquivo gravado pela metade. Nada jamais é excluído: um arquivo que falta de um lado é copiado para esse lado, a menos que você escolha deixá-lo como está.

            Gravar um arquivo dá a ele a data de hoje, porque uma página web não consegue definir a data em que um arquivo foi modificado. A próxima comparação reconhece as cópias como iguais pelo conteúdo.
