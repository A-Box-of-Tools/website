在讲话设备上开始

在本网站打开 Local Walkie-Talkie，选择 Start channel 并允许使用麦克风。支持此功能的手机或电脑可以通过 HTTPS 页面主持频道。无需 Python 辅助程序、下载或账号。请保持主机页面可见，并让设备保持唤醒状态。

邀请听众

将收听链接或二维码分享给你所在的 Wi-Fi 或以太网上能够与主机直接连接的设备。打开邀请后会自动开始连接，且不会请求麦克风权限。如果浏览器阻止播放声音，选择 Unmute 即可开始播放。听众只有 Mute/Unmute 和 Leave 两项控制。

双方都需要连接互联网才能完成配对。配对服务传递连接信息和状态；实时语音则通过另一条直接加密的连接，从主机传送到每个听众。没有可供回退使用的公共音频中继服务。

按住说话

用触屏或鼠标按住 Talk 按钮，或让按钮获得焦点后按住空格键。松开即可停止发送语音。Start talking 提供单击开始、再次单击停止的方式。麦克风静音时，这两种方式都不会发送语音。最多可连接十名听众，等待中的连接也计入此上限；请先从小范围开始，并检查你打算使用的设备和网络。

恢复失联的主机

等待中的接收端会在当前页面检查主机是否可用，并保留静音设置。页面在前台时，目标检查间隔为一秒。已经正常工作的直接语音连接，可以在配对服务短暂中断时继续运行。浏览器处于后台、服务连接限制和设备休眠都可能延迟恢复。

隐藏主机页面会释放麦克风。返回同一个标签页并选择 Start channel，即可使用保留的邀请恢复频道。浏览器为每个标签页提供的临时存储，还能让频道在页面重新加载后得以保留；如果存储不可用，重新加载主机页面会生成新的邀请。End broadcast 会主动结束会话，下次选择 Start channel 时将创建新的邀请。Leave 会停止一名听众的连接及其重试。

谨慎分享邀请

任何持有收听邀请且能与主机直接连接的人，都可以收听实时音频。主机使用的另一把密钥保留在其浏览器标签页中，不会分享出去。听众密钥先通过链接中 # 字符之后的片段传递，随后通过安全的配对消息传递。服务在保持打开的连接上保存临时房间状态；Cloudflare 会将调用元数据日志保留七天，但不会保留麦克风音频。

网站常规的广告、测量和捐赠按钮脚本也会在此页面运行。工具不会向它们提供音频，但页面脚本可以读取页面地址和浏览器存储。在存储可用时移除地址中的邀请片段，可以减少该片段随后暴露的机会，但无法将这些脚本隔离开来。请在信任此页面的前提下授予麦克风权限。接收者可以自行录制听到的内容。

检查设备能否直连

访客 Wi-Fi 可能会隔离设备。即使两台设备看起来连接着同一个 Wi-Fi，防火墙、浏览器的本地网络权限、VPN 和操作系统路由也可能影响直接连接。工具仅使用主机候选地址，不使用 STUN 或 TURN 服务器；这会限制可用路由，但不能据此证明连接被限定在某个物理网络内。请先用实际要使用的手机和电脑进行测试，再依赖这个频道。
