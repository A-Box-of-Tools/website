在讲话设备上开始

在本网站打开 Local Walkie-Talkie，在 Channel name 中输入听众容易辨认的名称。保持 Make this channel discoverable 选中以列出频道，或取消选中，只通过链接邀请。Connection 保持为 Direct；如果设备无法直接连接，就在开始前选择 Cloud relay。选择 Start channel 并允许使用麦克风。支持此功能的手机或电脑可以通过 HTTPS 页面主持频道。无需 Python 辅助程序、下载或账号。为获得更稳定的连接，请尽可能保持主机页面可见，并让设备保持唤醒状态。

批准听众加入

新频道默认开启 Require approval。每位新听众都要等待批准后才能接收音频。在请求弹窗或列表中选择 Approve 或 Deny；Review later 会关闭弹窗，并让请求保持等待状态。可以在开始前关闭审批。以前获批的身份可以在同一房间内恢复连接；结束广播会阻止恢复。

寻找频道或邀请听众

听众打开 Local Walkie-Talkie，在 Available connections 中查看频道的连接方式图标，再选择该行的 Join。列表会自动更新。仅浏览不会连接；加入后只接收音频，绝不会请求麦克风权限。如果没有列出频道，改为分享听众链接或二维码；打开 Direct 邀请会自动开始连接。Cloud relay 邀请会先显示连接方式，等待选择 Join。如果浏览器阻止声音，Unmute 可以开始播放。连接后，听众使用 Mute/Unmute 和 Leave。

双方都需要联网才能进行发现和配对。服务传递频道名称、听众邀请、连接信息和状态；实时语音通过另一条加密路径，从主机传到每位听众。默认使用 Direct，绝不会自动切换连接方式。Cloud relay 是需要明确选择的替代方式，通过 Cloudflare 转发加密音频；它能看到地址、时间和流量，并且需要全程联网。双方使用主机选择的连接方式。

附近发现根据公网 IPv4 地址或 IPv6 /64，以及本站来源（origin）对浏览器分组。它不会扫描 Wi-Fi，也不能证明列出的频道就在你的物理网络中。共享网关可能包含陌生人；VPN 和不同的互联网路径可能隐藏就在身旁的设备。如果发现列表遗漏频道，请使用听众链接。

按住说话

用触屏或鼠标按住 Talk 按钮，或让按钮获得焦点后按住空格键。松开即可停止发送语音。如需免按住按钮讲话，请选择 Start talking。音频会持续发送，直到选择 Stop talking。放下设备前，请确认屏幕上显示的发送状态。麦克风静音时，这两种方式都不会发送语音。最多可连接十名听众，等待中的连接也计入此上限；请先从小范围开始，并检查你打算使用的设备和网络。

恢复失联的主机

等待中的接收端会在当前页面检查主机是否可用，并保留静音设置。页面在前台时，目标检查间隔为一秒。已经正常工作的直接语音连接，可以在配对服务短暂中断时继续运行。浏览器处于后台、服务连接限制和设备休眠都可能延迟恢复。

隐藏页面不会主动断开正常的连接。按住讲话会自动松开；通过 Start talking 开启的免按住讲话会在浏览器允许时继续运行。不过，锁屏后手机仍可能暂停麦克风、声音或网络。麦克风实际中断时，频道保持开放，但语音发送会停止。返回页面后，若麦克风已停止，页面会尝试重新获取；必要时请选择 Resume microphone。若整个页面曾被挂起，页面会尝试恢复同一频道和邀请；浏览器要求操作时请选择 Resume channel。发生中断后，语音发送保持关闭，直到你主动重新开始。

浏览器为每个标签页提供的临时存储，还能让频道在页面重新加载后得以保留；如果存储不可用，重新加载主机页面会生成新的邀请。End broadcast 会移除频道列表条目、结束会话并阻止自动恢复。下次开始时会创建新的邀请。Leave 会停止一名听众的连接及其重试。

谨慎分享邀请

听众邀请让持有者通过主机选定的连接方式申请访问。开启 Require approval 时，主机必须先批准，听众才能接收任何音频。开始时选中 Make this channel discoverable，会有意向发现组分享频道名称和听众邀请密钥。找到频道的人可以申请加入，仍需按审批设置获批。如果只想通过链接分享邀请，请在开始前取消选中该项。主机单独使用的密钥留在自己的浏览器标签页中，不会分享。复制的链接通过 # 字符之后的片段携带听众密钥，随后通过安全的配对消息传递。服务在保持打开的连接上保存临时房间状态；Cloudflare 将调用元数据日志保留七天，绝不会保存麦克风音频。

网站常规的广告、测量和捐赠按钮脚本也会在此页面运行。工具不会向它们提供音频，但页面脚本可以读取页面地址和浏览器存储。在存储可用时移除地址中的邀请片段，可以减少该片段随后暴露的机会，但无法将这些脚本隔离开来。请在信任此页面的前提下授予麦克风权限。接收者可以自行录制听到的内容。

检查设备能否直连

如果手机热点允许参与设备之间直接通信，也可以使用热点。请将设备连接到同一个热点，并保持互联网连接以便发现和配对。列表中没有频道时，请使用听众链接或二维码。部分热点和受管理的设备会阻止直接通信，请先用实际要使用的设备测试。

访客 Wi-Fi 可能会隔离设备。即使两台设备看起来连接着同一个 Wi-Fi，防火墙、浏览器的本地网络权限、VPN 和操作系统路由也可能影响直接连接。Direct 仅使用主机候选地址，不使用 STUN 或 TURN 服务器；这会限制可用路由，但不能据此证明连接被限定在某个物理网络内。请先用实际要使用的手机和电脑进行测试，再依赖这个频道。
