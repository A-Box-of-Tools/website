把下载页面给你的校验和粘进来。什么形式都不要紧：光是十六进制、 sha256sum 的输出、整份 SHA256SUMS 文件、 SHA256 (文件名) = … 这种写法，或者 script 标签上的 integrity 属性。是哪种算法由长度决定，所以没有什么要选的。

这是一个 。这是一份清单，里面有 个校验和。这是 个十六进制字符，而这里没有哪一种是这个长度。多半是复制时丢了结尾。里面没有看起来像校验和的东西。

✓ 这就是那串校验和所描述的文件。它的 和你粘进来的一字不差。

✓ 字节对得上，但对上的是另一行。你粘进来的内容把这个文件叫作 ，而你选的文件叫别的名字。要么它在路上被改了名，要么它不是你想核对的那次下载；无论哪种， 都是对的。
