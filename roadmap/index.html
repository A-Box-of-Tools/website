What is coming next

Everything on both lists below does its work inside your browser and uploads nothing — that is the rule a name has to pass before it goes on here at all. The counts are not written down anywhere; the build reads them off the two lists.

22 planned · 28 built

How this list was drawn up

It is not a wishlist. It was drawn up by going through the tool list of the largest online GIF and video site, the closest thing there is to a catalogue of what people actually want done to a file, and keeping every entry that can be built so the work happens on your own machine and keeps happening with the network unplugged.

Most of what survived runs on APIs the browser already ships. A few need a codec vendored into the one tool that uses it, which is allowed — the file still never leaves the machine. Anything that cannot clear that bar was left off rather than promised, so a few of the obvious-looking gaps below are gaps on purpose.

The tools that already exist sit at the top of their group, marked Built and linked to their own page. Everything under them is still to come, and nothing is a link until it is.

Every kind of file, and what can be done to it

Not built yet. Listed so you can see where this is going.

Images

  • EXIF Viewer & Remover — See what a photo says about you. Then take it out. Built
  • Image Redactor — What you cover is deleted from the file, not covered up in it. Built
  • HEIC to JPG — The photos an iPhone makes, in a format everything opens. Built
  • Image to Data URI — The whole picture as one line of text. Paste it straight into CSS or HTML. Built
  • Image to ICO — One picture in. Every size a browser, Windows or a Mac asks for, out. Built
  • SVG to Image — Name the size. A vector has none of its own to lose. Built
  • ID Photo Maker — Pick the country. It applies that country's rule, exactly. Built
  • Image Resizer — Say the size. Draw the box. Pick the format. Built
  • Image Compressor — Name the size. It works out the rest. Built
  • Rotate & flip — quarter turns, or straightening by a few degrees
  • Add text — over the picture, or in a caption box above it
  • Filters — brightness, contrast, saturation, blur, grayscale
  • AVIF & JPEG XL — convert either way, in whichever browser you happen to use

GIF & animation

  • Video to GIF — Pick the section, the size, and the frame rate. Built
  • GIF Maker — Turn a set of pictures into one animation. Built
  • GIF Splitter — Every frame out as its own PNG. Built
  • GIF Analyzer — Frames, delays, palettes, and where every byte went. Built
  • GIF to MP4 or WebM — the same animation, usually a tenth of the size
  • Resize, crop & rotate GIFs — frame by frame, with the timing kept
  • Reverse a GIF — last frame first
  • Change GIF speed — retime it without re-rendering the frames
  • APNG maker — animation with real transparency and full color
  • Animated WebP — the same animation again, at a fraction of the size

Video

  • Images to Video — Turn a folder of images into a video. Built
  • Video Cutter — Mark the parts worth keeping as it plays. Get them back as one video. Built
  • Video Cropper — Cut a clip down to the part that matters. Built
  • Video Reverser — Last frame first, sound and all. Built
  • Time-Lapse Maker — An hour of footage, in twenty seconds. Built
  • Video Frame Grabber — A full-quality still from any point. Built
  • Resize — down to a size that will actually send
  • Rotate — for the clip that was filmed sideways
  • Mute, or save the audio — drop the sound, or keep it on its own
  • Convert to MP4 or WebM — whichever one the site you are posting to insists on
  • Filters — brightness, contrast, saturation, blur
  • Burn in subtitles — an SRT file drawn into the picture

Audio

  • Audio Trimmer — Mark the parts worth keeping as it plays. Get them back as one file, cut where you said. Built
  • Audio Editor — Play it backwards, change the speed, lift a quiet recording — all of it here, on your machine. Built
  • Fade in & out — so it does not start and stop on a cliff
  • Waveform image — draw a track as a picture
  • Convert format — MP3, WAV and Opus, in any direction

Documents & PDF

  • PDF Merger & Splitter — Pages moved around without a round trip to a server. Built
  • PDF Compressor — Shrink a document without sending it anywhere. Built
  • Images to PDF — Put your pictures into one document. Built
  • Rotate & crop pages — fix a scan that came in sideways, or trim its margins
  • Extract images — pull the pictures back out of a document

Beyond media

  • QR & Barcode Generator — Type it, and it becomes a code. Nothing is sent to make one. Built
  • Hash & Checksum — Check a download against the number the publisher printed, without sending it to anyone. Built
  • Text & Code — Lay it out, see what changed, encode it, or turn it into the other format. Nothing is pasted into anyone else's server. Built
  • Password & Passphrase Generator — Made here, by your own browser, and never sent anywhere. Nothing is stored and there is no history. Built
  • Data — CSV and JSON conversion, cleaning, inspection
